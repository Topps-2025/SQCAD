# Branching futures: image provenance

The 32 new scene panels were generated using GPT Image (`gpt-image-2`) through the user-authorized image API and the bundled imagegen CLI. No credential is stored in the website or these prompts.

Eight original 2048 × 2048, high-quality four-panel sheets were generated, then cropped into WebP panels by `case_study/art/split_sheets.py`. The finance future sheet was returned as PNG; the remaining production sheets were returned as WebP. Their local sheet directory is `case_study/art/generated/branching-v3/`. Raw sheets are not published by Pages. Each final panel has a distinct SHA-256, enforced by the model/asset test.

Each case uses `future-A1`, `future-A2`, `future-B1`, `future-B2`, and `evidence-resolve`, `evidence-probe`, `evidence-uncertain`, `evidence-delay` under `case_study/assets/`. Observation and action labels remain HTML; illustration content is not evidence or experimental output.

The 1024 × 1024 exploratory Alex sheet is discarded, not used in the site. Failed API responses produced no final panel and were retried without replacing successful sheets.
