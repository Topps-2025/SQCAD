THE WORLD TREE / VALUE ACCOUNTING

A trajectory is not an expectation.

The interaction now separates four objects: latent context A/B; a future task sequence A1/A2 or B1/B2; a continuation/query policy π; and the initial persistent intervention a. These must not be collapsed into a single red or green ending.

G(ω,a) = Σ[t=1..H] γ^(t−1) (Y_t − λC_t − ζR_t)
V_s^π(a) = E^π[G(ω,a) | do(A_i^pers=a), s]
τ_s^π = V_s^π(keep) − V_s^π(archive)
Regret_s^π(a) = max_b V_s^π(b) − V_s^π(a)

The last line is binary commitment regret for a declared continuation policy and objective. A later gain may offset an earlier loss in G. That does not erase the earlier loss or make accumulated per-task regret decrease: the difference is between cumulative return and the sum of nonnegative regrets against a per-task oracle. The website computes return and a paired contrast; it does not silently substitute that oracle sum.

Read the finite teaching model.

Four complete task trajectories and three tasks make the expectation inspectable. The sliders set p(A), p(A1|A), p(B1|B), γ and H. The other child probability is its complement. The leaf weights sum to one. Every (Y,C,R) triple is disclosed in the payoff table. λ = ζ = 1; R is a declared task-risk penalty in this model, not the regret above. These are synthetic teaching constants, not benchmark results or clinical/financial utility estimates. They deliberately share a numerical pattern across domains to illustrate one mechanism.

This finite model holds exogenous task probabilities equal across the paired interventions; exposure, outcome and cost still differ. In the general theory, p(ω | do(a),s) can itself depend on a through state transitions, later observations and recovery. No interface can enumerate all real-world futures.

When the theorem applies.

Under one fixed objective, time and continuation policy, two states must have the same proposal score and opposite expected commitment contrasts with positive margins. A single unlucky path does not prove this premise. The page calculates conditional contrasts within A and B and explicitly reports when the sign conflict disappears.

The alternative query policy pays an inspection cost every task, recovers archived sources and filters unsuitable kept notes. It is intentionally allowed to succeed. This prevents a weak score-only control from standing in for every existing memory system.

Evidence changes the information state.

Probe and Resolve now branch into useful, inconclusive, wrong-scope and late observations. Defer branches into later evidence, continued silence and a missed window. Each branch is explicitly selected as a scripted observation, not generated by a live query. After a useful observation, per-world Keep/Archive/Defer choices reveal separate outcomes without editing the original commitment.

For the successful route, the replay assumes that a sufficient sign certificate for the declared authorization scope accompanies the evidence. A natural-language quote about validity is not a value certificate. Actual SQCAD requires audited closure bounds and a margin, as in the paper’s qualification theorem. An action against the assumed certificate is shown as an unsupported visitor choice, not authorized by SQCAD.

Source: the local paper’s “State, action, and commitment contrast”, “Irreducible score-fiber commitment error” and “Margin certificate for SQCAD authorization” sections. The research artifact makes no deployment or SOTA claim.

02 / REPLAY CONTRACT

The page is a scriptable evidence surface.

The browser replays a fixed explanatory fixture. Future continuations are rendered only after a visitor selects Keep or Archive; hidden-world text is never shown before the commitment step.

{
  "evidence_boundary": "illustrative replay",
  "gold_sent_to_model": false,
  "choice": "keep | archive",
  "future": "revealed after choice",
  "next_actions": ["resolve", "probe", "defer"]
}
Why defer matters. If a score fiber contains opposite lifecycle-value signs, a fixed commitment cannot be correct in every latent world. SQCAD exposes an evidence-seeking path before changing persistent authorization.

05 / CLAIM DISCIPLINE

What this artifact does not claim.

  • It is not a deployed memory product.
  • It is not a native reproduction of every baseline.
  • It does not expose evaluator labels or hidden benchmark files.
  • Displayed outcomes are scripted explanations, not new experimental measurements.

The research claim is about the information needed to authorize a persistent lifecycle action. Retrieval quality alone is not that authorization.
