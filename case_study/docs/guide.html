SQCAD / UNDER THE HOOD

Authorization is a decision,
not a relevance score.

A browser-readable companion to the visual case study. It explains the distinction between finding a memory, qualifying it, and allowing it to shape future tasks.

01source→qualification→authorization→access
01 / DECISION MODEL

Four questions, four different answers.

01

Proposal

Is this memory related to the current request?

relevance(x, q)
02

Qualification

Does the visible evidence support its scope, lineage, and current validity?

qualify(e)
03

Authorization

May this memory change the default exposure policy for future tasks?

authorize(q)
04

Access

Can this task inspect it temporarily without changing persistence?

probe(x)
02 / REPLAY CONTRACT

The page is a scriptable evidence surface.

The browser replays a fixed explanatory fixture. Future continuations are rendered only after a visitor selects Keep or Archive; hidden-world text is never shown before the commitment step.

{
  "evidence_boundary": "illustrative replay",
  "gold_sent_to_model": false,
  "choice": "keep | archive",
  "future": "revealed after choice",
  "next_actions": ["resolve", "probe"]
}
Why defer matters. If a score fiber contains opposite lifecycle-value signs, a fixed commitment cannot be correct in every latent world. SQCAD exposes an evidence-seeking path before changing persistent authorization.

04 / GODOT COMPANION

A second renderer, the same causal story.

The Godot project is a Steam-style companion surface for branch animation and replay pacing. The HTML page remains authoritative for text, evidence, and the state transition. Godot uses a deterministic local fixture and does not read evaluator-only labels.

HTML choice→Godot branch animation→HTML regret + inspector
05 / CLAIM DISCIPLINE

What this artifact does not claim.

  • It is not a deployed memory product.
  • It is not a native reproduction of every baseline.
  • It does not expose evaluator labels or hidden benchmark files.
  • Displayed outcomes are scripted explanations, not new experimental measurements.

The research claim is about the information needed to authorize a persistent lifecycle action. Retrieval quality alone is not that authorization.
