# SQCAD 文档分类索引：论文主体、证据、研究 gap 与历史草稿（2026-08-17）

> 用途：避免把“研究过程中有价值的 Markdown”误当作“应直接写进论文的正文”。本索引不删除、不改写历史文档；它只指定每类文档在老师汇报、论文写作和复现实验中的角色。当前完整实验方案的唯一入口仍是[23-SQCAD 完整实验方案](23-SQCAD完整实验方案-理论公开自建消融-20260817.md)。

## 1. 四类文档与使用规则

| 类别 | 定义 | 在老师汇报中的位置 | 在论文中的处理 |
|---|---|---|---|
| A. 论文主体 / 汇报必读 | 当前研究问题、方法、实验设计和可复核结论的主干 | 优先阅读 | 可直接压缩、改写为 Introduction、Method、Experiment、Discussion |
| B. 实验结果与可复现证据 | 运行结果、审计、数据卡、合同、代码对应关系 | 支撑 A 的每个数值与断言 | 转化为表、图、附录与 artifact 文档；不原样搬入正文 |
| C. research gap / 理论底稿 | 证明问题为何存在、何种主张可成立、何种路线被排除 | 被问“为什么不是检索/遗忘搬运”时引用 | 正文只保留定义、定理和关键反例；完整推导进附录/补充材料 |
| D. 历史草稿 / 知识库 / 路线探索 | 早期构想、文献卡、过渡实验、工作台账 | 一般不读；需要追溯时查 | 不进入论文正文；可作为内部写作素材或删除前的审计记录 |

### 3.2 仍有用但应降级为背景证据的实验报告

`docs/自用/03-实验证据链/00–04`、`09–15` 记录了早期 Gap、恢复、估计与理论数值佐证。它们对研究历程和反例审计有价值，但与 16–25 相比不是最新公开集/自建集主结果。论文中仅在需要说明一个特定命题的数值佐证时引用，不应让它们与当前主表并列（公开集数值一律以 25- 修复后主表为准）。

`docs/自用/02-历史草稿/实验报告/` 下的报告（包括 LongMemEval-S 初步检索、规则语义、最小模拟、OPE 校准等）是早期试验与诊断材料。除非其中某项有当前主线未覆盖的独特对照，否则不作为论文结果；若要重用，必须按 23 的冻结合同复跑并迁入 B 类证据链。
