# 30- ICLR2027 论文结构与叙事设计（2026-08-19）

> 用途：把 29-（0819 导师 Meeting 总结）的论证链与个人要求（理论空白验证入文、云 GPU 复现、框架改进优先于数学删减）落成一篇 ICLR2027 论文的**结构设计**。设计文档先行，初稿见 31-。
> 原则：论文以"persistent-access lifecycle value 的识别与授权"为唯一主线；理论证明为骨架，机制与实验全部回接定理；删减只发生在框架组件与实验，不删数学。

## 1. 一句话叙事（paper narrative）

> Agent 记忆治理的真正对象不是"检索到哪条证据"，而是"这条记忆是否应被长期授权访问"（persistent keep/archive）。现有方法使用关联、衰减、query-local 因果等信号，但本文构造性证明这些信号在信息论层面不足以决定持久动作（观测等价世界可给出相反生命周期价值；局部效应相同而长期价值相反），且无恢复提交在动作依赖的证据流下产生 Θ(T) 的自我遮蔽后悔（reduction-separation 证明其无法化约到标准 bandit/OPE）。由此提出 SQCAD：Evidence–Qualification–Access 三层框架，把"授权"建立在可审计的识别区间上——区间不跨零才授权，跨零则 defer/probe（Theorem 4/5 必要性）。公开轨迹上（L2）SQCAD 以 45× 更低的持久存储取得与检索基线可比的证据覆盖（Guard 修复一次性覆盖缺口）；自建反事实 LifecycleBench（L3）上，keep/archive 的长期价值被直接测量，并定位了 lineage 冲突与 hitchhiker 两条框架修改。

### R3. 框架不提升时的改进（不违反理论）
- 判断：L3 上现框架（certificate 规则）regret 1.258 落后 probe_willing 0.115；L2 上原 SQCAD 覆盖落后检索基线（Guard 已修复）。
- 改进路径（全部由定理导出，不新增机制）：
  1. **Thm 5 对齐**：把授权规则改为"L>0 → keep；U<0 → archive；跨零 → defer/probe（VOI 定价）"，而非"默认 keep"——直接修复 hitchhiker/未识别类盲提交；
  2. **lineage conflict → archive**（20- 已确认 +8.62 改善，进入框架）；
  3. **VOI probe 上 L3**：probe_willing 是"只 keep POSITIVE"，而理论要求的是"跨零时按 VOI 探测"——在 L3 上实现该变体应逼近 oracle 上界且保留成本诚实；
  4. L2 上候选 guard 作为最小修复配置（Guard-1 与 BM25 F1 持平）；
- 若理论对齐后仍落后：删减框架组件（candidate guard 变体 2/4、无关消融行），绝不删数学。
