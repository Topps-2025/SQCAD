## 1. 环境

与 33- §1 相同（AutoDL RTX 5090 32G, torch 2.8.0+cu128, python 3.12.3）。
本轮新增环境坑记录：

- **HF 网络挂起**：huggingface.co 在机房不可达（TCP 挂起，非拒绝），transformers `from_pretrained` 即使模型缓存完整也会去 hub 做 revision 检查 → 进程 0% CPU/0% GPU 无限挂起（本机第一次 0.6B 预计算 02:00 时 4 分钟完成，同一命令 16:00 起挂死 >1h）。修复：`HF_HUB_OFFLINE=1`（模型已全部在 `/root/.cache/huggingface/hub`，见 33- §5 的 modelscope 直链放置）。hf-mirror.com 可达（200，4.3s），可作备选。
- **无 PTY exec 的后台任务持有 SSH 通道**：`nohup ... &` 后接验证命令会导致本地 paramiko `out.read()` 永久阻塞（后台任务继承通道 stdin）。修复：`setsid nohup bash -c '...' </dev/null > log 2>&1 &`，随后**另开**会话轮询。
- **非交互 shell 不读 .bashrc**：任何 HF/镜像环境变量必须在启动命令里显式 export，不能依赖 .bashrc。

## 3. Wall-clock / FLOPs（闭合 31- Limitations (7)）

工具：`tools/contract_wallclock.py`（冻结合同路径逐 trace 计时 + Qwen3-Embedding 编码计时 + FLOPs 估算）。运行环境：云端 RTX 5090（与产生 tier-B 行的同机），LME-S 全部 500 trace。

| 行 | ms/trace（中位） | ms/QA（估） | 说明 |
|---|---|---|---|
| bm25 | 11.2 | 11.2 | 冻结 BM25 检索路径 |
| dense | 0.041 | 0.041 | 预计算 workspace 缓存读（预计算是离线一次性成本） |
| sqcad | 1.93 | 1.93 | 治理行决策路径（中位 1.93 / 均值 2.92） |
| sqcad_v2 | 335.8 | 335.8 | L3 全证书规则（单 trace 完整证书计算；L2 合同行不用它） |

嵌入编码（同一 32 文本批次，GPU 编码 + 同步）：

| 模型 | 参数量 | ms/query（中位） | FLOPs/query 估（2×n_params×512，前向） |
|---|---|---|---|
| Qwen3-Embedding-0.6B | 595.8M | 17.5 | 0.61 T |
| Qwen3-Embedding-8B | 7.57B | 22.3 | 7.75 T |

要点：① 治理行（sqcad）的决策成本 1.9 ms/trace 与 bm25（11.2 ms）同量级，显著低于任何生成式记忆系统；② dense 行把 0.6B/8B 编码当作**离线一次性预计算**（0.6B 17.5 ms/query、8B 22.3 ms/query），线上决策只是缓存读（0.04 ms）——与 17- D1/D2 的 dense 缓存约定一致；③ FLOPs 公式显式给出，不冒充精确测量。

- **零差异核对**：w1 与 33- sqcad_v2_probe 完全一致（0.8499/0.1294/0.8125/0.0725，CI [−0.0180, +27.4488] = 33- §3.2 的 +8.99 [−0.01, 27.48]）。

- 统计口径：bucket 配对（n≈14 rule-world 实例），CI 下界恰好为 0.0000 → 保守判为边缘不显著；效应方向（正值、值提升、后悔降低）三个 willingness 档位单调一致。

## 5. 同预算 streaming 基线（评审回应：storage-matched 基线升级）

工具：`tools/streaming_managed_baselines.py`（新 module；冻结合同零改动）。设计（预注册，无任何阈值调参）：

- **预算**：streaming 存储的 token 预算 = 治理行观测 store（冻结工件）：LME-S 1631 / LoCoMo 1646。
- **准入（严格在线，消息按时间序到达时）**：bm25_stream 用**在线 idf 自信息**（idf 由已见消息累积，无任何 look-ahead）；dense_stream 用 **Qwen3-Embedding-0.6B 在线 mean-cos**（与已见消息的平均余弦，`msg_sims` 预计算）；满则**替换最差**（并列取最旧），超预算单条不入库。
- **任务时**：workspace = 当前 store 上按冻结 scorer（bm25_scores / 缓存 query cos-sims）取 top-BUDGET；随后相关性反馈准入（多任务对话如 LoCoMo 的承重路径；单任务 trace 上为零操作）。
- **生命周期**：逐出→archives，重新准入→restores。
- **引用行**：同一冻结 runner 重算 sqcad / bm25（零差异核对）。
- **统计**：逐 trace 配对 studentized bootstrap（n_boot=2000，预注册种子 20260812/20260817，与冻结 significance 同例）。

### 5.1 LME-S（500 traces；本地冒烟与云端全量逐字段一致）

| 行 | hit | recall | tokens/QA | store tokens |
|---|---|---|---|---|
| sqcad（引用，零差异 ✓） | 0.7542 | 0.1149 | 2721.7 | 1631.2 |
| bm25（引用，零差异 ✓） | 0.9667 | 0.3232 | 1973.0 | 74092 |
| bm25_stream | 0.3625 | 0.0330 | 4758.6 | 5383.3 |
| dense_stream | 0.2292 | 0.0306 | 1089.2 | 1929.2 |

| 对比（− sqcad） | hit | recall | tokens |
|---|---|---|---|
| bm25_stream | −0.3917 [−0.4454, −0.3364] sig | −0.0819 [−0.0946, −0.0696] sig | +2036.9 [−1893.9..+2175.9] sig |
| dense_stream | −0.5250 [−0.5722, −0.4729] sig | −0.0842 [−0.0984, −0.0698] sig | −1632.6 [−1762.4, −1526.2] sig |

**两个同预算 streaming 管理器在命中率与召回上同时显著劣于治理行**（bm25_stream 还多付 1.9× workspace token；dense_stream 便宜但命中 0.229 最低）。机制：在线 idf 自信息偏好罕见/独特消息、在线 mean-cos 偏好"平均"消息，都偏离证据分布，把 ~50-100 条存储槽位填向噪声；查询时 store 内已无证据，top-12 无从补救。这正面回应评审"storage-matched 基线弱"的批评：**更强（分数驱动、同预算、严格在线）的 streaming 基线同样打不过 sqcad**。

### 5.2 LoCoMo（10 conversations；官方冻结评测器，SHA c37d0ab…）

| 行 | hit | recall | tokens/QA | store tokens | 官方 F1 | 官方 recall |
|---|---|---|---|---|---|---|
| sqcad（引用，零差异 ✓） | 0.2122 | 0.1899 | 348.2 | 329.9 | **0.0339** | 0.1901 |
| bm25（引用，零差异 ✓） | 0.5717 | 0.5294 | 281.8 | 13343.8 | 0.0454 | 0.5296 |
| bm25_stream | 0.3302 | 0.2937 | 555.1 | 3577.5 | 0.0333 | 0.2892 |
| dense_stream | 0.0959 | 0.0728 | 305.6 | 1978.4 | 0.0179 | 0.0706 |

| 对比（− sqcad） | hit | recall | tokens |
|---|---|---|---|
| bm25_stream | **+0.1180 [+0.0547, +0.1430] sig** | **+0.1038 [+0.0442, +0.1255] sig** | +206.9 [+176.1, +243.3] sig |
| dense_stream | −0.1163 [−0.1462, −0.0876] sig | −0.1172 [−0.1435, −0.0883] sig | −42.6 [−67.3, −12.3] sig |

- **多任务对话上 bm25_stream 的覆盖显著反超治理行**（相关性反馈准入在 LoCoMo 是承重路径），但官方 F1 0.0333 vs sqcad 0.0339——覆盖优势**没有转化为**抽取式读者上的 QA 得分（10 单位内无差异，差 0.0006），且多付 +59% exposure。
- dense_stream 全面崩溃（F1 0.0179）：在线 mean-cos 显著性在多任务长对话上把存储槽位填给"平均消息"。
- 净结论：治理行（证书准入 + 证据评分逐出）在同预算 streaming 控制面前保持其质量–存储–暴露位置；更强控制不改变任何主表结论。

## 6. 复现命令（云端）

```bash
# 1) 带 msg_sims 的 dense scores（0.6B，两数据集；须 HF_HUB_OFFLINE=1）
python tools/precompute_dense_qwen.py --dataset longmemeval_s --data datasets/longmemeval_s_cleaned.json \
    --model Qwen/Qwen3-Embedding-0.6B --out results/cache_tmp_lme.json \
    --scores-out results/dense_scores_0.6B_lme.json
python tools/precompute_dense_qwen.py --dataset locomo --data datasets/locomo10.json \
    --model Qwen/Qwen3-Embedding-0.6B --out results/cache_tmp_locomo.json \
    --scores-out results/dense_scores_0.6B_locomo.json

# 2) streaming 基线全量
python tools/streaming_managed_baselines.py \
    --longmemeval datasets/longmemeval_s_cleaned.json --locomo datasets/locomo10.json \
    --dense-scores-lme results/dense_scores_0.6B_lme.json \
    --dense-scores-locomo results/dense_scores_0.6B_locomo.json \
    --qa-out-dir results/locomo_qa_stream \
    --out remote_results/lifecycle_audit/streaming_managed_baselines.json

# 3) LoCoMo 官方 F1（冻结上游评测器）
python tools/run_locomo_official_scorer_portable.py \
    --eval-file datasets/locomo_eval/evaluation.py \
    --pred-dir results/locomo_qa_stream/locomo \
    --out results/locomo_official_qa_stream.json

# 4) wall-clock / FLOPs
python tools/contract_wallclock.py --longmemeval datasets/longmemeval_s_cleaned.json \
    --dense-cache results/dense_cache_0.6B.json \
    --out remote_results/lifecycle_audit/contract_wallclock.json

# 5) L3 愿意度扫描
python tools/l3_voi_willingness_scan.py --out remote_results/lifecycle_audit/l3_voi_willingness_scan.json
```
