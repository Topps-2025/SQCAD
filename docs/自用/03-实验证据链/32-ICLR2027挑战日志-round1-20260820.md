## 2. 关键发现（按严重度，★=三个审稿人独立命中）

### 2.1 CRITICAL ★★☆

1. **L3 统计单元虚构（experiments #1，theory 呼应）**：1,380 episodes 中 13/14 个 rule-world bucket 只有 1 个不同 value（本报告已用冻结 JSON 验证：`hitchhiker/default` 2 个，其余各 1）；episode 级 paired bootstrap（n=1380）将精度虚增 ~10×，"sig" 全部失效。**修复**：新增 bucket-level bootstrap（n≈14），31- §5.3 改用诚实单元重报；见 §3.1。
2. **L2 评估的是论文自己证明退化了的规则（experiments #2）**：L2 的 sqcad 行是修复前的 event-rule 资格判定；被提议的 Thm-5 规则（sqcad_v2）没有任何公共数据结果 → 外部有效性不可声明。**修复**：在冻结公共合同上实现 v2 规则并补行（新模块 public_v2_rule.py，冻结代码零改动）；见 §3.2。
3. **sqcad_v2 ≡ probe_willing 是"换名的基线"（theory #F2，novelty #3）**：框架的最佳 L3 数值由 3 行基线产生；框架特有机制（VOI probe/restore/lineage）在自测中全部 ≤0。**修复**：宣布 Thm-5 决策规则**就是** SQCAD 的 Qualification 规则（方法行），probe_willing 等价性降格为 sanity check，audit 层为可测量新增；"两个框架修订"的措辞降格。见 §3.1、§3.4。

### 2.2 CRITICAL（theory 独有，算术/定义硬伤）

4. **Thm-5 验证实例算术不一致（F5）**：(L,U)=(500,1650) 时 L>0 无 straddle，"commit-archive regret 500 / C_probe<330" 无定义；330=660/2 表明两个实例被合并。误差下界 "attained at p*=0.4" 错（误差在 p=0.5 取到，p*=0.4 是 regret 极小点）。**修复**：改用 straddling 实例 (L,U)=(−1650,1100)：R*=660，p*=0.4；误差/regret 极小点分开陈述；§5.1 补穷举验证（§3.3）。
5. **T1(b) probe 成本项算术错（F10）**：E[probes]=1/ρ（与 q 无关），非 1/(qρ)；"更小 q 花费更多 probe 支出" 错误——小 q 延长的是 wrong-state 损失。Cor 3 / §3.7 同款修正。
6. **T2 分离定理是定义工程（F1）**：faithful 定义保留全部信息 → 定理是同语反复；"唯一逃逸是新状态"（Cor 2）未证。**修复**：重述为诚实的 lemma（faithful 归约保持极小极大 regret 率），标准 bandit/OPE 框架的"不忠实"在于假设逐步损失可观测；Cor 2 降级为猜想。
7. **摘要因果句错（F4）**：Θ(T) 界对任何 committing policy 成立（与 censor 无关）；censor 阻断的是非 committing 恢复（T1(b)/(c)）。"self-obscuring because the action censors" 归因错误。
