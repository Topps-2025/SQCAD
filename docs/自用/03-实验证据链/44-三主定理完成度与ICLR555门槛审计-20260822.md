# 理论闭环完成度与 ICLR 5/5/5 门槛审计（2026-08-22）

## 1. 审计结论

三条基础定理与架构无关总括定理的数学骨架已完成，旧 Theorem 5 以后不断追加 certificate 条件的路线已经退出主叙事。当前可以声称的是：在明确的有限时域、可测 kernel、belief update、standard-Borel、Blackwell/transcript-KL，以及 G4 的 score-visible immediate cost、$0<\gamma\le1$、regular quotient 和 uniformly bounded separating utility 合同下，G1--G4 的结论成立。当前不能声称的是：真实 LLM Agent 已落入 future-lossy 分支、自然任务必然分离 kernel，或者理论部分已经通过独立 ICLR 复核。

因此目标状态为：

| 层级 | 当前判定 |
|---|---|
| G1--G4 条件化数学闭环 | 已达到 |
| Agent-specific 架构无关陈述 | 已形式化为穷尽三分；真实系统分支定位未达到 |
| Lifecycle sufficient statistic | $T_{\rm LC}^*$ 与 $\varepsilon_{\rm LC}$ 已定义并证明最小性/近似 regret 关系 |
| 内部 theorem regression | 32 项专项测试通过；不能替代证明与外部复核 |
| ICLR 理论 solid 5 | 接近但未证实 |
| 整篇论文 5/5/5 | 未达到 |

### 数学证明是否需要真实 Agent 轨迹

不需要用真实轨迹完成 G1--G4 的逻辑证明。定理在其明示的 standard-Borel、有限时域、kernel、Blackwell、transcript-law 或 separating-utility 合同下成立；真实数据不能把一个错误证明变正确，也不应成为证明步骤。

真实 Agent 数据验证的是另一件事：实现系统处于 G4 的哪个分支，以及 Agent-specific 机制是否非退化。具体包括 keep/archive 是否实际改变 candidate/workspace/evidence kernels、自然任务是否分离这些变化、baseline score fiber 内的 $\varepsilon_{\rm LC}$ 和 opposite-sign frequency、archive/defer 分支是否低 KL、probe/restore 是否以可测成本重新打开信息通道。若系统全部 future-null 或现有 score 已 lifecycle-complete，数学三分仍成立，但论文针对现有工作的强 research-gap claim 会失去经验支撑。

## 2. Requirement-by-requirement evidence

### R1 Lifecycle Bellman Decomposition

**要求。** persistent action value 分解为 immediate、future access/state 和 future information/recoverability；interval minimax、probe/defer 和 recovery certificate 退为特殊情形。

**权威证据。** `19-Agent-Lifecycle-Belief-Control-一般理论-20260822.md` 定理 A、推论 A.1；`42-ICLR2027-General-Theory-Section-Draft-20260822.md` Theorem 1；主稿 §3.2、§3.5 与 Appendix A；`lifecycle_belief_theory.lifecycle_contrast`。

**判定。** 已证明。三项分账依赖 canonical Agent filtration；只有总 continuation 与总 lifecycle contrast 对 state/observation 的表示移动不变。Bellman/tower-property 不是原创。

### R2 Score Sufficiency iff measurability

**要求。** 固定任务的最优动作由 score 决定 iff 动作区域对 score 可测；所有 cost shifts 下充分 iff lifecycle contrast 因子化为 score 的可测函数。

**权威证据。** 理论底稿定理 B；英文 Theorem 2；standard-Borel saturated-set/Lusin separation 与 rational-level-set/Doob--Dynkin 证明；fiber minimax 与 least-favorable prior。

**判定。** 已证明。零宽度 tie fiber 已单独处理，避免 `0/0`；近似充分性要求 fiber endpoints 有限且可测。

### R3 Agent-specific horizon-wide score condition

**要求。** 将 observation、candidate/state、budget competition 和 belief continuation 条件写成 Agent kernel 的一般条件，而不是把四条分别冒充固定任务下的逻辑必要条件。

**权威证据。** 命题 B.2a / Proposition 2.2：逐时刻 quotient maps、reward factorization、controlled belief-kernel push-forward equality 和 backward induction；universal converse 使用 Borel indicator payoff。`finite_score_quotient_violations` 提供有限模型 audit。

**判定。** 数学条件已形式化。它是一般 control homomorphism/lumpability 的 Agent-memory specialization，不是新的一般 MDP 定理。真实 Agent 是否满足该 quotient contract 尚无证据。

### R4 Same-score opposite persistent actions

**要求。** archive censoring、keep crowding 或其他未编码 future-kernel 差异能够产生相同 score、相反最优动作，而不只给一个手工数值反例。

**权威证据。** 推论 B.2b / Corollary 2.3：若同 fiber 状态的 signed keep--archive quotient kernels 能被该 Agent 任务类中至少一个可实现 continuation value 分离，则该 value 加共同 midpoint immediate offset 产生严格相反 contrasts。只有当 model class 对所有 bounded measurable quotient terminal payoffs 闭合时，kernel 不同本身才由 Borel indicator separation 推出该条件；若 kernel 差异与全部可实现 value 正交，则它们对该任务类 decision-equivalent。定理 C 是固定任务版本；explicit binary witness 是可读实例；`value_separating_signed_kernel_contrasts` 是有限回归检查。

**判定。** 相对于 admissible continuation-value class 的 model-class existence theorem 已证明。对某个固定真实 reward/cost contract 是否能感知 kernel 差异、以及是否已经跨零，仍需 paired intervention，不能由裸 kernel inequality 或 existence theorem 推出。

### R5 Value of Recoverability / Information

**要求。** 给出用户指定的 continuation-value difference，并在 archive experiment 被 Blackwell 支配且未来不确定性具有决策价值时证明严格正 option value。

**权威证据。** 理论底稿定理 D(a)、英文 Theorem 3(a)。一般量定义为

$$
\operatorname{VoR}^{\mathrm{cont}}_{t,K:A}=\gamma(C_t^K-C_t^A),
$$

共同 next-state kernel 下的条件信息量定义为

$$
\operatorname{VoR}^{\mathrm{info}}_{t,K:A}=\gamma(I_t^K-I_t^A).
$$

共同 state kernel、conditional Blackwell dominance、belief-value convexity给出非负；正概率 strict conditional Jensen gap 和 $\gamma>0$ 给出严格正。

**判定。** 已证明并修正了记号歧义。`VoR^cont` 在 access/crowding kernel 不同时不保证非负；只有 `VoR^info` 被 Blackwell 定号。仅有 posterior uncertainty 不够，必须存在 continuation-policy relevance/strict Jensen gap。

### R6 Adaptive recoverability information budget

**要求。** 从固定 restore certificate 推进到任意 adaptive authorization policy 的一般信息必要性。

**权威证据。** 定理 D(b) / Theorem 3(b)：augmented stopping transcript $T_\tau=(Y_\tau,D)$、统一 branchwise gaps、Bretagnolle--Huber、adaptive KL chain rule、absorbing padding、per-action KL ledger 与 inversion bound。终端 decision kernel 在两世界相同，故其 conditional KL 为零且事件 `{D=A}` 可测。

**判定。** 条件化证明已闭合。下界针对 terminal authorization action regret，不自动包含之前支付的 probe/defer 成本；要声称 total policy regret，必须另加成本 ledger。真实 archived branch 是否为零 KL 尚未测量。

### R6b Priced recoverability frontier

**要求。** 把“需要信息”推进为“信息不是免费的”：当只有付费 probe/restore/exposure 能重新打开区分通道时，同时下界诊断成本和错误授权损失。

**权威证据。** 推论 D.3 / Corollary 3.1 与 proof appendix Corollary A.3.1。令 $\alpha=d_+d_-/[2(d_++d_-)]$；若 channel-opening action 每次最多提供 $\kappa$ KL、至少成本 $c$，则最坏总授权损失至少为

$$
\frac{c}{\kappa}W_0\!\left(\frac{\kappa\alpha}{c}\right).
$$

`priced_recoverability_regret_floor` 与新增专项测试提供有限数值回归。

**判定。** 数学推论已闭合，且直接表达 Agent-specific no-free-recovery；Lambert-$W$ 优化不是原创。它仍要求真实实验估计每类 channel-opening action 的 conditional KL cap 与实际成本，不能用动作名称预设参数。

### R7 Probe/defer and old Theorem 5--13 as subclasses

**要求。** interval minimax、probe/defer 和 recovery certificates 不再作为并列主理论。

**权威证据。** 推论 A.1、D.2；主稿 §3.5；Appendix A 的 Construction/Proposition/Corollary 编号；claim--evidence matrix A1--A10。

**判定。** 已完成叙事与编号迁移。Gaussian/sub-Gaussian、fixed-threshold 和 archived-committed results 仍严格保留为 contract subclasses。

### R8 Agent specificity and novelty

**要求。** 证明问题不是一般 POMDP 工具换名，而是由 Agent 的持久授权结构产生。

**权威证据。** `20-三主定理Prior-Art与Novelty边界-20260822.md`；process definition 中的 persistence、candidate regeneration、workspace competition、scope/version、recoverability；dynamic quotient 与 signed-kernel theorem。

**判定。** 形式化差异已建立；经验差异尚未建立。若真实系统中 keep/archive 不改变这些 kernels，项目会退化为一般 retrieval/control reformulation。

### R9 Architecture-agnostic trichotomy and lifecycle sufficient statistic

**要求。** 不依赖 external/retrieval/prompt/cache/adapter 等具体实现，穷尽 future-null、lifecycle-complete 与 future-lossy；把第三分支的遗漏 kernel 转成严格 regret witness，并导出后续框架应估计的最小对象。

**权威证据。** 理论底稿定理 E/定义 7；主稿 Theorem 4；proof appendix Theorem A.4/Definition A.4.2；`finite_lifecycle_trichotomy`、`task_universal_shifted_regret` 与 32 项专项测试。

**判定。** 条件化证明闭合。三分穷尽且互斥；即时 contrast 已显式要求 score-visible；$0<\gamma\le1$ 排除零折扣伪正下界；utility class 统一有界、包含零并具有分离性；midpoint shift 只证明 cost-uniform failure，fixed-cost failure 另需原 contrasts 异号；task drift 不是必要条件；参数化记忆仅在存在可操作 retain/suppress/update intervention 时覆盖。$T_{\rm LC}^*$ 的最小性严格限定为 partition order；实现 standard-Borel controller state 另需 smooth quotient/可数 determining family。$\varepsilon_{\rm LC}/4$ 是逐任务、逐成本的 fiber-wise minimax 界，且不支持“标量维数天然不足”的主张。

## 3. 尚未关闭的 ICLR solid-5 gates

1. **External proof audit:** 独立复核 standard-Borel factorization、dynamic quotient converse、admissible-value signed-kernel separation、Blackwell strictness、augmented stopping transcript、weighted BH 下界和 priced frontier。
2. **Transition/observation audit:** forced keep/archive 下测量 candidate exposure、workspace、scope/version、evidence generation 和 restore state。
3. **Score-fiber audit:** 在真实 baseline score bins 内估计 lifecycle contrast，报告 fiber width 与 opposite-sign frequency。
4. **Per-action KL audit:** 对 exposure/probe/restore 和 archived/defer 分支估计 conditional KL；不能预设 archive 为零信息。
5. **Recoverability intervention:** 固定 immediate 与 access/crowding 项，单独改变 observation experiment，估计 `VoR^info`；另行报告 `VoR^cont`。
6. **Prior-art completion:** 对 Agent memory、controlled sensing、MDP homomorphism/lumpability 做完整检索，避免把标准 quotient result 包装成原创。
7. **Claim consistency:** 摘要、正文、附录、图、表和代码注释必须始终区分 fixed-task iff、universal model-class converse、conditional information value 与 total action value。
8. **Trichotomy applicability:** 在多个真实 Agent memory implementations 上定位 future-null/lifecycle-complete/future-lossy，并用自然 task utility 估计 $T_{\rm LC}^*$ 的可实现近似和 $\varepsilon_{\rm LC}$。
