## 3. 修掉的矛盾：GovMem 的等级

- 正文 §5.2：「GovMem is write-time and not transportable to the current access-time contract」→ 语义是 D 栏。
- Appendix D 原表：C 栏「no official implementation … paper-rule behavior proxies」。

两处冲突。**判定按机制而非按有无代码**：GovMem 的动作是 promote/reject/needs-review 的**写入路径**门控，它没有一个 access-time authorization 决策可以移植到本文合同下——这是 D 栏（not transportable）的定义，与「有没有官方实现」无关。FadeMem 同理（video diffusion-KV 域，需 Wan2.1 权重），SAGE 同理（write-time novelty gate）。故：

- C 栏收缩为 Memory Worth / DeMem / Trivium（确实是「无官方实现、按论文规则做行为代理」）。
- D 栏扩为 GovMem / FadeMem / SAGE / GateMem / MemAudit / ReMe，并写明各自不可移植的**机制原因**，而不是只贴标签。
- 另加约束：GovMem 在附录中仅以「access-time coverage control (not GovMem)」保留，**永不以其系统名出现在结果行**——这正是导师 §3.3「不要为了凑基线而强行塞入主表」的要求。
