# ICLR 2027 一般理论严格三审（2026-08-22）

> **Post-audit correction.** The manuscript now distinguishes the general continuation difference `VoR^cont` (not sign-definite under action-dependent state kernels) from the conditional `VoR^info` signed by Blackwell/Jensen. Proposition 2.2 supplies a dynamic score-quotient route and limits its converse to universal action-value factorization, avoiding a claim that fixed-task score optimality identifies the full transition kernel.

> **Final theory-round correction.** Theorem 4 now adds an architecture-agnostic future-null / lifecycle-complete / future-lossy trichotomy and the minimal estimand $T_{\rm LC}^*$. The audit explicitly requires score-visible immediate cost, $0<\gamma\le1$, a regular quotient, and a uniformly bounded separating utility class containing zero. Midpoint shifting establishes cost-uniform failure, not fixed-cost failure unless the original contrasts already cross zero.

- **Assessment boundary:** 这是 ICLR 风格的技术预审，不是最终录用判断。结论只覆盖当前文本和已存在工件；没有把 toy witness、代理基线或离线引用解析升级为真实 Agent 证据。
- **Shared manuscript claim summary:** 持久 Agent 授权会改变未来 candidate、workspace、scope/version 与 evidence/recoverability kernel。G1 将 keep--archive value 分成 immediate/access/conditional-information 三项；G2 给出 score-only governance 的可测充要条件和 score-fiber regret；G3 给出 recoverability 的条件价值与 transcript-KL 必要性；G4 对所有 intervention-defined memory implementations 给出三分，并把后续框架目标收束到 $T_{\rm LC}^*$ 或 $\varepsilon_{\rm LC}$。

- **Missing materials affecting confidence:** 真实 Agent 的 forced-keep/forced-archive transition audit、score-fiber 内的 lifecycle contrast 异质性、逐动作 conditional KL、recoverability intervention、held-out certificate calibration、至少一个具名强基线完整质量行，以及外部数学复核。

## Reviewer 1

- **Overall assessment:** 理论主线已经从受限定理堆叠重构为三条基础命题和一个架构无关总括定理。G4 的三分逻辑、kernel separation、cost-shift witness 与最小 statistic 在明示条件下闭合；技术风险已从“继续补 lemma”转为外部 proof audit 和真实系统在三分中的位置。
- **Who would be interested in the results, and why:** 研究 sequential decision、POMDP/controlled sensing、agent memory 和 safe authorization 的读者会关心，因为论文把持久授权导致的 future-kernel 变化和证据删失写入同一 action-value 对比。
- **Major strengths:** G1 的 canonical filtration 明确区分 access 与 conditional information；G2 把 score sufficiency 从经验相关性改成可证伪的 sigma-measurability/fiber 条件；G3(b) 不再把旧 restore 上界外推到任意 policy，而是对包含 actions、randomized stopping、terminal decision 与 absorbing padding 的 transcript 明确计 KL；priced frontier 将 KL 必要性和恢复成本合并为 no-free-recovery 推论。
- **Major concerns:** G1 本身是 Bellman/tower-property accounting identity，不能作为独立原创数学突破。G2 的可测性证明依赖 standard Borel 和 saturated-set 分离。G3(a) 只给 information 项符号，G3(b) 只下界 terminal authorization regret。G4 的穷尽性本身是逻辑二分，贡献必须落在 intervention-defined transcript kernel、治理后果和 estimand 上；正文不得省略 $\gamma>0$、utility normalization 或 regular quotient。
- **Technical failings that need to be addressed before the case is established:** (1) 对 stopping-time transcript 的 sigma-field、吸收补齐和绝对连续性给出统一定义；(2) 逐动作 KL ledger 必须验证“其余动作 conditional KL 为零”的假设；(3) 证明 (d_+,d_-) 是所有正概率错误分支上的统一下界；(4) 用真实配对 rollout 检查 archive 是否真的删失 distinguishing event；(5) 外部数学复核 G3(b) 的 Bretagnolle--Huber 加权最小化与 adaptive chain rule。
- **Assessment against Nature-style criteria:** **Originality:** Agent-specific kernel/censoring ledger 有潜在新意，但标准 Bellman、Doob--Dynkin、Blackwell、BH 与 KL 工具不应计作原创。**Scientific importance:** 对持久 memory authorization 的形式化有领域重要性；“outstanding”程度取决于真实 Agent 机制证据。**Interdisciplinary readership:** sequential decision、ML systems 与 trustworthy agents 读者可能感兴趣。**Technical soundness:** 条件化证明基本成立，实证合同尚未建立。**Readability for nonspecialists:** 三定理主线清楚，但需在正文用一个 lifecycle diagram 解释 score fiber、future kernel 和 KL channel。
- **Recommendation posture:** 理论部分在补齐合同审计和独立复核后具有较强说服力；当前不能把 G1--G3 作为无条件真实 Agent 定理。

## Reviewer 2

- **Overall assessment:** 最可信的贡献是把现有 memory score 的缺口重新表述为 lifecycle-value identification，而不是声称提出新的信息论不等式。G2 的“当前阈值充分性 vs 所有 cost shift 的值充分性”区分很有用；G3(b) 的 novelty 主要在 action-dependent Agent transcript 的 operational ledger。
- **Who would be interested in the results, and why:** 研究 memory compression、decision-centric retrieval、active information acquisition 和 uncertainty-aware agent control 的读者会关注，因为同一 score fiber 内的未来 kernel 差异可直接转成 regret。
- **Major strengths:** 主稿已明确承认 DeMem、controlled-sensing POMDP、Blackwell/Jensen、measure separation 和 adaptive KL chain rule 的先验地位；G4 不再尝试证明“所有 Agent 必然失败”，而是保留 future-null 与 lifecycle-complete 分支；$T_{\rm LC}^*$ 把理论缺口转成后续框架的明确 estimand。
- **Major concerns:** novelty 仍可能被评为“标准工具的新包装”，除非论文展示真实 Agent 中 keep/archive 改变 candidate/workspace/evidence kernels，这些变化能被实际任务 utility 感知，并且不被已有 score 吸收。裸 kernel inequality 不足以推出自然任务或 fixed-cost action difference；G4 的 midpoint shift 只否定对所有成本统一充分的 score claim。
- **Technical failings that need to be addressed before the case is established:** (1) 做系统 prior-art matrix，逐项比较已有 agent memory 是否已有 lifecycle belief-control formulation；(2) 报告真实 score fibers 的宽度、跨 fiber action gap 与 same-score opposite-action 频率；(3) 报告每类 exposure/probe/restore 动作的 conditional KL 及置信区间；(4) 做 recoverability intervention，固定 immediate/access cost 后单独估计 conditional information value；(5) 删除任何把 offline citation parsing 写成 online verification 的措辞。
- **Assessment against Nature-style criteria:** **Originality:** Agent-specific estimand 和 censoring/KL ledger 有可辩护的新意，标准数学组件没有。**Scientific importance:** 若能证明 persistent authorization 的信息预算必要性对多个 Agent kernel 普遍适用，重要性会显著提高；当前仍是 promising framework。**Interdisciplinary readership:** 与 active sensing、causal decision making、agent systems 有交叉。**Technical soundness:** 证明边界透明，但实证 novelty gate 未关闭。**Readability for nonspecialists:** “score 不等于 lifecycle value”的主旨可理解，术语表和图示仍需压缩。
- **Recommendation posture:** 原创性有潜力但尚未由真实机制证据锁定；支持条件是完成 prior-art、kernel audit 和干预实验。

## Reviewer 3

- **Overall assessment:** 叙事已经形成一条比旧 theorem patchwork 更强的线：persistent action 改变未来证据，score sufficiency 需要保留 lifecycle contrast，recoverability 需要付出可量化信息预算。主要问题是读者容易把条件性结果误解为“keep 总是更好”或“所有 agent 都满足删失”。
- **Who would be interested in the results, and why:** 广义 agent、memory systems、safe AI 和 sequential decision 读者会关心；他们可以把 recoverability 看成带价格的 future experiment，而不是事后工程补丁。
- **Major strengths:** 三条基础定理和一个总括定理的角色分工清楚；明确写出 access 与 information 不能偷换；G4 把 task drift 降为扩大 challenge class 的条件，而不是失败的必要前提；主稿已披露 L3 restore 净负，避免把机制结果包装成全面胜利。
- **Major concerns:** G1--G3 的符号密度和“belief / score / fiber / kernel / transcript”术语会阻碍非理论读者。G3(b) 中 (R_\tau) 若不强调是 terminal authorization regret，读者会误读为全 horizon regret。公开数据目前只支持 trade-off，不支持端到端 SOTA 或真实 lifecycle benefit。
- **Technical failings that need to be addressed before the case is established:** (1) 主文加入一个从 state、action、observation 到 stopping transcript 的示意图；(2) 在 theorem statement 旁边列出“proved / needs evidence / not claimed”；(3) 将旧 Theorem 1--13 全部改成 Appendix construction/corollary 标签；(4) 对真实 LLM trace 报告 candidate exposure、workspace occupancy、scope/version 和 restore rate 的 paired audit；(5) 对 certificate 只写 contract-conditional，不写 raw-LLM coverage。
- **Assessment against Nature-style criteria:** **Originality:** 视 Agent-specific evidence 而定。**Scientific importance:** 对 agent memory governance 有直接意义，但目前尚未证明跨任务的远-reaching impact。**Interdisciplinary readership:** 概念上较强，图示和摘要需要降低进入门槛。**Technical soundness:** 数学范围透明，系统证据仍不完整。**Readability for nonspecialists:** 当前理论草稿可读性中等，需减少标准工具细节并突出一个反例和一个信息预算例子。
- **Recommendation posture:** 叙事方向正确且可形成 strong proof，但在读者可理解性和外部机制证据补齐前，整体论证尚未完全建立。

## Cross-review synthesis

- **Consensus strengths:** G1--G4 已形成条件化数学闭环；三分保留 future-null 反例边界，utility normalization 使 $\varepsilon_{\rm LC}$ 定义良好；贡献边界诚实承认标准数学工具；Agent-specific 增量集中在 persistent intervention、future-kernel censoring、score-fiber regret、priced transcript KL 与 lifecycle estimand。
- **Consensus technical risks:** 尚无独立数学审稿来排除隐藏的 standard-Borel、stopping-time 或最小性漏洞；真实 Agent 是否处于 non-null 分支、自然 utility 是否分离 kernel、现有 score 的 $\varepsilon_{\rm LC}$ 是否显著，均未由真实轨迹测量；toy/controlled witness 不能外推为部署定理。
- **Where emphasis differs across reviewers:** Reviewer 1 主要要求独立数学复核和 stopping/transcript 定义；Reviewer 2 主要要求 novelty 的 prior-art 与真实机制证据；Reviewer 3 主要要求术语、图示和 claim-scope 的读者可辨识性。
- **Broad-interest / significance readout:** 对 agent memory 与 sequential control 社群有明确兴趣，对更广泛 ICLR 读者的吸引力取决于能否证明该信息预算现象在多个真实 Agent kernel 中反复出现，而不是只在规则世界出现。
- **Most important issues to resolve before a strong ICLR case is established:** 由独立研究者复核 G2 的 standard-Borel 论证、G3 的 BH/KL 推导和 G4 的 quotient/minimality；在真实框架上完成 transition/observation、score-fiber $\varepsilon_{\rm LC}$、utility separation、per-action KL 和 recoverability intervention；完成至少一个具名强基线完整质量行。主稿、附录、claim matrix 和评分文档已在本轮同步 G4。

## Risk / unsupported claims

- “G1 发明 Bellman decomposition”“G2 发明 Doob--Dynkin”“G3 发明 Blackwell/BH/KL inequality”均不支持。
- “G4 发明 measure separation/quotient/no-free-lunch”“所有 LLM Agent 或自然任务必然失败”均不支持。
- “所有 scalar retrieval scores 都失效”“keep 一般优于 archive”“recoverability 总是有正总价值”均不支持。
- 真实 LLM traces 满足 common-state Blackwell contract、future-kernel-rich 条件或零-KL archived branch，当前不可评估。
- LifecycleBench 的受控机制结果不能写成公开数据泛化、部署收益或端到端 SOTA。
- L2 metric CI、toy certificate coverage 和离线 BibTeX parsing 不等于 lifecycle certificate coverage、在线文献验证或真实 Agent external validity。
