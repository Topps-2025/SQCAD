**Oracle/估计器一致性**（评述要求）：oracle 与估计器调用**同一** `sample_rollout`（同一 $H$、同一 $\gamma$、同一动作窗口），RNG 流独立（seed+1 vs seed+5）。Stage 2 中 oracle 始终评估**预注册 estimand**；漂移/采纳误差/选择只影响估计器侧，从而表现为估计偏差。

## 1. 世界与公平性

- 12 个记忆：3 useful（+1.2/暴露）、2 short_term（局部 +0.2，但保持它会以 $0.15^{n}$ 抑制 bridge 暴露 → 生命周期为负）、2 bridge（局部 +0.2 + rare/critical 状态加成 +1.5）、2 harmful（−1.0）、3 neutral（0，不可识别）。
- $\gamma=0.98$，$H=150$ 步，每（记忆 $\times$ 动作）$n=100$ 条轨迹；oracle $n=300$。
- **观测日志含平台探索（probe）**：状态保持策略 archive 的候选以 $p=0.2$ 被探测曝光（影子部署/A-B probe 的常规设定）——否则观测方法对 archived 记忆零数据，"失败"会是数据真空假象而非 estimand 失配（本轮修复，见 §4.3）。
- 基线全部使用其规范估计器且（在构造内）无偏：association = Beta 后验成功概率；CMI/naive OPE = $\mathbb{E}[Y \mid E=1] - \mathbb{E}[Y \mid E=0]$（暴露随机化 → 逐局部无偏）。

## 3. Stage 2：逐条件违反（验证 Theorem 3(d) + gate）

| violation | 失败的条件 | gate 行为 | 强制决策（盲于 gate） | 数值要点 |
|---|---|---|---|---|
| adoption | C6：$D \ne E$（误记率 0.3） | **12 unresolved**（全部弃权，err=0.000） | regret 0.42, err 0.167 | 协议内 RCT 不依赖 $D$、仍无偏；但部署侧无法验证干预落地 → 保守弃权 |
| co_exposure | C7：bundle 不可分（$\mathbb{E}[h] = \mathbb{E}[u]$，corr $= 1.00$） | **pair m0/m7 unresolved**（err=0.000） | regret **41.0**, err 0.083 | bundle 值 +9.0（真值 +8.1）：+48 的 useful 掩盖 −41 的 harmful；强制个体归因 keep both |
| eligibility | C3：harmful 记忆永不获得随机化证据 | **5 unresolved**（m7/m8 + 3 neutral，err=0.000） | regret **83.4**, err 0.333 | 强制默认 keep 无证据记忆 → 保留 harmful |
| drift | C8：版本中途漂移（+2.0/暴露/步） | **12 mismatch**（版本层 $z = 147.6 \gg 3$，err=0.000） | regret 2.2, err 0.083 | 漂移偏差方向是机制依赖的（keep short_term 抑制 bridge 暴露 → 加成偏向 archive 侧），不可先验预测 → mismatch 是唯一诚实输出 |
| scope | Cor 1：target 在 source 支持外 | **12 mismatch**（err=0.000） | regret 0.96, err 0.083 | 结构检查：source 证据对 target 决策不可运输 |

**gate 消融结论**：五种违反下门控全部弃权（12/12 或 5/12 或 pair），**自信错误恒为 0**；强制变体在 co_exposure（41.0）和 eligibility（83.4）上付出结构性代价。弃权不是免费的——adoption 下弃权放弃全部价值（gated regret 192），co_exposure 下弃权放弃 m0 的 48；但这是识别失败时诚实输出（unresolved/mismatch）的固有成本，框架的承诺是"绝不做自信错误决策"，而非"弃权永远零损失"。

## 4. 本轮修正（使实验对自身公平的构造缺陷）

| # | 缺陷 | 后果 | 修正 |
|---|---|---|---|
| 1 | `_stability_z` 用**折扣后半效用**比较 h1/h2 | $\gamma=0.98$ 使 $\mathbb{E}[h_2] < \mathbb{E}[h_1]$ 系统性 → 稳定检查恒失败（12 mismatch） | 改为**未加权**分段均数（折扣趋势剥离）；无漂移时 $z \approx 0$，漂移时 $z \gg 3$ |
| 2 | C7 bundle 空洞：harmful 成员从不 active → 共暴露耦合 $\mathbb{E}[h] = \mathbb{E}[u]$ 从未触发、日志无 pair 数据、corr $= 0$ | C7 检查形同虚设（m0 被放行 keep） | co_exposure 下背景策略**联合保留 pair**（"pair 永远一起被提议"），耦合真正生效（corr $= 1.00$）；bundle oracle/估计器改为**联合 toggle**（keep-both vs archive-both） |
| 3 | 观测日志只含 active 记忆 → archived 记忆零数据 | 基线对 short_term 的"正确" archive 是数据真空假象（score 恰 0.5 默认值），Theorem 2 教训未真正成立 | 日志加入 **probe 机制**（$p=0.2$ 探测曝光）；CMI/naive OPE 现在真正在 short_term 上误判（regret 10.3） |
| 4 | 漂移 violation 下估计器采样平稳世界 | 估计器与 oracle 一致 → 无偏差可观测，漂移只被门控检测 | 估计器采样**实际漂移的机制**（oracle 仍评估预注册 estimand）→ 偏差方向机制依赖、不可先验预测 |

## 5. 已验证 / 未验证（声明边界）

**现在可以声称**（仅限本合成环境）：
1. 满足 C1–C8 时，随机化持久动作的 rollout 估计器**恢复已知生命周期值**：bias≈0（MC 水平）、CI 诚实（0.97±0.05）、决策零错误、unresolved 恰为 neutral。
2. 单一条件违反时（C6/C7/C3/C8/Cor1），Qualification gate **检测到失败并弃权**（unresolved/mismatch），不做自信错误决策；盲于 gate 的强制决策付出可计量的 regret（41.0 / 83.4）。
3. Theorem 2 的教训在 Stage 1 内成立：CMI/naive OPE（局部无偏）在 short_term 上误判（局部 +0.2 vs 生命周期 −5.2）。

**尚不能声称**：
1. **观测路径**（Theorem 3(b)(c)：sequential g-formula / DR/OPE）未实现未验证——本实验只验证协议路径。
2. **部分识别界**（C6/C7 失败时的 bound 输出）未实现——当前退化为 unresolved。
3. 真实 Agent Memory 系统的有效性（需 chronological rollout + 真实/高保真数据，见 §6）。
4. $\lambda = \rho = 0$（成本/风险权重未激活）；合成世界边界不变（效应、分布、机制人工设定）。
5. Stage 2 中 drift/scope 的强制 regret 较小（2.2 / 0.96）——该配置下偏差未翻转多数决策；声称的是"gate 检测并弃权"，不是"每种违反都会让强制决策破产"。
