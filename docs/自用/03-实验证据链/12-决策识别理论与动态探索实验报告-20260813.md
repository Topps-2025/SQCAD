## 1. P0-1：C6 隔离实验（机制不变、只污染观测代理）

`13-` §7.4 要求：真实采纳过程完全不变，只翻转观测代理，协议估计器应恢复同一 oracle，观测 g-formula 因错误代理失效。原 `lemma_a`（`11` 报告）中 D 反馈进暴露 boost，机制随误测改变——本实验隔离这一点。

**构造**：世界生成一次（机制固定）；对每个污染率 ε 只翻转日志代理 D_obs（P(翻转)=ε），机制与结局流不变。

| 污染率 ε | 协议路线估计 | 观测采纳对比 | 代理准确率 |
|---|---|---|---|
| 0.0 | **1.1914** | 0.3221 | 1.000 |
| 0.3 | **1.1914**（逐位相同） | **0.0894** | 0.709 |

**读法**：协议路线估计器只读 (A, E, Y)——**逐位不变**且恢复 τ·p = 1.2（MC 噪声内）；观测采纳核对比（E[Y|D=1]−E[Y|D=0]）是暴露率选择加权量，按 (1−2ε) 稀释（0.322→0.089 ≈ 0.4×）。**C6 对协议路线不必要、对依赖采纳核的观测路线必要**——机制变化与测量误差被干净隔离（`13-` §7.4 的修正要求）。

## 2. P0-2：lifecycle IV（`13-` §7.3）

原 `lemma_c`（`11` 报告）识别常数横截面效应 τ。本实验把 IV 扩展到 lifecycle estimand：持久访问动作 A（keep/archive）、H=30 期折扣回报 G=Σγ^{t-1}Y_t、**归档即不暴露**（candidate–exposure 反馈）、未观测混杂 U、有效工具 Z（外部配额抽签）。

| 量 | 值 |
|---|---|
| Wald-IV 估计 τ̂ | **1.0173**（真值 1.0，误差 0.017，n=40000） |
| 观测对比 E[G\|A=1]−E[G\|A=0] | 偏倚 **+12.96**（混杂） |
| 第一阶段 E[A\|Z=1]−E[A\|Z=0] | 0.331（相关性成立） |

**如实标注**：识别的是**加性效应同质性**下的 lifecycle ATE（无 A×U 交互）；存在交互时 Wald 估计量是 Z 诱导 keepers 上的 LATE，不是 ATE——这正是 IV 路线的"不可检验断言"代价（分类学第 3 行）。协议路线的 C2/C3 仍是设计保证。

## 3. P1：Theorem 5（一般决策识别定理，`13-` §2）

**定理（完整证明见 §5）**：对二元持久访问决策，识别集合 [L, U] = {τ_M : M ∈ M(o)}（与日志相容世界的 lifecycle 对比范围）：

- 若 L > 0（或 U < 0）：存在最坏情况 regret = 0 的 committing 规则（keep / archive）——**决策可识别不需要点识别**；
- 若 L ≤ 0 ≤ U：任何 committing 规则的最坏情况期望 regret ≥ **R\*(L,U) = U(−L)/(U−L)**，在 commit 概率 p\* = U/(U−L) 处取得。

**计算验证**：

| 实例 | 结果 |
|---|---|
| 跨零集 (−1100, 1650)（Theorem 4 的两点对） | R\* = **660.0** @ p\* = 0.6（网格逐位一致；Theorem 4 是特例） |
| 决策可识别非点识别集 (500, 1650)（相容世界值不同但动作相同） | commit keep 最坏 regret = **0**；commit archive 最坏 regret = 500——**值未点识别、动作已识别** |

Theorem 4 由此从"双世界计算"升级为"任意跨零识别集合上的一般决策下界"（`13-` §2.1 的要求）。

## 4. P2：commit/defer/probe 成本边界（`13-` §3）

拒绝不是零成本、探测也不是免费。决策函数：min{ R\*(L,U), C_defer, C_probe + R\*_after }（探测把识别集收缩 shrink=0.5 的诚实简化）。

**实例（L=−1100, U=1650, C_defer=500, shrink=0.5）**：

| C_probe | 最优动作 | 最坏 regret |
|---|---|---|
| 0 | **probe** | 330 |
| 100 | **probe** | 430 |
| 300 | defer | 500 |
| 700 | defer | 500 |
| 1200 | defer | 500 |

**边界**：probe 胜 commit 当 C_probe < R\*(L,U) − R\*_after = 330；胜 defer 当 C_probe < C_defer − R\*_after = 170。**"未识别就必须 unresolved"被修正为"未识别时按三成本比较"**——与 Gate 4 成本合同的 λ_probe 通道直接对接（break-even λ_probe\* 的识别理论对应物）。

## 5. P3：self-confirming unidentifiability（动态必要性，`13-` §4 方向 A）

**构造**：rare-critical 记忆真值 τ=10/暴露步，被混杂先验误归档。无探测 → 永不暴露 → 永无证据 → 永不纠正：

| 机制 | regret(T=2000) | 每步斜率 |
|---|---|---|
| 无探测（q=0） | 12000.0 | **6.000 = τ·p**（精确线性——自我证实的不可识别性） |
| 预算探测 q=0.05 | 128.4 | 0.064（纠正后平台） |
| 预算探测 q=0.2 | 28.2 | 0.014 |

**读法**：无探测时 regret 线性累积（Ω(T) 的数值对应物——严格证明仍需形式化，如实标注）；小概率探测让归档候选重新进入证据流，运行均值越阈值即恢复，regret 平台化。**非识别不是一次性的数据不足，而可能被治理策略永久制造和维持**（`13-` §4.1 的 memory-specific 命题的数值验证）。P3 方向 B 与 P4 合并见下节。

## 6. P4：探测复杂度下界与 SQCAD 式停止规则上界（`13-` §4.2）

**设置**：两世界探测观测 N(μ₁=0.3, σ²)（keep 最优）vs N(μ₂=−0.5, σ²)（archive 最优）。下界：N ≥ log(1/δ)/KL，KL = (μ₁−μ₂)²/(2σ²)；上界：SQCAD 式停止规则（探测至 CI 排除 0：mean − z·σ/√n > 0）。

| 量 | 值 |
|---|---|
| KL 下界（δ=0.05） | **9.36** |
| 停止规则经验均值（150 seeds） | **34.6** |
| 比值（上界/下界） | **3.7**（同阶，常数因子） |
| 停止规则未提交率 | 0.000 |

**读法**：SQCAD 式 gate/probe 策略达到 O(log(1/δ)/Δ²) 探测数，与信息论下界**同阶**（Gaussian 实例常数因子 3.7）——"接近最优"的数值证据；严格 minimax-rate 证明（P4 完整版）仍需形式化。
