# Gap 命题证明实验公平性审查 — 2026-08-12

> 用途：在把三个反例用作"理论空白"的证据之前，先回答一个最基本的问题——**命题 A/B/C 的实验是否对基线方法公平**？若不公平，反例就只能证明"稻草人被击败"，不能证明"存在识别空白"。
> 结论：**总体公平**。三项命题均满足信息公平、构造公平、基线非稻草人、正面方法无 oracle 优势。发现 2 处需要修正的代码弱点（已修正，见 §6）。

---

## 0. 公平性审查标准

对"反例型 gap 论证"，公平性有四个可操作标准：

| 标准 | 含义 | 不满足时的后果 |
|---|---|---|
| **S1 信息公平** | 基线方法可访问的信息集 = 任何方法可访问的信息集。没有字段被刻意隐藏，也没有 oracle 字段被混入日志。 | 失败来自"信息被剥夺"，而非方法本身不行 |
| **S2 构造公平** | 失败是结构性的（代数等价、精确相等、信息论层面的不可分），而非噪声水平、调参或小样本伪影。 | 换一组参数可能就不失败 |
| **S3 基线非稻草人** | 基线估计的是其文献中的规范 estimand，且在构造中至少是无偏的（不能给基线一个故意有偏的估计器再宣称它失败）。 | 只证明了"坏实现失败" |
| **S4 正面无特权** | SQCAD 侧不能读到基线读不到的 oracle 信息。框架主张（识别条件、micro-intervention、unresolved）必须与反例构造自洽。 | 对比被暗中操控 |

## 1. 命题 A：观测等价 SCM（Memory Worth 路径）

### 1.1 主张

存在 P(O|M₁) = P(O|M₂) 但 persistent-access lifecycle value 符号相反的世界。

### 1.2 S1 信息公平：✓（且强于所需）

- 日志行包含：`time, scope, item, task_type, difficulty, propensity, exposed, outcome, success`。**基线只使用 exposed/success/time 三个字段**——`propensity`（真实暴露率）、`task_type`、`difficulty` 就放在日志里而未被使用。没有任何信息被剥夺。
- **关键强化点**：暴露是随机化生成（$\mathrm{Bernoulli}(p)$，与一切独立），因此 **$\mathbb{E}[Y \mid E=1] - \mathbb{E}[Y \mid E=0]$ 在两个世界中都是当前结果暴露效应的无偏因果估计**——仍等于 +1.5（复合系数）。也就是说，即使一个方法做了正确的因果调整，它看到的仍是"暴露效应为正"。不可识别性不是"关联 $\ne$ 因果"这一层——而是更深的**信息论层面**：$E_{\mathrm{star}} \equiv E_{\mathrm{prime}}$ 的完全共线性使得 $(m_{\mathrm{star}}, m_{\mathrm{prime}})$ 构成一个不可分的 treatment bundle，观测分布无法将其拆开。
- 结论：基线即使换成一个"正确设定的因果估计器"也必然失败 → 命题不是关于基线的实现质量，而是关于数据本身。

### 1.3 S2 构造公平：✓

- 等价性是**代数等价**（共享随机序列 + 恒等结构方程），`max_field_diff = 0.0`（全字段、全行、全记忆验证），不是"检验不显著"级别的近似等价。
- 生命周期值由解析式给出（$\beta \cdot p \cdot H'$），非估计值。

### 1.4 S3 基线非稻草人：✓

- Memory Worth 用的是 Beta 后验均值（$(s+1)/(n+2)$），阈值 0.5 是"成功概率 $>$ 失败概率"的自然决策边界。
- recency / frequency / fade-like 都是各自文献的规范形式。
- 四个基线全部失败，且失败方向一致（M₂ 中错误 keep m_star）。

### 1.5 S4 正面无特权：✓（自洽性检查）

- 在仅观测日志下，**SQCAD 也无法点识别** m_star 的价值——它应当输出 `unresolved`（bundle 不可分）。这与框架一致：Prop A 展示的是"观测日志下的不可识别性"，不是"SQCAD 在观测日志下能赢"。
- 打破共暴露需要的是**联合 micro-intervention**（随机化 $E_{\mathrm{star}} \perp E_{\mathrm{prime}}$），这是 Theorem 3 的 positivity 条件 + Stage 1 实验的内容，属于另一侧的主张，不由 Prop A 承担。

### 1.6 发现的弱点（已修正）

- 原 `_prop_a_distribution_check` 只数值比较了 m_star 一列的 outcome，未验证全联合分布。虽然代数构造保证全字段一致，但验证面不足。**修正**：改为全行全字段比较，新增 `full_joint_identical`、`max_field_diff`、`n_rows_checked`，并纳入 verdict 条件。

**判定：公平（修正后）**。

## 2. 命题 B：真 do-intervention 相等、生命周期相反（CMI 路径）

### 2.1 主张

即使 query-local 的强制干预效应 $\Delta_{\mathrm{do}}(m_{\mathrm{short}}) = \Delta_{\mathrm{do}}(m_{\mathrm{long}})$ 精确相等，两者的 lifecycle value 符号相反。

### 2.2 S1 信息公平：✓

- 基线获得完整的查询日志（task_type、difficulty、exposed、outcome）。干预是 forced-in/forced-out 成对构造，Δ_do 相等是构造前提（命题陈述的就是"即使相等"）。

### 2.3 S3 基线非稻草人：✓（本命题最重要的公平性事实）

- 观测暴露是随机化生成（`rng.choice([0,1])`，与任务、难度、噪声独立），因此 CMI 基线估计的 $\mathbb{E}[Y \mid E=1] - \mathbb{E}[Y \mid E=0]$ **是无偏的局部因果效应**（$\approx \alpha = 2.0$，与真值精确一致）。
- 也就是说：**基线拿到了正确的因果答案，仍然会做出错误的生命周期决策**。失败发生在 estimand 层面（query-local 效应 ≠ lifecycle value），而非估计误差层面。这是该反例的最强形式——它排除了"CMI 只是实现得不好"的辩解。

### 2.4 S2 构造公平：✓

- 生命周期符号差异来自未来 rollout 的动力学：m_short 未来零收益 + 概率性挤占关键记忆（crowding_prob=0.25），m_long 维持 rare-critical 检索桥。这是**结构性的未来状态依赖**，不是参数凑出来的统计差异（多 seed 下 regret = 1872±77，符号稳定）。
- 一个可预见的质疑："未来任务分布会变，任何方法都看不到未来"——这正是命题的边界声明：Theorem 2 主张的是"局部效应**不足以**决定生命周期决策，除非额外建模未来动力学（state transition、interference、budget）"，而不是"CMI 无用"。未来分布不可预见不是不公平，而是命题本身的内容。判断一个反例是否公平要看它是否**用尽了方法可获得的信息**——CMI 用尽了自己 estimand 的信息，仍然失败，这就是公平的失败。

### 2.5 S4 正面无特权：✓

- m_critical 的局部效应（4.0 on rare）比 m_short/m_long 更大，任何 CMI 排序都会把它排在前面——拥挤机制正是通过"workspace budget 下共同暴露"建模的，即 Theorem 3 的 C7（interference）。SQCAD 的解法不是"更强的局部效应估计"，而是把 budget/co-memory 放进状态并只在识别条件满足时行动。

### 2.6 发现的弱点（已修正）

- 原日志行内包含 `y_do1`、`y_do0`、`delta_do_true` 三个 oracle 列。虽然基线代码不读它们，但**观测日志里混入真值列**在结构上构成泄漏风险（任何审稿人都会质疑）。**修正**：真值 Δ_do 改由生成器单独返回，日志行只含可观测字段。

**判定：公平（修正后）**。

## 3. 命题 C：source 等价世界、target 相反（OPE/MSM 路径）

### 3.1 主张

source-scope 数据完全相同的两个世界，target-scope 机制不同 → source 平均效应不能无条件迁移。

### 3.2 分析

- **S1 信息公平**：✓。source 日志中没有任何 target 行（构造上就没有），scope 权重是真实的 source prevalence。任何方法都不可能从 source 数据中看出 target。
- **S3 基线非稻草人**：✓。估计器是标准 MSM 型 estimand——每个 scope 内 $\mathbb{E}[Y \mid E=1] - \mathbb{E}[Y \mid E=0]$（暴露随机 → 逐 scope 无偏），再按 prevalence 加权。这正是 OPE/MSM 文献中的规范做法。
- **S2 构造公平**：✓。教科书级非迁移性（Pearl & Bareinboim 意义上的 target mechanism 漂移），两个世界只在 target 结构机制上不同。
- **S4 正面无特权**：✓。SQCAD 在 scope transport 失败时输出 `mismatch`/`unresolved`（Qualification 层），与 Corollary 1 自洽。
- 无代码弱点。

**判定：公平，无需修正**。

## 4. 交叉审查

### 4.1 系统性地"对基线最有利"的设置

三个合成世界都用了**随机化暴露**（非策略驱动暴露）。真实系统里暴露是 history-dependent 的，存在混杂——那只会让关联方法更糟。反例在最有利于基线识别的设置下（无混杂、无测量误差、已知 propensity）仍然失败，说明失败不能归因于"现实太脏"，而应归因于**estimand 与生命周期决策之间的结构性缺口**。

### 4.2 三个命题是否相互独立

| 命题 | 失败层 | 排除的辩解 |
|---|---|---|
| A | 观测分布层面的非识别（完全共暴露） | "换更好的关联/因果调整方法" |
| B | estimand 不匹配（局部 ≠ 生命周期） | "换更精确的局部因果估计器" |
| C | 作用域迁移（source ≠ target） | "换更正确的 scope 加权" |

三者覆盖了基线路径的三个正交失败层，且都是反例级（existential）主张——存在这样的世界，因此任何声称"该路径总是足够"的方法都被反驳。

### 4.3 剩余的系统性局限（承认但不构成不公平）

1. **合成世界**：效应、分布、机制都是人工设定的。反例证明的是"存在这样的机制组合"，不是"真实 Agent Memory 系统中这种组合的比例"。这是反例方法的内在边界，需在论文中声明。
2. **无成本/风险项**：estimand 中 $\lambda C_t + \rho R_t$ 在三个命题中均为 0。成本与风险不改变不可识别性（它们是确定性的折扣项，不增加识别信息），故不影响结论，但实验报告应注明。
3. **决策遗憾的定义**：`compute_regret` 假定 archive 的效用恰为 0（不考虑恢复成本与预算释放收益）。该定义对基线与 oracle 一视同仁，只影响数值大小，不影响符号结构。

## 5. 判定汇总

| 命题 | S1 信息公平 | S2 构造公平 | S3 非稻草人 | S4 正面无特权 | 修正项 |
|---|---|---|---|---|---|
| A | ✓ | ✓ | ✓ | ✓ | 全联合分布验证（已修） |
| B | ✓ | ✓ | ✓ | ✓ | oracle 列移出日志（已修） |
| C | ✓ | ✓ | ✓ | ✓ | 无 |

**总体判定**：

> 三个反例实验对基线公平。基线获得完整信息集、被给予规范且（在构造中）无偏的估计器、失败是结构性而非统计性；SQCAD 侧没有 oracle 特权，其积极主张（可识别条件下的恢复、条件失败时的 unresolved）由独立的两阶段识别实验承担。修正后的反例可以作为论文中"counterexample-grounded identification gap"的证据。
