## 2. SimpleMem open-weight 完整复现

### 2.1 协议（30- R1 "open-weight substitute protocol reproduction"）

| 层 | 官方（论文） | 本行替换 | 说明 |
|---|---|---|---|
| 压缩 LLM | GPT-4.1-mini | **Qwen3-8B（temperature 0）** | 官方 MemoryBuilder 原样（窗口结构化压缩，无代词+绝对时间锚定） |
| 检索 | 混合检索（planning/reflection 默认开） | 官方 HybridRetriever 原样 | top_k = 官方默认 5/3/10 |
| 嵌入 | text-embedding 类 | **Qwen3-Embedding-0.6B** | 官方仓库自带 qwen3 映射 |
| 答案生成 | LLM | **合同抽取式 reader** | 与 sqcad/bm25 行同 reader，只比较记忆管理机制 |

- 官方代码零改动；子类仅记录 provenance（entry → 来源窗口 dialogue ids），用于合同的消息级 workspace 映射。
- 合同评估：workspace = 检索条目的**来源消息**；存储 = 全部压缩条目 token（SimpleMem 全量保留无逐出，lifecycle 计数按构造为 0——如实标注"无生命周期管理"）。
- LLM 调用量/输入输出字数全部计数回传。

## 3. ActMem 论文机制复现（无官方代码）

### 3.1 实现（arXiv ActMem §3.1–3.4，全部 open-weight 替代）

| 论文组件 | 本行实现 | 超参 |
|---|---|---|
| §3.1 事实提取 LLM(pext) | Qwen3-8B（每轮消息提取原子事实 JSON 列表） | — |
| §3.2 事实聚类（论文用 Qwen3-Embedding-8B） | Qwen3-Embedding-0.6B（显存同驻约束，见下） | τ_cluster = 0.75（论文未公开，预注册默认） |
| §3.3 语义边 | 簇内 pairwise cos | τ_sem = 0.80（同上） |
| §3.3 因果边 LLM(pcause) + PMI 验证 | Qwen3-8B 候选对 + Qwen3-0.6B 条件/无条件 NLL（式 (4)） | τ_pmi = 0.0（论文未公开） |
| §3.4 反事实检索（式 6-7） | 初始 top-12 → 反事实问题 → 二次检索 | top_k = 12 |

- **嵌入层显存约束（如实披露）**：vLLM 服务 Qwen3-8B bf16（util 0.9 ≈ 28.8 GB 预分配）与 Qwen3-Embedding-8B（15.1 GB）无法同驻 32 GB 显存。机制行嵌入层采用 Qwen3-Embedding-0.6B（与 SimpleMem 行同规格）；论文口径 8B 嵌入的检索行为已由 33- tier-B 行单独验证（负向规模结果：hit 0.771 vs 0.973、LoCoMo F1 0.0351）——嵌入规模不改变本行任何机制结论，也不影响"8B 嵌入"在表 5.2 的既有呈现。

- 评测：workspace = 检索事实的**来源消息**；存储 = 事实 token 总数（全量保留，lifecycle 0）；reader 统一。
- 超参未公开的如实标注（不冒充官方端到端；30- R1 已标注"非官方端到端"）。

