## 1. 为什么需要这道门

统一合同主表（`05` §3）有 18 个可传输策略行。但"有数字"不等于"数字可支持任意比较"：

- **R3（原论文结果复现）未完成**：Oblivion、SimpleMem、FadeMem、DeMem、Memory Worth 的官方实现未在原协议下运行（无 GPU、无 API key——环境事实，`05` §1 已如实标注）；
- **proxy 传输有缺省成分**：CMI 的受控扰动 oracle 换成流内效应估计；Trivium 的时间折现遗憾目标迁移到流上；FadeMem 用"差异化衰减率"结构替代精确参数化；
- **不可迁移对象无数字**：SAGE、MemAudit、GateMem 被列为 `not_transportable under the unified protocol`，主表无行。

**这不会推翻 Theorem 1/2**（它们是机制级构造性反例，不依赖任何基线的复现状态——见 §4），**但会阻止系统级外延**："现有 Agent Memory 理论均无法处理该问题"（§3 给出被阻止的精确表述与可声称的校准版）。

## 3. 被阻止的外延声称 vs 可声称的校准版

**被阻止（不可声称）**：

> “现有 Agent Memory 理论均无法处理该问题。”（以及任何 `first` / `unique` / `absence of` 表述——`docs/自用/01-research-gap/研究路线与方案/08-Gap1覆盖审计与框架设计重点-20260811.md` 已明确禁用。）

**不可声称的原因**：R3 未完成意味着无法排除"官方完整系统（含 LLM 层、官方环境、原协议）在相同任务上表现不同"的可能性；not_transportable 对象连数字都没有。系统级外延需要 R3 或等效的官方数字，这是复现门纪律的直接推论。

**可声称的校准版 A（机制级，Theorem 1/2 + Gap 证明支撑，不受 R3 阻塞）**：

> 在三个构造性反例中（`01`/`02` 报告），关联价值（Memory Worth 类）、query-local 干预效应（CMI 类）与 source-scope 平均（OPE/MSM 类）**各自都可能**对持久访问生命周期决策不充分——且失败发生在基线拿到正确因果答案时（estimand 层失败，非估计误差层失败）。因此"这些估计目标本身"不足以支撑生命周期决策。这是**估计目标级**命题：只要基线使用该类估计目标，无论官方实现多好，该结论都成立。

**可声称的校准版 B（结构级，统一合同 18 行 + 成本合同 + paired CI 支撑）**：

> 在统一合同（同一候选流、任务流、预算、评估器、种子）的可迁移子集上，18 个可传输治理策略中，SQCAD 在 utility–risk–cost frontier 上支配全部对照（utility 差值 CI 不跨 0，`08` §4 B1；成本合同下对最优非探测基线 V 优势区间不交叠，`08` §4 B2）；proxy 迁移的数字只断言**结构级**性质（estimand 忠实 + 缺省成分具名），不替代原论文 R3。

**可声称的校准版 C（审计级，本报告 + `05` §2）**：

> 对 R1 已冻结的核心治理基线（Oblivion、SimpleMem、FadeMem、DeMem、Memory Worth），其论文核心机制的结构级传输在统一合同下各自暴露其风险通道（stale 暴露、rare 保护缺失、token 效率）——这是**机制命题**；"官方完整系统在同合同下同样暴露"未验证，等待 R3。

**三种校准版的使用纪律**：A 用于理论部分（Theorem 1/2 支撑）；B 用于主表比较（`05`/`07`/`08` 数字支撑）；C 用于相关工作总结（机制讨论）。任何混用（拿 B 的数字说 A 的机制、或拿 A 的机制说系统级外延）都是声称违规。

## 4. 为什么 Theorem 1/2 不受 R3 阻塞

Theorem 1（观测不可识别）与 Theorem 2（局部效应不充分）是**构造性数学命题**：给定满足假设（A1–A3 / B1–B3）的世界族，存在两个 SCM 使观测等价而生命周期符号相反。它们的验证（`gap_proof_experiments.py` 命题 A/B，`01`/`02` 报告）只要求：

1. 构造满足假设（不需要任何基线实现）；
2. 基线在构造内使用其**规范估计器**且无偏（公平性审查 S1–S4 已验证："基线拿到正确的因果答案仍做错决策"）。

因此基线复现状态（R0–R3）**完全不在** Theorem 1/2 的证明路径上。R3 阻塞影响的是"官方系统表现如何"的系统级问题，不影响"某类估计目标是否足以支撑生命周期决策"的机制级问题。**审稿人若质疑"基线没复现完整"，正确的回应是把声称指向校准版 A/B/C 各自的支撑，而不是补一句笼统的"baseline 是 proxy"。**
