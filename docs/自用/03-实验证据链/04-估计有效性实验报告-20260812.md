## 1. 目的：补上定理第 (b)(c) 条的证据

`00-实验报告与当前结论.md` 中 Theorem 3 的状态是 "(a)(d) 已实验验证，(b)(c) 与部分识别界未实现"。本实验补上：

1. **观测路径**（Theorem 3(b)(c)）：在观测日志上拟合暴露过程与结局模型，模拟目标策略下的生命周期价值；
2. **估计器可信性边界**：正确/误设模型下的 g-formula、IPW、DR 对照，以及 C6 采纳误归属（D≠E）下"双重稳健也失效"的边界；
3. **识别失败时的正确处理**：支持缺失（crowding 机制在日志中无支持）、C7 共暴露时，比较**强制点估计 vs 部分识别界 vs 门控 unresolved/mismatch**；
4. **校准与覆盖—风险曲线**：不只报"零自信错误"（必要不充分），而是量化 gate 为了安全付出了多少覆盖率与价值；

全部在**已知真值**的合成世界（D0 及其变体、带混杂的逐步世界）上运行——估计量正确与否由真值裁决，与数据真实性问题（Gate 2）正交。

## 2. 实验 A：局部效应估计器的双重稳健性边界（含 C6 误归属）

**设定**：逐步观测日志，难度混杂（任务越难，暴露概率越高且基线结局越低），真效应 = 1.0。估计器 = g-formula（回归调整）、IPW、DR、naive 对比，各在 {correct, misspecified} × {correct, misspecified} 的结局/倾向模型设定下运行；治疗变量 = 真实暴露 E 或采纳代理 D（C6 误记率 0.25）。5 seeds × 4000 步。

**偏差表（full 配置，bias = 估计−真值，n_seeds=5）**：

| 模型设定 | g-formula | IPW | DR | naive |
|---|---|---|---|---|
| 两模型都正确 | **−0.001** | **+0.002** | **+0.000** | −0.210 |
| 仅结局误设 | −0.210 | **+0.002** | **−0.004** | −0.210 |
| 仅倾向误设 | **−0.001** | −0.210 | **−0.001** | −0.210 |
| 两模型都误设 | −0.210 | −0.210 | **−0.210** | −0.210 |
| 都正确，但治疗=D（C6） | −0.570 | −0.574 | −0.574 | −0.622 |

**结论（教科书模式，逐格成立）**：

- 单一误设：g-formula 只对结局敏感、IPW 只对倾向敏感；**DR 对任意单一误设稳健**（bias ≤ 0.004）；
- 双重误设：所有估计器都失效——双重稳健不是双重免疫；
- **C6（D≠E）比任何模型误设都致命**：即使两模型"正确"，一切估计器（含 DR）偏差 ≥ −0.57。采纳代理不能作为治疗的代理变量——这正是 Stage 2 门控在 C6 下全量 unresolved 的统计基础。

**采纳误记率敏感性**（DR 与 g-formula 用 D 或 E 作为治疗）：

| 误记率 | DR on E | DR on D | g-formula on D |
|---|---|---|---|
| 0.00 | 1.000 | 1.000 | 0.999 |
| 0.10 | 1.000 | 0.737 | 0.746 |
| 0.25 | 1.000 | 0.426 | 0.430 |
| 0.50 | 1.000 | **−0.005** | −0.005 |

用真实 E 则估计值全程稳定；用 D 则随误记率线性恶化，误记一半时估计量完全失效。

## 3. 实验 B：序贯 g-formula 的生命周期估计——estimand/support 失败

**设定**：D0 世界（12 记忆：3 useful β=1.2、2 short_term β=0.2、2 bridge β=0.2+1.5 status 加成、2 harmful β=−1.0、3 neutral β=0；背景策略 keep useful+bridge；short_term 永不进入活跃集，仅在平台探索下以 p_probe=0.2 被探测；γ=0.98，n_epochs=150）。观测日志 = 部署策略自身暴露引擎的 3000 步记录（含采纳反馈 boost、C7 耦合、C6 误归属、探测），逐行记录 active 状态。g-formula：从日志拟合每个 (记忆, 状态) 的暴露率与 OLS 结局模型，在目标持久动作下前向模拟 200 次。

**结果（full 配置，真值 = n_oracle=300 的 do-intervention 均值）**：

| 记忆 | 角色 | 点估计 | 真值 | 活跃格支持 | 判定 | 符号错误 |
|---|---|---|---|---|---|---|
| m0–m2 | useful | +47.1/+49.9/+48.1 | +47.9/+48.5/+48.4 | 3000 行 | keep | 无 |
| **m3/m4** | short_term | **+1.45/+2.41** | **−5.14/−5.19** | **0 行** | **keep（错）** | **有** |
| m5/m6 | bridge | +6.7/+8.2 | +29.5/+30.0 | 3000 行 | keep | 无 |
| m7/m8 | harmful | −10.3/−9.7 | −40.7/−39.9 | 0 行 | archive | 无 |
| m9–m11 | neutral | +0.16/+0.14/+0.05 | ≈0 | 0 行 | keep | 无 |

**结论**：

- **被识别机制上估计正确**：useful 的点估计与真值差 ≤ 1.5（相对误差 ~3%），判定全部正确；
- **estimand/support 失败精确复现**：short_term 的活跃格在日志中**零支持**（3000 步从未活跃），点估计从探测率 0.2 外推 → 判 keep，而真值是 −5.1（keep 会因 crowding 压垮 bridge 而净损）。**g-formula 在支持缺失处犯符号错误**——这正是 Theorem 3(b) 的边界：观测路径只在支持覆盖处可信；
- **量级低估的系统性来源**：bridge/harmful 的量级被低估 4–4.5×（bridge：8.2 vs 30.0；harmful：−10 vs −40）。bridge 的价值大部分来自 status 加成与 crowding 反事实路径——这些机制在状态现状日志中无支持，结局模型只能把它们摊进平均暴露系数。判定方向仍正确；
- neutral 点估计 ≈ 0（±0.2），真值 ±1.2 为 oracle MC 噪声（n_oracle=300 时 se≈0.6–0.9）。

## 4. 实验 C：部分识别界 vs 强制点估计 vs unresolved

**设定**：对第 3 节同一世界，把未识别机制（crowding 强度 s∈[0,1]、bridge 加成份额）参数化，对 s 网格 {0, 0.15, 0.5, 1.0} 计算生命周期值集合（每个 s 值 200 次模拟），输出区间 [lo, hi]；门控对跨界区间输出 `unresolved`。

**汇总（full 配置，真值 se≈0.5–0.9）**：

| 指标 | 值 |
|---|---|
| 非零真值记忆数（\|truth\| > 1.96·se） | 10/12 |
| 强制点估计符号错误（非零真值上） | **2**（m3、m4） |
| 强制点估计决策错误（非零真值上） | **2**（m3、m4） |
| **界决策错误（非零真值上）** | **0** |
| unresolved 数 | 2（恰为 m3、m4） |
| **界挽救次数**（点估计符号错→界内真值且弃权） | **2/2** |

**逐记忆关键行**：

| 记忆 | 真值 | 点估计 | 界 | 界判定 | 真值在界内 |
|---|---|---|---|---|---|
| m3 | −5.14 | +1.45 | [−13.4, +1.45] | **unresolved** | ✓ |
| m4 | −5.19 | +2.41 | [−12.4, +2.41] | **unresolved** | ✓ |

**结论**：

- **点估计犯 2 个自信决策错误（判 keep，真值 archive）；界把这两处全部改为 unresolved，真值均落在界内，界决策错误 = 0**。识别失败时"拒绝做持久访问决策"是有代价有收益的：代价是放弃 m3/m4 的决策（也放弃了有用的确定性），收益是绝不自信地错；
- 识别良好的记忆（useful/harmful）界退化为点（无未识别参数），决策正确；
- **C7 共暴露**：pair (m0 useful, m7 harmful) 暴露相关 = 1.0（秩亏），单记忆系数不可识别；bundle 局部对比 0.173 可识别，bundle 生命周期 7.36 vs 真值 8.32（**bundle 可恢复**）；门控输出"per-item unresolved; bundle-level decision available"——与 Stage 2 的 C7 结论一致，且此处给出了**可识别的 bundle 替代量**而非直接弃权。

## 5. 实验 D：qualification 校准与 coverage–risk 曲线（含诚实负面发现）

**设定**：协议路径（RCT 估计量）在 8 seeds × 12 记忆 = 96 个 (估计, se, 真值) 三元组上评估。z = 估计/se 被解读为 P(V>0) 的正态分位数，门控阈值 z* 决定"置信决定 vs 弃权"。

**校准指标（full 配置）**：

| 指标 | 值 |
|---|---|
| n（记忆×seed） | 96 |
| Brier | 0.076 |
| ECE（5 bins） | 0.049 |
| **z*=1.96 下自信符号错误率** | **1.43%**（≠0！） |
| **95% CI 覆盖** | **88.5%**（< 95%） |

**coverage–risk 曲线**：

| 阈值 z* | 覆盖率（决定比例） | 错误率 | 放弃价值 |
|---|---|---|---|
| 0.5 | 90.6% | 8.05% | 4.2 |
| 1.0 | 83.3% | 3.75% | 4.6 |
| 1.28 | 78.1% | 2.67% | 4.6 |
| 1.64 | 76.0% | 1.37% | 6.9 |
| **1.96** | **72.9%** | **1.43%** | **7.6** |
| **2.58** | **68.8%** | **0.0%** | **7.8** |

**结论（两部分，缺一不可）**：

1. **期望的模式**：覆盖率随 z* 单调下降（90.6%→68.8%），错误率单调下降（8.05%→0），放弃价值单调上升（4.2→7.8）——**安全不是免费的，曲线量化了购买 0 自信错误的价格**（z=2.58 时放弃 27.3% 的记忆决策与 7.8 的价值）。
2. **必须如实报告的负面发现**：预注册阈值 z*=1.96 在 full 配置下**不是**零错误——96 个三元组中有 1 个自信符号错误（1.43%）；95% CI 覆盖 88.5% < 名义 95%（正态近似 CI 轻微反保守，重尾价值分布所致）。fast 配置（36 个三元组）恰好为 0 错误/83% 覆盖——**"零自信错误"依赖配置，不能当作普适事实**。这正是评审要求报 coverage–risk 曲线而非只报零错误的原因。

## 6. 实验 E：样本量—偏差—CI 覆盖曲线

| RCT n_trajectories | bias | RMSE | CI 覆盖 |
|---|---|---|---|
| 10 | +0.18 | 3.16 | 94.4% |
| 30 | +0.26 | 2.31 | 94.4% |
| 100 | −0.57 | 1.75 | 86.1% |
| 300 | −0.18 | 1.40 | **72.2%** |

| DR n_steps | bias | bias_sd |
|---|---|---|
| 300 | +0.030 | 0.057 |
| 1000 | +0.022 | 0.013 |
| 3000 | −0.004 | 0.014 |
| 10000 | −0.001 | 0.003 |

**结论**：RCT RMSE 随 n 单调下降（3.16→1.40）；DR 偏差与波动随 n_steps 单调收缩（偏差 → 0.001，sd → 0.003）。**负面发现**：RCT 的 CI 覆盖随 n 下降（94%→72%）——当前正态近似 CI 在更大样本下**反保守**，说明 se 被系统性低估（seed 间异质性/共享任务流的轨迹相关性所致）。Gate 5 计划中的 **paired seed/episode bootstrap CI** 正是为此而设——该发现成为 bootstrap 方案的需求来源。

## 7. 跨估计器综合对照（D0 世界，已知真值）

| 估计器 | 估计目标 | 在 D0 上的结果 | 来源 |
|---|---|---|---|
| **RCT（协议路径）** | 生命周期 V(a) | bias −0.47，CI 覆盖 12/12，自信错误 0，unresolved 恰为 3 neutral | Stage 1（`03-识别恢复实验报告`） |
| **g-formula（观测路径）** | 生命周期 V(a) | 支持覆盖处正确（useful 差 ≤3%）；支持缺失处符号错误（short_term 2 处）→ 由界挽救 | 本报告 §3–4 |
| **DR/OPE** | 局部 do 效应 | 双重稳健性逐格成立（bias ≤0.004）；C6 下全部失效（bias ≥−0.57） | 本报告 §2 |
| **association（Memory Worth）** | 历史关联 | regret 91.3（在 lifecycle 决策上结构性失败） | Stage 1 |
| **CMI** | 局部 do 效应 | 拿到正确的局部因果答案仍做错 lifecycle 决策（regret 10.3，err 0.17） | Stage 1 |

**综合解读**：三种估计目标（关联/局部因果/生命周期）必须分开——这与 Theorem 1/2 的构造性反例一致；生命周期估计只有在**支持覆盖**（协议路径随机化，或观测路径活跃格有支持）处可信；支持缺失处，**界优于点估计**（0 自信错误 vs 2 个错误决策），unresolved 是正确输出。

## 8. 可以声称 / 尚不能声称

**可以声称（均有实验支撑）**：

1. Theorem 3(b)：**观测路径的序贯 g-formula 在支持覆盖处恢复已知生命周期值**（useful 相对误差 ~3%），并在支持缺失处**犯可预言的符号错误**——估计值的可信范围由支持覆盖界定；
2. Theorem 3(c)：**DR/OPE 的双重稳健性逐格成立**（任一单一误设下 bias ≤ 0.004，双重误设失效），且 **C6 采纳误归属使包括 DR 在内的一切估计器失效**（即使模型正确）；
3. Theorem 3(d)：**识别失败时部分识别界优于强制点估计**——2 个自信决策错误被界改写为 unresolved，真值均在界内，界决策错误 = 0；C7 下 bundle 可识别而 per-item 不可；
4. **coverage–risk 曲线量化了门控的安全价格**：z=2.58 买 0 错误（放弃 27% 覆盖与 7.8 价值）；且如实报告 z*=1.96 在 full 配置下仍有 1.43% 自信错误——不能声称"门控零错误"。

**尚不能声称**：

- **完整序贯 DR（lifecycle 层面的双重稳健）**——本实验在局部效应层面验证了 DR 性质，生命周期层面实现的是 g-formula（OPE），未做序贯 DR 的对应实现；
- 观测路径在**真实 Agent 日志**上的行为（本报告全部在已知真值合成世界上）；
- RCT CI 的名义覆盖（88.5% 覆盖与随 n 下降——需 paired bootstrap 修复，Gate 5 承接）；
- 任何"SQCAD 改善真实 Agent Memory 治理"的结论（需要 Gate 2 的真实轨迹与 Gate 4 的成本合同）。
