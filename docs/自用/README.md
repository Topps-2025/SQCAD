## 使用规则

1. 23 是唯一实验总入口；任何结论先核对 23 的声称纪律与冻结合同。
2. 实验报告完整保留，不删除、不改写历史；被替代的版本留在 02-历史草稿 供追溯。
3. 论文正文只引用 00-论文主体 与 03-实验证据链 的关键报告；01/02 区是底稿。
4. 数据与代码资产：`results/`、`remote_results/`、`src/sqcad/`、`tests/`（见 04-reproducibility 与 freeze manifest）。
