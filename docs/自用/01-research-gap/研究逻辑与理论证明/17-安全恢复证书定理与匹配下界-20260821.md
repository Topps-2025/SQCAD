# 安全恢复证书：有限时域上界与 KL 下界

> 这是对旧版“恢复通道达到匹配复杂度”声称的替代，而不是补丁。旧版 Corollary 3 / Theorem 8 把“一次正向 probe 即 restore”的条件上界，与需要 `N*` 个样本才能达到错误率 `δ` 的下界放在一起，策略类和错误约束不一致；并且没有计入负世界中的误恢复。本文撤回该匹配声称，只保留下面这个可证明闭环。

## 1. 问题类：安全 archived-committed 恢复

固定一个决策 epoch 后的有限 horizon `H`。潜在世界为 `W+` 或 `W-`，对应 probe 成功后观测

```text
X_j ~ Normal(+mu, sigma^2)  (W+),
X_j ~ Normal(-mu, sigma^2)  (W-),     mu > 0.
```

每个时刻至多发起一次 probe；发起后以概率 `rho` 成功取得一个 `X_j`。允许的 probe attempt 概率上限为 `q`，因此每时刻取得观测的条件概率至多为 `kappa = q rho`。probe attempt 成本为 `c_p`，一次永久 keep/restore 成本为 `c_r`。为使下面的上界成为可实现的上界，`CS_delta` 明确采用每个 archived epoch 独立以**恰好 `q`** 发起 attempt；`q` 是类的上限，而不是任意策略都必须达到的速率。在得到 keep 授权以前，记忆保持 archived；在 `W+` 中 archive 每个时刻产生生命周期损失 `nu`，在 `W-` 中 archive 是正确动作。若在 `W-` 中错误 keep，则之后每个剩余时刻最多产生 `nu` 损失。记 `R_H^{life}` 为生命周期损失，并定义总成本

```text
C_H^{tot} = R_H^{life} + c_p M_H + c_r 1{K_H},
```

其中 `K_H={keep by H}` 是 keep 事件，`M_H` 是 terminal decision 前的 probe attempt 数。

定义 `Safe(H, delta)` 策略类：

1. 策略从 archived 状态开始，且在授权 keep 前不能默认 keep；
2. 策略只能通过 probe 获得 `X_j`，可以在任意 stopping time `tau <= H` 选择 `keep` 或永久 `archive`；终止 archive 后不得继续 probe（否则它不是本节的 archived-committed 类）；
3. 其错误恢复概率满足 `P_-(keep by H) <= delta`；
4. 若一个 epoch 开始时记忆仍为 archived，则该 epoch 的 lifecycle loss 按 `nu` 计；因此在该 epoch 取得最后一个成功 probe 并 keep，当前 epoch 仍计入损失。probe 和 restore 成本按实际发生次数计。

这里的安全约束是必要的：若允许“默认 keep”，`W-` 可被立即识别且不存在统一的恢复错误控制；若允许一个带 latent world identity 的 oracle，任何样本下界都会被走私信息破坏。

## 2. 上界：双侧固定样本证书

令

```text
n_delta = ceil( (sigma * Phi^{-1}(1-delta) / mu)^2 ),
```

其中 `Phi` 是标准正态分布函数。策略 `CS_delta` 在 archived 状态下的每个 epoch 以概率恰好 `q` 发起 probe，直到取得 `n_delta` 个成功样本或 horizon 结束；若达到门槛，则当样本均值大于 0 时 keep，否则 archive；若 horizon 结束仍未达到门槛，则 archive。

### 定理 11（有限时域安全恢复上界）

`CS_delta` 属于 `Safe(H, delta)`，并且

```text
P_-(keep by H) <= delta,

sup_W E_W[C_H^{tot}(CS_delta)]
  <= nu * n_delta / (q rho)
     + c_p * n_delta / rho
     + c_r
     + nu * H * delta.
```

若取 `delta = 1/H`，固定 `mu, sigma, q, rho > 0`，则

```text
sup_W E[C_H^{tot}] = O( (nu/(q rho) + c_p/rho) * (sigma^2/mu^2) log H + c_r + nu ).
```

因此，在安全恢复类内，总成本是 `O(log H)`，而不是旧文档声称的 horizon-independent `O(1/(q rho))`；只有把错误概率固定为常数、且不要求随 horizon 控制误恢复，才可得到常数级上界。

### 证明

每次成功 probe 的样本在两个世界下分别服从 `N(+mu,sigma^2)` 和 `N(-mu,sigma^2)`。固定样本均值检验的两侧错误率均为

```text
Phi(-mu sqrt(n_delta)/sigma) <= delta
```

故 `P_-(keep by H) <= delta`。在 `W+` 中，直到取得 `n_delta` 个样本以前始终 archived；令 `S_n` 为第 `n_delta` 个成功 probe 的时刻，`E[S_n] = n_delta/(q rho)`，有限 horizon 截断只会减少等待损失。因此，正确 keep 分支的生命周期损失至多 `nu n_delta/(q rho)`，probe attempt 的期望数至多 `n_delta/rho`，restore 成本至多 `c_r`。若固定样本均值错误地落在负侧，`W+` 以概率不超过 `delta` 终止于 archive，其额外生命周期损失至多 `nu H delta`。在 `W-` 中，正确 archive 不产生生命周期损失；唯一可能的生命周期损失来自错误 keep，其概率同样不超过 `delta`，每次最多损失 `nu H`，故也不超过 `nu H delta`。因此对每个世界分别取对应的错误方向，`sup_W` 仍只需一个 `nu H delta` 尾项；将两侧对应的 lifecycle、probe 和 restore 项相加，得到 `C_H^{tot}` 上界。∎

## 3. 下界：安全恢复必须支付信息和 censoring 成本

对任意策略 `pi in Safe(H, delta)`，令 `K_H={keep by H}` 表示 keep 事件，`M_H` 表示 terminal decision 前的 probe attempt 数，`N_H` 表示其中成功的 probe 数。设 `K = KL(N(+mu,sigma^2) || N(-mu,sigma^2)) = 2 mu^2/sigma^2`，并令 `kl(a,b)` 为 Bernoulli KL。

### 定理 12（有限时域安全恢复下界）

对任意 `pi in Safe(H, delta)`，以下二者至少有一个成立：

**(a) 未能及时恢复：** 若 `P_+(K_H) < 1-delta`，则

```text
E_+[R_H^{life}(pi)] >= nu * delta * H.
```

**(b) 达到高概率恢复：** 若 `P_+(K_H) >= 1-delta`，则

```text
E_+[N_H] >= kl(1-delta, delta) / K,
E_+[T_H^{arch}] >= kl(1-delta, delta) / (K q rho),
```

若 probe attempt 成本为 `c_p`、成功 keep 的 restore 成本为 `c_r`，并且

```text
E_+[C_H^{tot}(pi)]
  >= nu * kl(1-delta, delta) / (K q rho)
     + c_p * kl(1-delta, delta) / (K rho)
     + c_r * (1-delta).
```

其中 `N_H` 是 terminal decision 前获得的成功 probe 数，`T_H^{arch}` 定义为整个 horizon 内“epoch 开始时仍为 archived”的 epoch 数，**包括 terminal keep 所在 epoch，也包括 terminal archive 之后不再 probe 的剩余 epochs**；若 keep 从未发生，必有 `T_H^{arch}=H`。该记账约定与“probe 在当前 epoch 末才产生可用授权”一致，并使 `R_H^{life}=nu T_H^{arch}` 在 `W+` 中逐路径成立。特别地，对 `delta <= 1/4`，`kl(1-delta,delta) >= (1/2) log(1/(2 delta))`，所以安全恢复的生命周期信息成本至少为

```text
Omega( nu * sigma^2/(q rho mu^2) * log(1/delta) ).
```

### 证明

若 `P_+(K_H) < 1-delta`，则在 `W+` 中至少有概率 `delta` 到 horizon 仍未 keep；安全类要求 keep 前保持 archived，所以这些路径每步损失 `nu`，得到 (a)。

下面设 `P_+(K_H) >= 1-delta`。将策略的完整 transcript（probe attempts、成功/失败指示、成功样本和内部随机数）截断到 horizon。由数据处理不等式，transcript KL 不小于最终二元事件 `K_H` 的 KL：

```text
KL(P_+^tr || P_-^tr) >= kl(P_+(K_H), P_-(K_H))
                       >= kl(1-delta, delta),
```

最后一个不等式使用 `P_-(K_H) <= delta` 以及在 `a >= 1-delta, b <= delta` 区域内 Bernoulli KL 的单调性。probe 成功/失败过程和策略随机数在两世界中分布相同，只有每个成功样本的观测分布不同；链式 KL 分解给出

```text
KL(P_+^tr || P_-^tr) = K * E_+[N_H].
```

故得到第一个下界。成功指示在每次 attempt 后独立以概率 `rho` 发生，停止规则只依赖已观察历史，因此 Wald 恒等式给出

```text
E_+[N_H] = rho * E_+[M_H].
```

每时刻取得成功样本的条件概率至多为 `q rho`，且任何成功 probe 都发生在该 epoch 开始时 archived 的状态；terminal archive 后虽然不再 probe，但剩余 epochs 仍计入 `T_H^{arch}`。于是

```text
E_+[N_H] <= q rho * E_+[T_H^{arch}],
```

从而得到 `E_+[T_H^{arch}]` 下界。按上述 epoch-start 记账，`W+` 的 lifecycle loss 恰为 `nu T_H^{arch}`；高恢复分支还有 `P_+(K_H) >= 1-delta`，所以 restore 成本至少为 `c_r(1-delta)`；结合 `c_p E_+[M_H]` 即得总成本下界。∎

## 4. 闭环含义：何处匹配，何处不匹配

## 4A. Theorem 13：anytime Qualification certificate

The fixed-sample policy above is a clean audit object but does not yet mirror the online Qualification loop. The following anytime gate is the direct framework instantiation.

Let the `j`-th successful probe observation be conditionally `sigma`-sub-Gaussian around lifecycle contrast `tau` given the past probe transcript (the Gaussian model is a special case). Probe-attempt decisions may be adaptive, provided the current probe outcome is not selected using its unobserved value. This gives the safety statement for any predictable attempt schedule. For the displayed cost upper bound, define `CS_alpha(q)` to use conditional attempt probability exactly `q` at every unresolved archived epoch (or a separately verified lower rate `q`); if only an upper rate is known, the safety result remains valid but the displayed finite-cost upper bound does not follow. For `n >= 1`, define

```text
b_n(alpha) = sigma * sqrt( 2 log(pi^2 n^2/(3 alpha)) / n ).
```

The anytime gate updates after every successful probe:

```text
mean_n - b_n(alpha) > 0  -> keep,
mean_n + b_n(alpha) < 0  -> archive,
otherwise                -> unresolved / continue probing.
```

The gate is terminal after keep or archive and archives at the horizon if no boundary is crossed. Let `n_Delta` be the first `n` with `b_n(alpha) < Delta/2`.

### 定理 13（anytime 证书的安全性与恢复上界）

For every `alpha in (0, 1/2)`, and for every nonzero lifecycle contrast `tau`, the anytime gate satisfies

```text
P(there exists n with a wrong confident authorization, where wrong is defined by the sign of tau) <= alpha.
```

For every world with `|tau| >= Delta`, on the coverage event it authorizes the correct action by the `n_Delta`-th successful probe. Consequently,

```text
sup_{|tau| >= Delta} E[C_H^tot]
 <= nu * n_Delta/(q rho)
    + c_p * n_Delta/rho
    + c_r
    + (nu + c_p) * H * alpha.
```

The final term charges the confidence-complement event: in addition to at
most `nu H` lifecycle loss, the gate can make at most `H` probe attempts before
the horizon. Because the bad event is transcript-dependent, its probe count
cannot be multiplied by the marginal attempt probability `q`. The restore
term is already bounded by the displayed full `c_r` term.

The zero-contrast case is intentionally treated as unresolved rather than assigned a correct persistent action. The proof is a direct confidence-sequence argument. For each `n`, sub-Gaussian concentration gives

```text
P(|mean_n - tau| > b_n(alpha)) <= 6 alpha/(pi^2 n^2),
```

and the series over `n` is at most `alpha`. On the simultaneous coverage event, a positive `tau >= Delta` can never cross the negative boundary, while at `n_Delta` its lower endpoint is strictly positive; the negative case is symmetric. For `CS_alpha(q)`, the unconditioned contribution of the coverage event is bounded by `n_Delta/(q rho)` expected lifecycle waiting and `n_Delta/rho` expected attempts; this is not a conditional expectation after conditioning on the coverage event. On the complement event, lifecycle loss is at most `nu H` and probe cost is at most `c_p H`; this gives the displayed `(nu+c_p)H alpha` tail term.

### 推论 13（与所有安全 sequential policy 的阶匹配）

Restrict the Gaussian subclass to `tau in {+Delta, -Delta}` and impose the same `Safe(H,alpha)` false-keep constraint. When the horizon is long enough for the high-recovery branch to be relevant, Theorem 12 gives

```text
inf_safe sup_W E[C_H^tot]
 >= Omega( (nu/(q rho) + c_p/rho)
           * sigma^2/Delta^2 * log(1/alpha) ).
```

Without this long-horizon condition, the general statement is the two-branch
lower bound: either recovery probability is below `1-alpha`, incurring at
least `nu alpha H` lifecycle loss, or the KL information/probe/restore lower
bound applies. Thus the matching claim is an information-order result in the
sufficiently long, margin-separated regime, not a horizon-free exact minimax
identity.

The anytime gate has the same order up to the confidence-sequence overhead. To avoid treating the simple `n^2` union bound as optimal, we also implement a geometric stitched boundary. For integer epoch `m_k=ceil(eta^k) <= n <= M_k=ceil(eta^(k+1))-1`, allocate `alpha_k = 6 alpha/(pi^2(k+1)^2)` and use

```text
b_n^stitch = sigma * sqrt( 2 (M_k/m_k) log(2/alpha_k) / n ).
```

A maximal sub-Gaussian inequality within each epoch plus the summable `alpha_k` budget gives simultaneous coverage at least `1-alpha`; its sample threshold has only a `log log n` overhead. The stitched gate is therefore near-minimax in the margin-separated safe class, while the margin band `|tau| < Delta` remains intentionally unresolved. This is the first theorem in this project that directly maps the persistent-action certificate used by SQCAD to an online, anytime-valid authorization rule.

For completeness, on integer epoch `I_k={m_k,...,M_k}`, apply the two-sided maximal inequality to the centered sub-Gaussian partial sums up to `M_k`. Since `n >= m_k` on the epoch, the boundary above implies a sum threshold at least `sigma sqrt(2 M_k log(2/alpha_k))`; the maximal inequality bounds the epoch failure probability by `alpha_k`. Summing `sum_k alpha_k = alpha` proves the anytime coverage. The threshold inversion contributes `log(1/alpha)+2 log(k+1)`, hence `log log n` rather than `log n` overhead.

### 引理 14（margin band 内不存在 uniform fast authorization）

Let `epsilon > 0` and consider the two Gaussian worlds `tau=+epsilon` and `tau=-epsilon`. Any policy that authorizes `keep` in the positive world and `archive` in the negative world with probability at least `1-delta` must satisfy

```text
E_+[N_H] >= kl(1-delta, delta) / (2 epsilon^2/sigma^2).
```

As `epsilon -> 0`, this lower bound diverges as `epsilon^-2`. Therefore no finite, horizon-independent policy can guarantee fast correct authorization uniformly over a neighborhood of zero. The only honest uniform action in the unresolved margin band is to defer, retain reversibility, or report an explicit cost/risk trade-off. The proof is the same data-processing and transcript-KL argument as Theorem 12, but the statement is important because it rules out “solving” the hard case by shrinking the certificate threshold or tuning a more aggressive score.

定理 11 和定理 12 在同一个 `Safe(H,delta)` 类、同一个 finite-horizon 风险定义和同一个错误恢复约束下给出；定理 13 的 anytime gate 另有 transcript-dependent probe 尾项：

```text
fixed-sample upper:  O((nu/(q rho) + c_p/rho) * mu^-2 log(1/delta) + c_r + nu H delta),
anytime upper:  O((nu/(q rho) + c_p/rho) * mu^-2 log(1/alpha) + c_r + (nu + c_p) H alpha),
lower:  Omega((nu/(q rho) + c_p/rho) * mu^-2 log(1/delta) + c_r(1-delta)).
```

因此可以审慎地说：**在安全 archived-committed 类中，censoring 使生命周期等待代价按 `1/(q rho)` 放大，统计错误约束再引入 `log(1/delta)/mu^2`；probe 成本按 `1/rho` 计，双侧固定样本证书在同一总成本合同下达到这一阶。** Anytime gate 的坏覆盖事件还可能继续 probe，所以其尾项单独含 `(nu+c_p)H alpha`。这里的“匹配”只针对安全类、有限 horizon 和声明的 false-restore 预算，不针对任意 sequential policy。

不能再说：

- 任意 sequential policy 都有同一个下界；
- 一次正向 probe 的 restore 上界与 `N_delta` 下界匹配；
- 对所有 horizon 都有固定 `O(1/(q rho))` regret；
- 该结论覆盖允许默认 keep、外部 intervention、latent state 或可观察 continuation feedback 的更大策略类。

## 5. 与 SQCAD 的一一映射

1. `Evidence` 提供成功 probe transcript、失败 censoring 和 epoch horizon；
2. `Qualification` 不再是“一次正证据就 restore”，而是输出一个双侧 certificate：只有下界严格大于 0 才授权 keep；否则继续 defer/archive；
3. `Access` 承担 `q`、`rho` 与预算约束，因而其 probe 成本必须进入主表；
4. `Decision` 记录 `delta`、horizon `H` 和 false-restore 预算。`delta` 不是装饰性置信参数，而是决定 `log(1/delta)` 信息成本的治理旋钮。

旧版 T1(b)、Theorem 8 和 Corollary 3 仅保留为显式 Bernoulli 单世界的诊断引理，不再承担最优性、minimax 或 matching claim。论文主线应改为 Theorem 11–12；原 Theorem 4 的 reduction separation 降为 restricted impossibility appendix，不再作为核心理论贡献。

## 6. 可复核检查项

- `n_delta` 必须按 `Phi^{-1}(1-delta)` 计算，而不是用一次观测阈值替代；
- 模拟同时报告 `W+` 的恢复延迟和 `W-` 的 false-restore rate；
- 统计单元是独立 world / seed，不能用 episode 数掩盖机制实例数；
- 所有成本报告同时列出 lifecycle loss、probe cost、restore cost；
- 当 `delta` 随 `H` 变化时，主图应显示 `log H` 而非水平平台。
