# SQCAD 证书—删失桥接定理（Certificate–Censoring Bridge）

> 文档性质：这是把 Theorems 11–13 的抽象 `Safe(H, alpha)` 模型映射到 SQCAD `QualificationAccess` 授权路径的接口定理。它不声称真实 LLM probe 自动满足统计假设；统计假设必须作为可审计的 certificate contract，或由独立校准实验支持。

## 1. 为什么需要桥接定理

Theorems 11–13 证明的是一个 archived-committed sequential testing 类的结果，而 `qualification_access.py` 实现的是一个区间授权器。若没有显式接口，审稿人可以合理地认为：

1. 统计上安全的 probe 证书与实际 persistent action 之间没有形式对应；
2. 代码的 `UNRESOLVED`、`KEEP`、`ARCHIVE` 可能只是工程约定，而不是定理中的 stopping rule；
3. Gaussian/sub-Gaussian toy model 的 coverage 被误读为真实 LLM certificate coverage。

下面的桥接定理只解决第一个和第二个问题，并把第三个问题明确保留为经验验证义务。

## 2. SQCAD certificate contract

固定一个 memory、scope 和 horizon `H`。令 `F_n` 表示前 `n` 个**成功 probe** 的 transcript filtration；失败 probe 只决定是否获得下一个样本，不作为均值样本计数。一个 `SQCAD-C(alpha, sigma, q, rho, nu, H)` contract 要求：

**C1（persistent action semantics）**：在 terminal authorization 前 memory 保持 archived；没有 default keep；terminal archive 后不得继续 probe。一个 epoch 若在开始时 archived，则该 epoch 计入生命周期损失 `nu`。

**C2（predictable probing）**：第 `t` 个 probe attempt 的发起由过去 transcript 和外部 pre-registered randomness 决定，不能依赖当前尚未观测的 probe outcome；每个 epoch 至多一次 attempt，条件发起概率不超过 `q`。安全性只需这个上界；若要使用 B4 的显示成本上界，SQCAD gate 必须在 unresolved 时以条件概率恰为 `q`（或有独立验证的条件概率下界 `q`）。

**C3（success channel）**：attempt 成功指示在条件历史下以概率 `rho` 获得一个 `X_n`；成功指示与当前 `X_n` 的取值独立。若只知道上界或存在依赖，必须把相应更弱的 channel 写入新的 contract，不能继续使用 Theorem 11–13 的精确系数。

**C4（fixed target and conditional concentration）**：在某个固定 lifecycle contrast `tau` 周围，成功 probe 满足

$$
\mathbb E[X_n\mid\mathcal F_{n-1}]=\tau,\qquad
\mathbb E[\exp\{\lambda(X_n-\tau)\}\mid\mathcal F_{n-1}]
\le \exp(\lambda^2\sigma^2/2).
$$

这允许 probe 的发起自适应，但不允许 `tau` 随 epoch 漂移。未知 `sigma` 不得直接用同一 transcript 的未经校准样本方差替代；工程上应使用外部上界，或另行证明可选方差估计的 self-normalized boundary。

**C5（authorization implementation）**：成功样本均值为 `mean_n`，区间为

```text
I_n = [mean_n - b_n(alpha), mean_n + b_n(alpha)],
b_n(alpha) = sigma * sqrt(2 log(pi^2 n^2/(3 alpha))/n).
```

代码只在 `lower > 0` 时返回 `KEEP`，只在 `upper < 0` 时返回 `ARCHIVE`，否则返回 `UNRESOLVED`；retrieval score、candidate rank 和 exposure budget 不能覆盖该授权条件。

## 3. Certificate–Censoring Bridge

### 命题 B1（代码路径与 sequential gate 等价）

在 C5 下，`anytime_qualification_certificate` 加上 `QualificationCertificate.authorized_action` 的输出，逐样本等价于 Theorem 13 的 anytime gate；使用 `SequentialQualificationGate` 时还逐路径强制 terminal keep/archive 后拒绝新 probe：

```text
lower > 0  <=>  keep,
upper < 0  <=>  terminal archive,
otherwise  <=>  unresolved.
```

失败 probe 不改变 `n`，因此不会被错误地当作一个统计观测。`plan_access` 只能在证书已经授权后生成 persistent action；未决 candidate 至多进入预先批准的 probe/defer 分支。

**证明。** `anytime_qualification_certificate` 对成功 observations 取算术均值，并以 `anytime_boundary(n, sigma, alpha)` 生成同一半径 `b_n`。`authorized_action` 使用严格不等号判断两个端点；跨零时两端点条件均不成立，返回 `None`。`SequentialQualificationGate.observe` 在首次单侧授权后设置 terminal action，后续 `observe` 直接拒绝；`close_horizon` 关闭未决 gate 而不伪造授权。`plan_access` 的 `persistent_actions` 分支只接受已授权的 keep/archive，非 persistent candidate 的 restore 还要求其进入 exposure set。因此代码输出与 gate 的三路 partition 完全一致，并且 C1 的“终止后不再 probe”不再只靠调用方自觉。∎

### 命题 B2（uniform soundness，非零 sign 类）

在 C4–C5 下，对任意固定 `tau != 0`，将 `keep` 视为只在 `tau>0` 时正确、将 `archive` 视为只在 `tau<0` 时正确，则

```text
P(ever authorize an action whose sign disagrees with tau) <= alpha.
```

**证明。** 条件 sub-Gaussian maximal/union bound 给出

```text
P(exists n >= 1: |mean_n-tau| > b_n(alpha))
 <= sum_n 6 alpha/(pi^2 n^2) = alpha.
```

在同时覆盖事件上，若代码授权 keep，则 `0 < lower <= tau`；若授权 archive，则 `tau <= upper < 0`。所以错误授权事件包含于 coverage-complement 事件，概率不超过 `alpha`。`tau=0` 属于无符号/未决情形，不被包装成 keep/archive 正确性结论。该结论是 contract-conditional，不能替代对真实 LLM certificate 的外部 coverage 测试。∎

### 命题 B3（margin completeness）

令 `Delta > 0`，令 `n_Delta` 是第一个满足 `b_n(alpha) < Delta/2` 的成功样本数。在 C4–C5 的覆盖事件上：

```text
tau >= Delta  =>  keep is authorized by n_Delta,
tau <= -Delta =>  archive is authorized by n_Delta.
```

**证明。** 当 `tau >= Delta` 时，在覆盖事件上

```text
lower_n = mean_n-b_n >= tau-2b_n > Delta-Delta = 0
```

于 `n=n_Delta` 成立；负号情形对称。若 horizon 内未获得 `n_Delta` 个成功 probe，则 gate 不承诺在该 horizon 内完成授权，这正是 Theorem 13 的 finite-horizon 截断情况。∎

### 命题 B4（cost transfer）

若 C1–C3 成立，且每个 archived epoch 的 attempt 概率取 `q`，则 B3 的 stopping rule 满足 Theorem 13 的成本上界：

$$
\mathbb E[C_H^{\mathrm{tot}}]
\le \frac{\nu n_\Delta}{q\rho}
   + \frac{c_{\mathrm{probe}}n_\Delta}{\rho}
   + c_{\mathrm{restore}}
   + (\nu+c_{\mathrm{probe}})H\alpha.
$$

若只知道 attempt 概率上限 `q`，该式是对“恰取 `q` 的实现策略”的上界，不是对所有更慢策略的统一上界。坏 coverage 事件上的 probe 次数与 transcript 相关，只能用路径级 `M_H <= H` 控制，因此尾项不能再乘一个边际 `q`。

**证明。** B3 在 coverage 事件上至多需要 `n_Delta` 个成功样本；在不对 coverage 事件作条件化的分解中，成功样本到达时间和 attempt 数分别由 `q*rho` 与 `rho` 的 Wald/负二项记账给出。coverage-complement 上最多损失 `nu H`，并最多产生 `H` 次 probe attempt，乘以其概率上界 `alpha` 即得尾项。∎

## 4. 与下界的闭环

命题 B1–B4 只给出上界和代码映射。下界不需要再引入新的 memory-specific 定理：对任意满足 C1–C3 且 `P_-(keep by H) <= alpha` 的 SQCAD 策略，完整 execution transcript 本身是 Theorem 12 的 transcript。二元 keep 事件的数据处理不等式、成功 observation 的链式 KL 分解和 Wald 恒等式分别给出：

```text
E_+[N_H] >= kl(1-alpha, alpha) / (2 mu^2/sigma^2),
E_+[T_H^arch] >= E_+[N_H]/(q*rho),
E_+[M_H] = E_+[N_H]/rho.
```

因此 SQCAD 实际授权路径在声明的 contract 内满足：

```text
implementation gate
  -> Safe(H, alpha)
  -> anytime upper bound (B4 / Theorem 13)
  -> transcript-KL lower bound (Theorem 12).
```

`qualification_access.py` 的纯函数用于 replay，`SequentialQualificationGate` 实现 terminal lifecycle 不变量；二者都只实现证书区间与授权投影，不观测或验证 `q`、`rho`、`sigma` 和 `tau`；这些量必须由调用方的 probe scheduler、实验校准或外部 contract 提供。因而这才是“理论证明导出框架设计”的闭环，而不是把一个纯函数误报成完整的在线安全策略。它不声称：

- 真实 LLM 的 certificate 自动满足 C4；
- 任意 observational OPE 或 target policy 满足 C1–C4；
- `evidence availability` 是唯一可能的额外状态；
- 旧的一次正 probe restore 具有 minimax matching。

## 5. 投稿前必须补的可证伪审计

1. 对独立 held-out mechanism families 检验 C4 的残差 tail、漂移和跨 epoch 稳定性；
2. 用独立标注或未来窗口检验真实 certificate 的 wrong-authorization rate，而不是把 toy Gaussian rate 当作 LLM coverage；
3. 若 `sigma`、`rho` 或 `tau` 由同一 transcript 估计，必须把估计步骤纳入 contract；否则只能报告“model-based certificate”；
4. 主稿、附录、历史报告中统一删除或标注旧的 $O(1/(q\rho))$、T1(b)/P4 matching 和“一次正 probe 安全恢复”表述。

当前推荐的理论主张是：

> 在显式的 SQCAD certificate contract 下，persistent authorization 等价于一个带 action-dependent censoring 的 anytime sequential test；其安全性、margin-completeness 和总成本上界由 B1–B4 给出，而同一 `Safe(H,alpha)` 类的 transcript-KL 下界给出信息论成本下限。
