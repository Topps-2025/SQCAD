#### **实验设计（精简但完整）**

**任务池（8 任务 × 15-20 episodes = 120-160 episodes）**：
```
从现有基准选取（避免从头设计）：
- AgentBench: 4-5 任务（代码生成、数据分析、决策规划）
- GAIA: 2-3 任务（多跳搜索、推理、工具使用）
- 或 ToolBench: 1-2 任务（多步工具调用）

标准：
- 需要多轮对话（10-30 turns）
- 需要长程记忆（证据跨 5+ 轮）
- 有明确成功判定（goal achievement）
```

**对比设置**：
```
Baselines:
1. Full-store BM25（upper bound）
2. SQCAD storage-constrained（B=12, 1.6k tokens）
3. Recency-12（lower bound）
4. BM25-stream（storage-matched，1.6k tokens）

固定：
- 相同 LLM（GPT-4 或 Claude Sonnet）
- 相同 workspace budget（B=12）
- 相同 retrieval scorer（frozen BM25/dense）
```

**评估指标**：
```
Primary:
- Task completion rate（binary: goal achieved = 1, else = 0）
- Success@k（前 k 次尝试中至少 1 次成功）

Secondary:
- Quality score（抽样 20%，GPT-4 as judge，1-5 分）
- Token cost（storage + exposure）
- Step efficiency（达成目标的平均步数）

Diagnostic:
- Failure mode 分类（memory-related vs retrieval vs reasoning）
```
