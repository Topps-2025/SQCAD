**解决方案**：

#### A. 在 §1 Introduction 增加 "Why Agent Memory is Different" 子节
```markdown
### 1.X Why persistent Agent-memory authorization differs from general POMDP

Standard POMDP assumes actions alter transition/emission (Shi et al., 2025), but 
the state space and action semantics are problem-given. Persistent Agent memory 
has three structural differences:

1. **Endogenous candidate regeneration**: keep/archive changes which memories 
   enter future C_t, not just their current exposure E_t.
2. **Workspace competition**: finite budget B makes retention a rivalry good.
3. **Evidence censoring**: archive may stop future observations until a priced 
   probe/restore reopens the channel.

These are not mere variable renamings: L1 §5.1 verifies that removing (3) drops 
the self-obscuring slope from 5.85 to 0.044 (Construction A.1 vs A.4c), and L3 
ablation shows that removing (1) costs +11.34 [0.90, 30.73] lifecycle value.
```

### 1.2 观测路径最小可行实现（可选但加分）

**问题**：Identification family A.3 的 g-formula/DR 只有公式，Reviewer 可能质疑 "没实现怎么知道能工作？"

**最小可行方案**（不需要真实 LLM 数据）：

#### A. 在 L1 Stage 1 增加 observational-route estimator
- 输入：协议路径的 rollout log（已有）
- 模拟：假装这是观测数据，用 propensity score + g-formula 估计
- 验证：与协议路径 ground truth 比较 bias/coverage

**伪代码**：
```python
def observational_route_estimator(rollout_log, propensity_model):
    # 输入已有的 protocol-route 轨迹
    # 估计 π(a|s) 并做 inverse-propensity weighting
    weights = 1.0 / propensity_model.predict(rollout_log['states'], 
                                              rollout_log['actions'])
    weighted_returns = weights * rollout_log['returns']
    return weighted_returns.mean(), weighted_returns.std()

# 在 L1 controlled world 中验证：
obs_estimate = observational_route_estimator(protocol_log, fitted_propensity)
assert abs(obs_estimate - protocol_ground_truth) < epsilon  # bias check
```

**验证目标**：
- bias < 2.0（vs 当前 protocol -0.47）
- 95% CI coverage ≥ 10/12（vs 当前 12/12）
- 证明观测路径在理想条件下可行

**工作量**：3-4 天实现 + 验证

**ROI 判断**：

### 2.2 增加 "end-to-end utility" 指标（可选但强推）

**问题**：当前只报告 Hit/Recall/F1，这些是 retrieval 指标，不是 lifecycle value

**补充方案**：定义 L2 的 **lifecycle-aligned metric**

```python
# 公开数据集的 lifecycle proxy
def l2_lifecycle_proxy(trace):
    """
    在无反事实分支的公开数据上，用可观测量代理 lifecycle value
    """
    return (
        10.0 * hit_rate(trace)           # 任务成功
        - 0.05 * exposure_tokens(trace)  # 暴露成本
        - 0.01 * storage_tokens(trace)   # 存储成本
        - 20.0 * scope_mismatch_rate(trace)  # 有害采纳（可检测的版本/scope 错误）
    )
```

**在 LongMemEval-S/LoCoMo 上报告该指标**：

| SQCAD | 0.754 | 1,631 | 2,722 | **7.26** |
| SQCAD + Guard-4 | 0.944 | 1,631 | 2,654 | **9.15** ✅ |

（数字为示例，需实际计算）

**优势**：

## 8. 风险与备选方案

### Risk 1：SimpleMem 运行失败或结果不利

**场景**：SimpleMem 在 n=500 上 hit > 0.9，显著超越 SQCAD

**应对**：
- ✅ **诚实报告**：不造假，不隐藏
- ✅ **重构叙事**：从 "SQCAD vs SimpleMem" → "compression vs retrieval 的 Pareto frontier"
- ✅ **强调互补性**："SimpleMem 的 hybrid retrieval 与 SQCAD 的 interval authorization 可结合"

**底线**：论文贡献是 **理论 + 框架 + 基准**，不是 "beat all baselines"

---

### Risk 2：L3 鲁棒性扫描发现 censoring 不稳定

**场景**：81 组合中只有 40% censoring 显著

**应对**：
- ✅ **诚实报告**：区分 "核心机制"（censoring 必要性）与 "参数敏感效应"（probe 净负）
- ✅ **降级声明**："Censoring 必要性在 [合理参数子集] 内稳定，不外推到任意参数"
- ✅ **future work**："需要更多 mechanism families 验证泛化性"

**底线**：一个显著效应 + 理论完整 > 多个不稳定效应

---

### Risk 3：R6 人工锚定 κ < 0.4

**场景**：Judge 与 oracle 一致性很低

**应对**：
- ✅ **反向解读**："人类 judge 也无法稳定判断 → 支持 'unresolved 是必要的'"
- ✅ **分层分析**：区分 high-certainty (|τ|>10) 与 crossing-fiber (|τ|<2) 的 κ
- ✅ **讨论意义**："LifecycleBench 的难度在于 lifecycle value 不等于 immediate relevance"

**底线**：低 κ 不一定是坏事，可以支持 "defer 决策的价值"
