**主定理层（Theorems A-D / 1-4）**：

```
Theorem A (Lifecycle Bellman Decomposition):
  Δ_t = Δ_t^imm + γ·Δ_t^access + γ·Δ_t^info

Theorem B (Score Sufficiency):
  Score φ is sufficient iff Δ_t is Doob-Dynkin measurable w.r.t. φ
  → Fiber regret bound when violated

Theorem C (Recoverability Monotonicity & Information Budget):
  (a) VoR^info ≥ 0 under Blackwell dominance + shared state kernel
```
