## 2. 已锁定的 Research Gaps

### Gap 1：Trajectory-Conditioned Associational Overfitting

候选生成、记忆暴露、任务难度、工作区组织、Agent 采纳和结果由同一历史策略共同产生。成功共现、频率或语义相关性因此不是可迁移贡献的充分证据。问题不是“Agent Memory 有没有因果方法”，而是能否在策略生成、时间变化的暴露下形成可审计的 treatment 和资格证据。

### Gap 2：Scoped Recoverable Governance

局部效应不能自动变成永久保留/删除。系统需要把作用域、版本、不确定性以及 false forgetting/false retention 的非对称代价映射为可撤回的访问动作，同时保证来源证据不被派生状态覆盖。

系统契约：

> 结构决定“测试什么”，付费干预决定“什么获得资格”，风险与作用域决定“未来如何访问”；任何派生状态不得覆盖原始证据。

## 3. 最终最小框架

1. **Source-Linked Treatment Adapter**：raw evidence 不可变；核心直接使用 session/turn/span pointer，语义 sidecar 只作可选增强；
2. **Conditional Associational Access**：association 只负责 shortlist 和低风险当前任务 fallback，不更新 causal state；
3. **Selective Scoped Causal Audit**：只在 qualification EVSI 高于成本时付费 probe；当前不主张性能收益；
4. **Sequential Scoped Qualification**：按 scope/version 输出 positive、negative、unresolved，并控制 family-wise/repeated-look error；
5. **Qualification-Gated Access Governance**：unresolved 冻结持久访问权；qualified evidence 才能 protect、veto、downweight、archive 或 recover；
6. **Evidence Survival / Relation Belief / Access Policy 分离**：archive 保留来源和 rollback；scope 变化需付费 revalidation。

在线 reader、planner、tools、向量库和 writer 是固定底座，不列创新。

## 5. 正式 v2/v3 结果

### 5.1 v2 失败反例

v2 错误允许 unresolved belief 参与风险衰减：

- weak-gap stationary Utility $\Delta$：-0.4313 ± 0.0796；
- stationary associational control Utility $\Delta$：-0.2067 ± 0.0572；
- 两个场景分别额外归档约 55.3% 和 53.1% 活跃记忆；
- FF-regret 明显恶化。

结论：证据不足不是负证据，不能获得改变长期访问权的权限。

### 5.2 v3 冻结协议

- schema：`minimal-framework-challenge.v3`；
- protocol hash：`F8AD57BDECECF20415163975648E5298C0540609C71774404DBAB768CE069C35`；
- source hash：`EC28087AB6379D80D62A37387F1E10B2F0DD3967F28F4BB4C3D6D24AD8ED8063`；

| 模块 | Utility $\Delta$ $\pm$ 95% CI | 结论 |
| --- | ---: | --- |
| causal evidence | -0.0138 ± 0.0068 | 当前实现负收益，降级审计 |

## 10. 不得跨越的论证边界

- controlled world ≠ public benchmark；
- probe potential outcome ≠ 真实可得反事实；
- atomic handle ≠ discovered causal variable；
- qualification ≠ 永久因果真理；
- archive ≠ physical deletion；
- more active memory ≠ stronger compression；
- lower false forgetting ≠ lower total harm；
- current causal audit ≠ performance improvement；
- safety invariant ≠ performance contribution。
