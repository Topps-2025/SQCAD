# 云端实验部署手册（手动执行版）

由于 SSH/SCP 需要交互式密码输入，请按以下步骤手动执行：

## 步骤 1: 上传实验脚本（在本地 Git Bash 执行）

```bash
# 1.1 上传 Phase 1 脚本
scp -P 16420 C:/Users/Lenovo/Desktop/Paper/SQCAD/scripts/cloud_phase1_experiments.sh root@connect.westb.seetacloud.com:/root/autodl-tmp/sqcad_workspace/SQCAD/scripts/
# 输入密码: o4F9PfgQzTR8

# 1.2 上传 Phase 2 脚本
scp -P 16420 C:/Users/Lenovo/Desktop/Paper/SQCAD/scripts/cloud_phase2_experiments.sh root@connect.westb.seetacloud.com:/root/autodl-tmp/sqcad_workspace/SQCAD/scripts/
# 输入密码: o4F9PfgQzTR8
```

## 步骤 2: 连接云端

```bash
ssh -p 16420 root@connect.westb.seetacloud.com
# 输入密码: o4F9PfgQzTR8
```

## 步骤 3: 启动 Phase 1 实验（在云端执行）

```bash
cd /root/autodl-tmp/sqcad_workspace/SQCAD
chmod +x scripts/cloud_phase1_experiments.sh
mkdir -p logs
nohup bash scripts/cloud_phase1_experiments.sh > logs/phase1_$(date +%Y%m%d_%H%M).log 2>&1 &
echo "实验已启动，进程 ID: $!"
tail -f logs/phase1_*.log
```

## 步骤 4: 监控实验（按 Ctrl+C 退出 tail，不会停止实验）

```bash
# 查看日志
tail -f logs/phase1_*.log

# 查看进程
ps aux | grep cloud_phase1

# 查看 GPU
watch -n 5 nvidia-smi
```

## 步骤 5: Phase 1 完成后启动 Phase 2

```bash
cd /root/autodl-tmp/sqcad_workspace/SQCAD
chmod +x scripts/cloud_phase2_experiments.sh
nohup bash scripts/cloud_phase2_experiments.sh > logs/phase2_$(date +%Y%m%d_%H%M).log 2>&1 &
tail -f logs/phase2_*.log
```

## 步骤 6: 实验完成后下载结果（在本地执行）

```bash
# 下载所有结果
scp -P 16420 root@connect.westb.seetacloud.com:/root/autodl-tmp/sqcad_workspace/SQCAD/transfer_to_local/*.tar.gz D:/SQCAD-database/cloud_results_20260822/

# 解压
cd D:/SQCAD-database/cloud_results_20260822/
tar -xzf sqcad_phase1_phase2_results_*.tar.gz
tar -xzf sqcad_phase2_data_*.tar.gz

# 复制到本地 SQCAD
cp *.json C:/Users/Lenovo/Desktop/Paper/SQCAD/results/
```

## 步骤 7: 关机

在 AutoDL 控制台手动关机（云端命令可能无效）
