# 解构—重组—关系分层—可恢复治理：框架思路草稿

> 本文件是设计探索，不是已确定的方法方案，也不应被写成 Introduction 的既定贡献。它用于检验“解构”是否能够回应当前 Introduction 中收紧后的两个 Research Gaps。

## 1. 直觉起点

一个记忆条目往往把多个事实、条件、实体、行动和结果压缩在同一段文本中。它在表面上是一个候选记忆，但对未来任务真正有用的可能只是其中一部分关系。

例如：

> 某人对坚果过敏；马卡龙含有坚果；因此该人不应食用马卡龙。

这里至少包含：

1. 主体：某人；
2. 条件/属性：对坚果过敏；
3. 对象属性：马卡龙含有坚果；
4. 行动约束：不应食用马卡龙；
5. 支持关系：过敏条件与食物成分共同支持行动约束。

对 Agent Memory 而言，解构的潜在价值不是把句子机械切碎，而是把复合记忆转换为带来源、时间、主体、作用域和版本的可寻址候选，使“哪一部分信息可能改变当前决策”能够被单独检查。

## 2. 与两个 Research Gaps 的对应关系

### Gap 1：内生曝光下的生命周期因果效应

解构可以回应 Gap 1 的“治理单元”部分：将一个整体轨迹、摘要或程序拆分为实体、属性、条件、行动、结果和关系候选，避免把整条记忆作为不可分的处理单元。

但解构本身不能解决内生曝光，也不能把共现变成因果。候选是否被生成、检索、放入工作区、被模型采用，仍受当前策略、任务难度、提示组织和共同暴露记忆影响。因此 Gap 1 至少需要三层区分：

| 层次 | 要回答的问题 | 不能直接推出的结论 |
|---|---|---|
| 表示层 | 记忆中有哪些可寻址成分和关系？ | 语言模型抽取出的成分不是因果真相 |
| 暴露层 | 哪些成分在什么策略和条件下进入候选/工作区？ | 被检索不等于被采用 |
| 效应层 | 暴露、遮蔽或替换某成分是否改变计划、行动或结果？ | 成功共现不等于该成分造成成功 |

因此，解构应被定位为因果治理的表示接口，而不是因果发现模块。

### Gap 2：作用域变化下的安全、分层和可恢复治理

解构可以为 Gap 2 提供更细粒度的治理对象：不同成分可以拥有不同的作用域、证据支持、更新时间和风险，而不必对整条记忆统一保留或删除。

但“因果链保留、相关链衰减”不能直接作为规则。原因包括：

- 关系标签可能抽取错误；
- 因果关系可能只在特定主体、时间或环境下成立；
- 相关关系经过多次独立、高质量验证后也可能具有很高行动价值；
- 一次性安全约束的平均效应可能很低，但错误遗忘代价很高；
- 关系强度和关系类型都会随新证据改变。

因此，分层治理应依据“证据支持 × 作用域合法性 × 估计效应 × 不确定性 × 错误成本”，而不是依据一个二元的 causal/associational 标签。

## 3. 建议的三阶段链路

### 阶段 A：证据保真的解构

输入仍然是历史交互轨迹、工具观察、任务描述和 Agent 行动记录。解构器输出候选单元，而不是事实定论：

- 实体：人、对象、地点、工具、任务；
- 属性：状态、偏好、能力、限制、成分；
- 条件：时间、主体、环境、权限、前置状态；
- 行动：建议、选择、工具调用、拒绝、保留；
- 结果：成功、失败、约束违反、代价；
- 关系候选：时间、支持、冲突、条件依赖、相关、可能因果。

每个候选必须保留原始 evidence span、来源、时间和作用域。无法定位来源的抽象关系只能进入“未验证候选”，不能直接控制遗忘。

### 阶段 B：任务条件化的重组与关系分层

当前任务不是被动查询，而是重组的条件。系统根据任务实体、目标、约束和时间窗口，从解构后的候选中构造局部路径或子图。

重组后的链路至少分为四类状态，而不是简单二分：

1. **已验证的机制/约束候选**：有明确条件、来源和干预证据；
2. **稳定的经验关联**：多次独立、高质量结果支持，但尚未具有机制识别证据；
3. **情境相关候选**：对当前任务有用，但作用域窄或证据不足以外推；
4. **未决或冲突候选**：关系方向、作用域或证据存在不确定性。

“因果”应是可升级、可撤回的资格状态，而不是由抽取器一次性赋予的标签。

### 阶段 C：分层、风险敏感、可恢复的生命周期治理

候选状态决定默认治理倾向：

| 候选状态 | 默认倾向 | 约束 |
|---|---|---|
| 已验证机制/约束 | 保留核心骨架，降低无关表面细节的暴露 | 仍需检查时间、主体和权限作用域 |
| 稳定经验关联 | 保留但允许按任务和证据强度调节访问 | 不能因高频共现自动升级为因果 |
| 情境相关候选 | 任务条件匹配时提高访问，离开作用域后降权 | 保留来源以支持恢复和再验证 |
| 未决或冲突候选 | 隔离、降权或请求额外证据 | 不得直接永久删除 |

治理动作优先采用可逆状态：active、downweighted、archived、isolated、restored。物理删除应由权限、撤回或保留期规则触发，而不是由低估计效应单独触发。

## 4. “因果链保留、相关链衰减”的可行性判断

这个想法可以作为研究假设，但不能直接作为论文方法定理。

### 可以成立的部分

- 复合记忆拆分后，关键条件和行动约束可能比整段文本更容易被审计；
- 保留证据支持的关系骨架，有望减少表面措辞、偶然共现和冗余细节的治理干扰；
- 对作用域窄、证据不足或不稳定的关联采用软降权，可能比硬删除更安全；
- 多次独立、跨表面变化且结果一致的经验关联可以逐步提高治理优先级。

### 必须避免的过度主张

- 抽取出“因果链”不等于发现真实因果结构；
- 图中路径存在不等于该路径会改变 Agent 行动；
- 低频不等于低价值，高频也不等于过时或错误；
- 相关性不应被统一衰减，稳定关联也可能是高价值程序记忆；
- 仅凭最终成功率不能估计某个成分的独立贡献。

## 5. 最小可证伪问题

若未来继续发展该框架，至少需要回答：

1. 在表面改写、实体替换和条件变化下，解构—重组是否比整段记忆或机械切分更能保留关键证据？
2. 在固定候选流和相同预算下，成分级遮蔽/替换是否能比成功共现更准确地预测行动变化？
3. 关系分层是否在跨主体、跨时间或跨工具条件下减少错误继承？
4. 分层软治理是否降低错误遗忘，同时保持或改善任务效用和资源成本？
5. 当解构质量下降、证据冲突或 overlap 不足时，系统能否退回保守的原始证据级治理？

只有这些问题通过受控对照和强基线比较，才能把“解构”从有吸引力的表示直觉提升为论文贡献。

## 6. 当前定位

现阶段最稳妥的定位是：

> 以证据保真的解构与任务条件化重组，构造可审计的记忆候选；再依据关系证据、作用域和干预效应的不确定性，实施分层且可恢复的生命周期治理。

这里的核心不是宣称“因果链天然值得保留、相关链天然应衰减”，而是研究能否把复合记忆中的不同证据关系转化为可验证、可撤回、风险敏感的治理状态。
