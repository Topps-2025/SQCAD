# 框架先验挑战与任务驱动自适应改进实验

> 状态：方法与实验草稿，不替代 `07-Introduction规范稿.md`。  
> 范围：主动挑战 `14-轨迹解构因果资格化与非对称衰减完整工程蓝图.md` 中的设计先验，提出可证伪的替代方案，并记录两项受控机制实验。

## 0. 一句话论证与术语账本

### 0.1 一句话论证

在轨迹条件化的 Agent Memory 生命周期治理中，本研究应把固定本体、双侧近似对称的全量解构和语义最短路径，改为**任务先行、记忆懒解构、价值信息驱动预算以及预算约束的反事实路径搜索**；受控模拟表明，该组合在廉价线索具有可校准信息量时可以提高净效用并保护低频关键记忆，但真实语义解析、干预可行性和公开 benchmark 上的优势仍未建立。

### 0.2 术语账本

| 规范术语 | 本文定义 | 避免混用 |
| --- | --- | --- |
| 事件日志 `Event Journal` | 对交互事件的不可变、可审计记录 | 活跃长期记忆、写入决策 |
| 记忆候选 `Memory Candidate` | 经写入门控保留、等待巩固或淘汰的候选单元 | 已确认有未来价值的记忆 |
| 已提交记忆 `Committed Memory` | 已进入默认长期索引，仍可降权、归档和恢复的单元 | 永久保存的知识 |
| 任务先行非对称解构 | 先解析当前任务，再按需解析少量候选历史 | 对任务和全部历史使用同一解析深度 |
| 价值信息 `Value of Information, VOI` | 一次额外解析或干预预期减少决策不确定性的净价值 | LLM 自报置信度或真实因果效应 |
| 预算约束反事实路径搜索 `BCPS` | 在固定干预预算下选择下一条值得探测的路径，并更新效应后验 | 从语义图直接发现因果结构 |
| 因果资格 | 经可审计、可估计、干预/调整和稳定性门控获得的可撤回状态 | 永久因果标签 |
| 治理状态 | 对默认访问权的保护、降权、归档、隔离和恢复 | 物理删除、模型参数 unlearning |

## 1. 结论先行：哪些原设计过于先验

当前蓝图最有价值的部分是证据谱系、完整决策日志、可撤回资格和可恢复治理；最需要修改的不是这些不变量，而是围绕它们的五个算法先验。

1. **不可变证据账本不等于写入策略。** 原始事件可以完整保留用于审计，但不能无差别进入活跃记忆。系统应区分事件日志、记忆候选和已提交记忆，并使写入同时服务未来任务价值和因果可识别性。
2. **固定实体—属性—条件本体不是充分解构。** 解构应从当前任务可能改变的行动、损失和反事实敏感因素反向发现候选处理，而不是把槽位抽取当作最终表示。
3. **任务和历史记忆不应近似对称解构。** 任务短、动态且定义本次决策，适合即时、高精度解析；历史长、冗余且多数无关，适合廉价召回后对少量候选懒解构。
4. **固定解析预算不符合“整体降噪大于引入噪声”的目标。** 预算应随任务风险、歧义、候选拥挤、冲突和边际信息价值变化，并以净效用而不是只以准确率评估。
5. **语义 beam search 或最短路径仍然主要是相关性搜索。** 它们适合生成候选，不适合认证机制。下一次 LLM/Agent 调用应由干预价值、效应不确定性、安全风险和成本共同决定。
6. **一次性因果标签和统一指数衰减都过强。** 关系应维护可更新的作用域内效应后验；证据存续、关系可信度和默认访问权应分开治理，不能由同一个时间函数同时决定。

因此，改进版方法的核心不是“建立更复杂的知识图”，而是把有限计算分配给**最可能改变治理决策的任务成分、记忆成分和反事实路径**。

- **Nature-style criteria：** 问题具有跨领域意义，但当前原创性取决于端到端耦合是否产生不可被单模块解释的增益。
- **Recommendation posture：** 不宜把“解构”本身写成创新；把创新收敛到自适应实验设计和可恢复治理策略。

- **Overall assessment：** “马卡龙—坚果—过敏”例子能解释为什么复合记忆需要拆分，但方法文本容易在因果推断、图搜索、遗忘和数据库状态机之间失去主线。

- **Consensus strengths：** gap 边界较严谨；证据保真、真实 propensity、可恢复状态和非对称错误成本值得保留。

## 4. 改进一：从“证据账本”到有选择的写入策略

### 4.1 三层写入而不是两极选择

不可变日志仍然必要，但它属于审计基础设施。真正的写入策略应有三层：

1. **Event Journal：** 低成本追加全部授权事件，保存时间、来源和版本；不默认进入语义索引，也不等同于长期记忆。
2. **Memory Candidate：** 通过轻量 novelty、constraint、surprise、future-use 和 identification gate 的候选；有短期 TTL 和探索配额。
3. **Committed Memory：** 经重复证据、未来任务触发或高风险保护门槛进入长期默认索引；仍可降权和恢复。

写入目标不应只是新颖性，而应近似优化：

$$
G_{write}(m,q)=
\mathbb E[\Delta V_{future}\mid m,q]
+\eta I_{identification}(m,q)
-\lambda C_{store/decompose}(m)
-\rho R_{privacy/error}(m).
$$

其中 $I_{identification}$ 表示该记录是否补充对照、负例、未暴露机会或潜在混杂信息。它不是可直接获得的真值，第一版可用 contextual bandit 或分层规则近似，并保留固定探索比例防止低频关键项永远没有反馈。

### 4.2 相对现有工作的边界

- SAGE 已有 novelty gate，因此本文不能把“选择性写入”本身作为创新；改进点是把未来治理可识别性纳入写入目标。
- Mem0 已有事实抽取和 CRUD，因此三层写入需要证明比事实级 ADD/UPDATE/DELETE 多获得了什么长期效用或审计能力。
- PREMem 已将推理前移到写入期，因此本文不应声称首个 pre-storage reasoning；差异在于任务条件化懒解析、来源撤回和干预日志。

## 5. 改进二：任务—记忆非对称的自适应解构

### 5.1 为什么不对称

任务是当前决策的查询端，通常短、动态且直接定义损失；历史记忆是供给端，长、冗余且绝大多数与本次任务无关。对两者同深度解析会产生两个浪费：简单任务被过度解析，长历史在被证明相关前就消耗大量 LLM 调用。

推荐流程为：

```text
轻量任务解析
→ 估计风险、歧义和候选拥挤
→ 必要时扩展任务解析
→ 原始/结构双通道召回
→ 只对高 VOI 候选记忆懒解构
→ 若工作区决策仍不稳定，再扩展路径或记忆解析
```

### 5.2 任务侧不只抽取实体和约束

任务侧优先抽取与决策直接相关的对象：

- 候选行动及可替代行动；
- 成功、连续损失和安全约束；
- 哪些任务属性改变时会改变最优行动；
- 风险等级、时间范围和不可逆工具；
- 需要区分的候选机制；
- 当前允许的解析、检索和干预预算。

这些输出用于提出 treatment candidate，而不是直接认定因果变量。

### 5.3 记忆侧采用多视图懒解构

每条历史保留：原文、低成本事件结构和任务条件化组件三个视图。只有当候选记忆可能改变行动、存在版本冲突或承担安全约束时，才运行更深解析。解析缓存键必须包含 `content hash + task abstraction + extractor version + scope`，避免把一个任务下的组件解释跨任务复用为真值。

### 5.4 VOI 预算调度

对待解析单元 $x$，定义工程近似：

$$
\operatorname{VOI}(x)=
\frac{
\widehat{Impact}(x)\cdot
\widehat{Uncertainty}(x)\cdot
\widehat{Risk}(q)\cdot
\widehat{DecisionProximity}(x)
}{C_{LLM}(x)+C_{latency}(x)}.
$$

调度器在边际 VOI 低于成本、预算耗尽或工作区决策稳定时停止。长期可以将该问题建模为 contextual bandit；第一版应先用透明启发式和离线真值模拟校准，避免策略学习掩盖机制。

## 6. 改进三：预算约束反事实路径搜索

### 6.1 从语义路径到实验路径

语义分数适合回答“哪些路径值得成为候选”，不适合回答“哪条路径改变行动”。改进版 BCPS 将每条候选路径维护为：

$$
p_i=(\mu_i,\sigma_i, c_i,r_i,\Gamma_i,P_i),
$$

其中 $(\mu_i,\sigma_i)$ 是局部效应后验，$c_i$ 是干预成本，$r_i$ 是错误决策风险，$\Gamma_i$ 是作用域，$P_i$ 是来源证据。

### 6.2 算法流程

1. 使用 BM25/dense/RRF、结构匹配和廉价机制线索生成有界候选路径；
2. 由历史观察调整、旧干预或保守先验初始化效应后验；
3. 计算每条路径的 VOI，选择最值得遮蔽、替换或簇级干预的路径；
4. 记录真实 propensity、共同暴露、位置和 token 变化；
5. 用干预结果更新后验；
6. 当最大 VOI 低于成本时早停；
7. 以作用域内效应稳健下界而不是语义分数选择工作区路径。

简化伪代码为：

```text
C ← semantic_and_structural_candidates(task)
posterior ← initialize(C)
while budget remains:
    i ← argmax_i VOI(path_i | posterior, risk, cost)
    if VOI(i) < stopping_threshold: break
    y_i ← safe_mask_replace_or_shadow_replay(path_i)
    posterior_i ← update(posterior_i, y_i)
return argmax_i scoped_lower_confidence_bound(posterior_i)
```

### 6.3 需要进一步形成创新的部分

单纯使用 VOI 并非新理论。Agent Memory 特有的算法贡献应落在：

- treatment 是带来源、作用域和共同暴露的记忆组件束；
- 候选流会被过去的遗忘动作内生改变；
- 允许簇级、规则—证据和位置匹配干预；
- 目标包含错误遗忘、错误保留和恢复代价；
- 缺少 overlap 时输出不可识别并保守治理。

这些约束应写入算法和实验，而不是只在系统描述中出现。

## 7. 改进四：因果识别从“分类”转向效应后验

### 7.1 识别对象

本文不应寻求完全“不受轨迹、任务和检索策略影响”的普遍因果成分，因为记忆暴露的效应本来就依赖工作区和决策环境。更可识别的目标是：

$$
\tau_{i}(h,\Gamma)=
\mathbb E[Y(Z_i=1)-Y(Z_i=0)\mid H=h,\Gamma],
$$

再检验该局部效应在预定义环境中的方向稳定性。所谓“剥离内生性”应改写为：通过真实曝光概率、受控干预和跨环境检验，减少策略生成曝光造成的偏差，而不是声称获得完全策略无关的因果结构。

### 7.2 推荐的识别阶梯

1. **观察调整：** OR/IPW/DR，前提是 propensity、overlap 和可观测混杂足够；
2. **微随机化：** 对安全、可自动判分的组件做遮蔽或版本替换；
3. **位置匹配对照：** 保持 token 长度、位置和格式，排除纯 prompt 结构效应；
4. **簇级干预：** 联合处理近重复或可替代记忆；
5. **二阶干预：** 仅对高价值冲突组件做少量 $2\times2$ 试验；
6. **shadow replay：** 不改变真实主线程，离线分叉不可冒险任务；
7. **序贯 OPE：** 评估治理状态改变未来候选流后的长期策略价值。

资格对象应保存 `estimate, interval, overlap, ESS, environment, parser_version, policy_version`，而不是单个 `causal=true`。

## 8. 改进五：衰减去先验化

原蓝图中的指数衰减可保留为透明 baseline，但不宜成为最终方法。推荐把三个状态分开：

1. **Evidence survival：** 原始证据是否仍合法、未撤回和可恢复；
2. **Relation belief：** 关系效应后验及其作用域；
3. **Access policy：** 当前任务下默认暴露概率或排序权重。

访问退出可改为 context-triggered hazard：

$$
h_i(t\mid x_t)=\sigma(
\theta^	op x_t
),
$$

其中 $x_t$ 包含任务失配、版本漂移、冲突、效应不确定性、检索拥挤、资源成本、误忘代价和恢复成本。该形式允许“长期未访问但高风险”的记忆保持低 hazard，也允许“刚被频繁访问但已经过时”的记忆快速退出。第一版可以用逻辑回归或小型 contextual bandit，且必须与固定指数、FadeMem-like 和 Oblivion-like 策略比较。

## 9. 与现有 Agent Memory 研究的对照定位

下表基于当前本地原文索引和研究地图，不替代最终逐篇引用核验。

| 研究方向 | 已覆盖能力 | 本方案不应重复声称 | 可检验的剩余接口 |
| --- | --- | --- | --- |
| SAGE、Mem0、PREMem | novelty/write gate、事实 CRUD、预存储抽取与关系 | 首个选择性写入、首个写前推理 | 写入是否同时提升未来效用与可识别性 |
| A-MEM、FraCom | 关联笔记、谓词—论元切分与按需组合 | 首个可组合记忆结构 | 组件能否成为有来源、可干预、可撤回的治理单元 |
| HingeMem、MemSearch-o1 | 任务条件化检索深度、路径扩展与回溯 | 首个自适应路径搜索 | 下一次搜索是否由反事实信息价值和错误成本决定 |
| FadeMem、Oblivion | 多信号差异衰减、访问性控制与读写联动 | 首个自适应遗忘或访问衰减 | 代理信号与作用域内增量效应如何区分 |
| Memory Worth | 成功/失败共现驱动信任和抑制 | 首个结果反馈治理 | 内生曝光下的关联信号如何校正 |
| DeMem | 决策充分性和率失真压缩 | 首个决策导向记忆压缩 | 决策充分性与干预效应、恢复风险如何联合 |
| CMI、MemAudit、ActMem、Trivium | 局部干预、审计、因果—语义图和长期因果控制 | Agent Memory 尚无因果分析 | 局部因果证据如何进入连续、可恢复的生命周期治理 |

因此，最稳妥的方法贡献候选是：

> 在策略生成、时间变化的记忆曝光下，以任务优先的非对称解构和预算约束反事实探测，为记忆组件建立作用域内、可撤回的效应资格，并据此优化可恢复访问治理的净效用。

## 10. 实验 A：非对称自适应解构预算

### 10.1 协议

- 50 个随机种子，每个种子 200 个任务；
- 每任务 32 条候选，包含 rare-critical、common-useful、stale、spurious 和 unrelated；
- 固定工作区为5条记忆；
- 所有方法共享任务、候选、解析错误随机数和 evaluator；
- 成本：每个任务解析单元0.015，每次记忆解析0.035；
- 比较 raw retrieval、全量解构、固定对称预算、任务先行固定懒解构和 VOI 自适应非对称解构。

### 10.2 主结果

表中为均值，括号内为95%置信区间半宽。

| 方法 | 毛效用 ↑ | 净效用 ↑ | 低频关键召回 ↑ | Stale exposure ↓ | 记忆解析调用 ↓ | 解析成本 ↓ |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Raw retrieval | 0.002 (0.012) | 0.002 (0.012) | 0.755 (0.009) | 0.825 (0.007) | 0.000 | 0.000 |
| Full decomposition | **1.368 (0.013)** | 0.158 (0.013) | **0.999 (0.001)** | **0.124 (0.005)** | 32.000 | 1.210 |
| Fixed symmetric budget | 0.456 (0.011) | 0.156 (0.011) | 0.766 (0.009) | 0.771 (0.008) | 6.000 | 0.300 |
| Task-first lazy memory | 0.455 (0.011) | 0.185 (0.011) | 0.766 (0.009) | 0.772 (0.008) | 6.000 | 0.270 |
| VOI adaptive asymmetric | 0.991 (0.014) | **0.677 (0.013)** | 0.991 (0.002) | 0.537 (0.008) | 7.446 | 0.314 |

全量解构获得最高毛效用和最低 stale exposure，但其固定成本使净效用很低。任务先行固定懒解构只比固定对称预算节省任务侧成本，并没有解决候选选择问题。VOI 方法通过风险、歧义、机制线索、冲突线索和不确定性调节调用，在该合成世界中取得最高净效用，并接近全量解构的低频关键召回；但它的 stale exposure 明显高于全量解构，不能声称全面更优。

### 10.3 廉价线索噪声压力测试

| Cue noise | 方法 | 毛效用 ↑ | 净效用 ↑ | 低频关键召回 ↑ | Stale exposure ↓ |
| ---: | --- | ---: | ---: | ---: | ---: |
| 0.13 | Full | 1.368 | 0.158 | 0.999 | 0.124 |
| 0.13 | Adaptive | 0.991 | 0.677 | 0.991 | 0.537 |
| 0.30 | Full | 1.354 | 0.144 | 0.999 | 0.135 |
| 0.30 | Adaptive | 0.918 | 0.604 | 0.986 | 0.623 |
| 0.50 | Full | 1.347 | 0.137 | 0.998 | 0.147 |
| 0.50 | Adaptive | 0.825 | 0.510 | 0.971 | 0.684 |

随着线索噪声增加，自适应策略仍有正净效用，但毛效用、关键召回和 stale exposure 都明显恶化。这支持把**廉价线索的校准质量**列为方法门槛，也否定了“自适应预算天然有效”的过强表述。

### 10.4 该实验支持与不支持什么

支持：当低成本任务/候选线索具有信息量、全量解析成本显著时，非对称 VOI 调度可以改善效果—成本前沿。  
不支持：真实 LLM 已能产生这些线索；成本系数符合真实 API；该方法在 LongMemEval、LoCoMo 或真实工具 Agent 上有效。

## 11. 实验 B：预算约束反事实路径搜索

### 11.1 协议

- 50 个随机种子、每个种子200个 episode，共10,000个 episode；先在每个种子内聚合，再以50个 seed-level 均值计算置信区间，避免把同一生成过程内的 episode 当成完全独立重复；
- 每个 episode 16条路径，包括3条一般因果路径、1条低语义相似的 rare-critical 路径、4条高语义 spurious 路径、3条 stale 路径和5条 neutral 路径；
- 默认干预算8.0，干预观测标准差0.65；
- 所有方法共享路径、潜在效应、先验、观测随机数、预算和 evaluator；
- 比较 semantic top-1、最短/最低成本路径、贪心 causal LCB 和 BCPS。

### 11.2 主结果

| 方法 | Selected-path regret ↓ | 真阳性选择 ↑ | Rare-critical 选择 ↑ | 干预成本 ↓ | 净效用 ↑ |
| --- | ---: | ---: | ---: | ---: | ---: |
| Semantic top-1 | 2.215 (0.008) | 0.030 | 0.000 | **0.000** | -0.149 |
| Shortest path | 1.951 (0.014) | 0.253 | 0.064 | **0.000** | 0.115 |
| Greedy causal LCB | 1.090 (0.008) | 0.967 | 0.033 | 7.749 | 0.356 |
| BCPS | **0.135 (0.007)** | **0.998** | **0.851 (0.007)** | 3.779 | **1.629 (0.009)** |

语义 top-1 在该压力世界中几乎总被高相似伪相关或陈旧路径吸引。贪心 LCB 能避免多数有害路径，但会反复验证当前领先者，使用96.9%的预算且难以发现低语义相似的 rare-critical 路径。BCPS 通过风险、机制线索、不确定性、竞争前沿和重复折扣选择探测对象，平均使用47.2%的预算并显著降低 regret。

### 11.3 预算敏感性

| 预算 | 方法 | Regret ↓ | Rare-critical ↑ | 干预成本 ↓ | 净效用 ↑ |
| ---: | --- | ---: | ---: | ---: | ---: |
| 2 | Greedy LCB | 1.140 | 0.043 | 1.774 | 0.785 |
| 2 | BCPS | 0.323 | 0.701 | 1.692 | 1.608 |
| 4 | Greedy LCB | 1.113 | 0.037 | 3.746 | 0.654 |
| 4 | BCPS | 0.159 | 0.836 | 3.142 | 1.656 |
| 8 | Greedy LCB | 1.090 | 0.033 | 7.749 | 0.356 |
| 8 | BCPS | 0.135 | 0.850 | 3.779 | 1.629 |
| 12 | Greedy LCB | 1.090 | 0.032 | 11.745 | 0.038 |
| 12 | BCPS | 0.138 | 0.850 | 3.775 | 1.626 |

BCPS 在预算4左右趋于饱和并早停；贪心方法随着预算增加持续重复验证，净效用反而下降。这一现象支持显式停止规则，但数值依赖当前成本系数。

### 11.4 线索噪声敏感性

| Cue noise | 方法 | Regret ↓ | Rare-critical ↑ | 干预成本 ↓ | 净效用 ↑ |
| ---: | --- | ---: | ---: | ---: | ---: |
| 0.12 | Greedy LCB | 1.090 | 0.033 | 7.749 | 0.356 |
| 0.12 | BCPS | 0.135 | 0.850 | 3.779 | 1.629 |
| 0.30 | Greedy LCB | 1.150 | 0.034 | 7.747 | 0.297 |
| 0.30 | BCPS | 0.173 | 0.819 | 4.252 | 1.553 |
| 0.50 | Greedy LCB | 1.218 | 0.033 | 7.749 | 0.229 |
| 0.50 | BCPS | 0.244 | 0.768 | 4.735 | 1.444 |

BCPS 的优势随 cue noise 增加而缩小，并需要更多干预成本。该实验只能证明算法能够利用有信息量的线索进行预算分配；它不能证明真实 Agent Memory 中存在同等质量的机制和风险线索。

## 12. 对14号工程蓝图的具体修改建议

1. 在 `EvidenceLedger` 前后明确区分 `EventJournal`、`MemoryCandidate` 和 `CommittedMemory`，补充 write propensity、未写入理由和识别价值字段。
2. 将“历史记忆与当前任务的证据保真双侧解构”改为“任务先行的非对称自适应解构”；任务深解析，历史懒解析。
3. 固定实体/属性本体降级为第一层 sidecar；增加 action/loss/counterfactual-sensitivity 驱动的 treatment candidate discovery。
4. 在 `DecompositionWorker` 和 `PathComposer` 之间增加 `BudgetScheduler`，统一管理任务解析、记忆解析和干预调用。
5. 将 beam/k-shortest-path 明确限制为候选生成器；新增 `CounterfactualPathExplorer` 执行 BCPS。
6. `effect_estimate` 改为可更新后验和作用域记录，不用一次性资格标签覆盖历史估计。
7. 将一个指数 decay rate 拆为 evidence status、relation belief 和 access hazard 三个状态；指数公式只作为 baseline。
8. 在统一 runner 中增加位置匹配 placebo、簇级 treatment、真实 propensity 和 cue-quality dashboard。
9. 实验主指标改为净效用、错误遗忘—错误保留前沿、低频关键召回、干预 regret 和总 token/延迟成本。

## 13. Go/No-Go 门槛与下一步实验

### 13.1 Go 条件

- 双人标注 Gate A 达到 Factor F1、Relation F1、provenance 和 scope 门槛；
- 廉价机制/冲突线索在独立集上校准后，能显著优于随机或纯语义预算分配；
- 在固定 reader、候选流和总成本下，非对称预算优于 full、fixed-symmetric 和 task-first-fixed；
- BCPS 优于 semantic、shortest、greedy LCB、随机探索和标准 best-arm/active-learning 基线；
- 加入位置匹配 placebo 和簇级 treatment 后，效应方向仍稳定；
- 至少一个公开 Agent Memory 数据集上出现可复核的帕累托改进。

### 13.2 No-Go 或收缩条件

- 真实 parser 不能稳定提出可干预组件；
- 廉价线索在独立集上接近随机，导致 VOI 调度退化；
- 真实任务不允许获得足够 overlap 或安全干预；
- BCPS 的收益可完全由增加 token、强检索或 privileged cue 解释；
- item-level causal 或 DeMem/Oblivion-like 基线在同成本下等效；
- 生命周期候选流变化使离线 OPE 排序失真。

若出现上述条件，论文应收缩为**可审计的诊断协议、预算调度 benchmark 或可恢复治理基础设施**，而不是坚持完整因果遗忘系统主张。

## 14. 当前支持的最终判断

改进路线能够更直接回应 trajectory-conditioned associational overfitting：写入阶段保存可形成对照的信息，任务阶段决定解析什么，路径阶段用有限干预区分表面相关与局部增量作用，治理阶段根据作用域内效应后验和非对称错误成本调整默认访问权。它比“全量解构后保留因果骨架”更严谨，也更接近工程成本约束。

但当前最强的结论只能是：

> **任务先行非对称解构和预算约束反事实路径搜索是值得进入真实 Agent Memory 实验的算法候选；它们是否构成论文创新，取决于真实线索质量、干预可识别性以及在统一成本下相对强基线的不可替代增益。**
