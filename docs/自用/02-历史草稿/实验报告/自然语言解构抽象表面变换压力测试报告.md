# 自然语言解构—抽象表面变换压力测试

## 1. 实验定位

该实验在已有抽象 simulator 与真实 LongMemEval Gate A 之间增加一个中间证据层：生成带自然语言表面形式的证据轨迹，并为每条轨迹保留潜在因子、结果和 OOD 反事实标签。它不是公开 benchmark，也不模拟真实 LLM 的语义能力；`parser_accuracy` 只是显式的测量误差旋钮。因此结果用于检验机制必要性与误差敏感性，不能写成语义解析器的真实准确率或 SOTA。

运行脚本：`natural_language_decomposition_stress_test.py`。默认 50 个随机种子、24 个机制组、每组 3 个 OOD 记录；训练和测试使用不同实体名称、不同属性词和不同句式。

## 2. 对照方法

1. `raw_surface`：按完整实体/轨迹记忆，无法迁移到 OOD 表面；
2. `lexical`：按属性词记忆，无同义表述抽象；
3. `decomposition_only`：可产生因子候选，但动作映射仍绑定具体实体，不能跨情境复用；
4. `proposed`：从带噪因子候选估计有来源的 factor→outcome 规则，再应用于 OOD；
5. `oracle_joint`：无误差的联合表示上界。

## 3. 50-seed 结果

| parser accuracy | raw / lexical / decomposition-only OOD accuracy | proposed OOD accuracy | rule precision | rare-critical recall |
| ---: | ---: | ---: | ---: | ---: |
| 0.90 | 0.667 / 0.667 / 0.667 | **0.946 ± 0.007** | 0.917 ± 0.012 | 0.900 ± 0.050 |
| 0.60 | 0.667 / 0.667 / 0.667 | **0.791 ± 0.013** | 0.697 ± 0.022 | 0.680 ± 0.072 |
| 0.50 | 0.667 / 0.667 / 0.667 | **0.725 ± 0.012** | 0.617 ± 0.024 | 0.467 ± 0.097 |

表中为均值 $\pm$ 95% 跨 seed 置信区间半宽；`oracle_joint` 在三个设置下均为1.0。结果说明：

- 表面实体、属性词和仅因子但无抽象均无法在 OOD 上复用机制；
- 联合表示在高质量候选下显著改善 OOD 准确率；
- 表示质量下降时，规则 precision 和低频关键记忆保全率先恶化，即使平均准确率仍高于多数类 baseline，也不能据此放宽 Gate A；
- 该结果与已有 governance group-noise simulator 一致：联合机制的收益依赖解构/分组质量，不能把抽象本身视为无条件增益。

## 4. 研究含义与边界

该实验支持一个更精确的机制命题：解构提供跨表面变化的可寻址因子，抽象提供在作用域内复用该因子的规则；二者缺一时，代理只能记住整体表面或局部候选。它不证明真实自然语言解构器已经达到可用精度，也不替代 Gate A 的人工 Factor/Relation/provenance/scope 评测。

因此，论文主实验必须同时报告 OOD 任务效用、规则 precision、低频关键 recall、作用域/来源覆盖和错误泛化率；若真实 Gate A 不通过，系统应回退到原始证据或 item-level causal 治理，而不是继续扩大抽象层。

- `natural_language_decomposition_stress_test_acc060.json`：parser accuracy 0.60；
