## 2. A1：heavy-tail 控制（已知真值）

**配置**：x ~ lognormal(1)（偏态、重尾，n=30），真值 θ = E[x] = exp(0.5) = 1.6487；reps=2000，n_boot=999。四种 CI 方法的名义覆盖（目标 95%）：

| 方法 | 覆盖 | 差于名义 |
|---|---|---|
| normal（现状） | 0.8745 | −7.6 pp |
| percentile（一阶） | 0.877 | −7.3 pp |
| BCa（偏差校正+加速） | 0.892 | −5.8 pp |
| **studentized（percentile-t，默认）** | **0.9275** | **−2.3 pp** |

**读法**：

1. 正态近似在偏态下系统性欠覆盖（Gate 3 机制的直接复现）；plain percentile 是一阶方法，共享同样的偏态偏差；
2. BCa 修正偏态有限；方法选择阶段的探针比较显示 BCa 在尖峰分布（t_4）下反而退化，**studentized 在偏态与尖峰下都最接近名义**——因此选为模块默认；
3. n=30 时即使 studentized 也只是 0.93 而非 0.95——如实标注：bootstrap 修复的是**系统性欠覆盖**，不是小样本精确性。

## 3. A2：D0 世界 seed-level coverage（Gate 3 复现与修复）

**配置**：世界与 Gate 3 样本量曲线完全一致（n_oracle=150、n_epochs=80），8 seeds（3..10，含 Gate 3 的 3/5/7）、12 条记忆、n_boot=999；两个 n_trajectories 配置 {100, 300}。两个覆盖靶子：

- **within-seed normal vs 该 seed 的 realized truth**——Gate 3 的复现（错误靶子：CI 只定价 within-seed 噪声）；
- **seed-level normal / seed-level bootstrap vs 每条记忆的 seed 均值 truth**——正确靶子 E_s[θ_s] 的一致估计（oracle MC 噪声随 1/√(n_oracle·n_seeds) 收缩，远小于 seed-level CI 半宽）。

| n_trajectories | within-seed normal（错误靶子） | seed-level normal | seed-level bootstrap（默认） | within 宽度 | seed bootstrap 宽度 |
|---|---|---|---|---|---|
| 100 | 0.9688（96 检） | 0.5000（12 检） | 0.5000（12 检） | 4.763 | 1.111 |
| 300 | **0.7917**（96 检） | 0.9167（12 检） | **1.0000**（12 检） | 2.759 | 1.451 |

Gate 3 锚点（seeds 3/5/7，36 检）：n_traj=100 → 0.861，n_traj=300 → **0.722**。

**读法（两个体制，缺一不可）**：

1. **within-seed 列复现 Gate 3 的 anti-conservatism（n_traj=300 → 0.792，Gate 3 为 0.722；seed 集更大所以略高）**：n_trajectories 增大 → within-seed CI 收缩（宽度 4.763 → 2.759）→ 覆盖继续下降——错误靶子（CI 只定价 within-seed 噪声）的失败随样本量加深。n_traj=100 的 0.969 是"偶然校准"（CI 半宽 ~2.4 吞掉真值噪声），随 seed 集漂移（此前观测 0.86–0.95）；
2. **seed-level 列修好靶子后斜率反转**：覆盖随 n_trajectories **上升**（0.50 → 0.92–1.00）而非下降——采样单元修正消除的是"覆盖随样本量递减"的 anti-conservatism。但必须如实标注：**检查本身含 oracle MC 噪声**——seed 均值 truth 是随机靶子（sd ≈ 0.35），所以观测覆盖是名义 95% 的下界（8 seeds 时估计噪声占比更大），不能声称"达到 95%"；
3. **n_traj=100 的 seed-level 0.50 是检查噪声封顶，不是估计量偏差**：每 seed 估计噪声 1.22（within-seed se），8 seeds 平均后 gap sd ≈ 0.55 与 CI 半宽 0.56 同量级——区间是诚实的，检查太弱；n_traj=300 时每 seed 噪声降至 0.70，seed-bootstrap 12/12 全中（其中 m5 是 normal CI 差 0.04 未中的边缘例，studentized 的加宽恰好救回——见 §4 B1 同一机制）；
4. **12 条记忆为 5 组同角色副本**（useful×3、short_term×2、bridge×2、harmful×2、neutral×3）：A2 中每条记忆独立调用估计器（rng 每记忆重播种），同组副本估计逐位相同（40.67342422938469 等），truth 因 oracle 共享 rng 流而略异——覆盖计数按 96/12 计，同组副本不独立；
5. 结论：**Gate 3 的 0.722 不是估计量坏，是 CI 的采样单元错**；统一合同主表的报告单元从此刻起是 seed-level paired bootstrap（§4）。
