## 1. 目的与合同

Gate 1 主表回答"谁在相同合同下 utility 更高"；Gate 4 回答"谁的**净收益**更高"。原始 utility 会掩盖成本结构：keep_all 的 utility 0.650 高于多数治理基线，但它每步烧 962 token 且每步暴露 stale 记忆。

**合同**（默认系数全部可扫）：

$$V = \sum_t \gamma^{t-1}\left[ U_t - \lambda_{\mathrm{tok}}\cdot C_{\mathrm{tok},t} - \lambda_{\mathrm{llm}}\cdot C_{\mathrm{llm},t} - \lambda_{\mathrm{probe}}\cdot C_{\mathrm{probe},t} - \lambda_{\mathrm{lat}}\cdot C_{\mathrm{lat},t} - \rho_{\mathrm{harm}}\cdot R_{\mathrm{harm},t} \right] - \rho_{\mathrm{ff}}\cdot R_{\mathrm{ff}}$$

| 通道 | 定义 | 默认系数 | 依据 |
|---|---|---|---|
| $U_t$ | required-hit utility（评估器唯一成功信号） | — | Gate 1 合同 |
| $\lambda_{\mathrm{tok}}\cdot C_{\mathrm{tok}}$ | 每步工作区 token（容量成本） | $\lambda_{\mathrm{tok}}=0.001$ | 与 Gate 2 情节值一致 |
| $\lambda_{\mathrm{llm}}\cdot C_{\mathrm{llm}}$ | LLM 端点成本 | **0** | 所有传输规则都是流的确定性函数；LLM 层已在 Gate 1 标注 `not reproduced`，不给它虚构价格 |
| $\lambda_{\mathrm{probe}}\cdot C_{\mathrm{probe}}$ | 资格期探测（step 0 一次性收费） | $\lambda_{\mathrm{probe}}=0.05$ | Gate 4 探测合同 |
| $\lambda_{\mathrm{lat}}\cdot C_{\mathrm{lat}}$ | 每步暴露条目数（wall-clock 代理） | $\lambda_{\mathrm{lat}}=0.002$ | 工作区越大读取越慢 |
| $\rho_{\mathrm{harm}}\cdot R_{\mathrm{harm}}$ | stale 暴露指示（风险通道） | $\rho_{\mathrm{harm}}=0.35$ | 与 Gate 1 评估器罚分一致 |
| $\rho_{\mathrm{ff}}\cdot R_{\mathrm{ff}}$ | 低频保护费：$4 - \mathrm{rare\_kept\_final}$（情节级一次性） | $\rho_{\mathrm{ff}}=0.25$ | 未保护低频关键记忆的代价 |

探测层（Gate 4 新增，`_probe_qualification`）：risk_gated_decomp_abstract / causal_item 探测**未识别条目**（$item\_effect\_lcb \le -10^5$）；trivium 探测未识别**或低量级**条目（其论文的显式探测层，成本按 Gate 1 注释落在这里）；其余传输不探测。探测以 oracle 真值组效应 + 流证据噪声（$\sigma=0.10$）解析条目效应，受合同 probe_budget 限制。

4. **效率（utility/1k token）**：前列策略 ≈ 2.74，keep_all 1.02，no_memory 0——token 效率把"更聪明的记忆"与"更大上下文"分开。

## 3. E2：utility–risk–cost frontier（四个价格区间）

| 区间 | 系数 | winner | runner-up |
|---|---|---|---|
| default | 默认 | **risk_gated_decomp_abstract** (38.48) | causal_item (38.41) |
| risk_averse | ρ_harm=1.0 | **risk_gated_decomp_abstract** | causal_item |
| latency | λ_lat=0.02 | **risk_gated_decomp_abstract** | causal_item |
| capacity | λ_tok=0.01 | **no_memory** (8.95) | —（记忆策略全部转负） |

**必须如实报告的边界**：

- **默认区间 SQCAD 对配探测 CMI 的领先只有 0.07（0.2%）**——充足探测预算下两者收敛（都把未识别条目解析后保留）。框架的实质性优势不在"默认价格下的均值差距"，而在：探测需求更低、以及探测预算受限时的结构性优势（见 E3 扫描）；
- **极端容量价格翻转 frontier 到 no_memory**：λ_tok=0.01（10× 默认）时任何记忆治理的 token 成本都吞掉收益。这是合同参数的诚实结论——不声称"记忆治理总值得"。

## 4. E3：显式 break-even 与敏感性扫描

**Break-even（$\lambda_{\mathrm{probe}}^*$ 使 $V(\mathrm{SQCAD}) = V(\text{最优基线})$）**：

- 对**最优基线 causal_item（配探测）**：两者探测需求相等（各 2.9），领先不随探测价格变化 → **无有限盈亏平衡点**（"no finite probe price erases the lead"）；
- 对**最优非探测基线 rrf**：$\lambda_{\mathrm{probe}}^*$ = **5.53** = 默认价格 0.05 的 **110 倍**——探测在价格上升两个数量级之前都值得。

**ρ_harm × λ_tok 扫描（全传输池，9 格）**：

| | λ_tok=0.001 | λ_tok=0.005 | λ_tok=0.01 |
|---|---|---|---|
| ρ_harm=0 | SQCAD | **no_memory** | **no_memory** |
| ρ_harm=0.35 | SQCAD | **no_memory** | **no_memory** |
| ρ_harm=1.0 | SQCAD | **no_memory** | **no_memory** |

→ SQCAD 在全部三个风险价格下、容量价格 5× 以内保持最优；容量价格 ≥5× 时 frontier 翻转给 no_memory（6/9 格如实标注）。

**探测预算扫描（$probe\_budget \in \{0, 2, 4, 8\}$，默认价格）**：

| probe_budget | SQCAD | causal_item | trivium | 差值 ($\mathrm{SQCAD}-\mathrm{CMI}$) |
|---|---|---|---|---|
| 0 | **36.53** | 29.95 | 23.02 | **+6.6** |
| 2 | **38.49** | 37.96 | 22.92 | +0.53 |
| 4 | **38.48** | 38.41 | 22.82 | +0.07 |
| 8 | **38.48** | 38.41 | 22.62 | +0.07 |

**这是框架与 CMI 的关键分离点**：零探测预算下 SQCAD 靠**组作用域回退**（Theorem 3(d) 的资格回退路径）保持 rare 保护 0.83，而 CMI 把全部未识别条目按点估计 −1e6 归档（rare 0.17）——V 差 6.6。探测预算增加时 CMI 追赶并在满预算下与 SQCAD 收敛。**"SQCAD 比 CMI 好"的正确表述是：在相同探测预算下，框架把探测需求限定在真实识别缺口（2.9 次），并在预算不足时用组证据兜底；CMI 在无探测时塌陷。**

## 5. E4：负面生命周期恢复结果（保留）

评审要求保留"生命周期价值不可识别时，系统拒绝做持久访问决策"的负面结果。实现两个**强制决策对照**（非主表行，强制对照组按合同收到同一流）：

- **blind_gate（点估计强制）**：未识别条目按原始点估计（−1e6）决策，无组回退、无 harm veto、无探测——探测前的 causal_item 与其**逐位相同**（同流同评估器同 episode）；
- **forced_restore（强制恢复）**："when in doubt, keep"——每个未识别条目恢复进工作区，剩余槽位按门控评分填充。

并在**变体世界**（标准 episode 后处理：75% 的 stale 条目变为未识别——识别缺口内含有害记忆，流对块内所有策略一致）上重跑。

| 世界 | 策略 | V | hit | rare | stale | probes |
|---|---|---|---|---|---|---|
| 标准 | blind_gate | 29.95 | 0.885 | **0.175** | 0.000 | 0 |
| 标准 | forced_restore | 38.62 | 1.000 | 0.90 | 0.000 | 0 |
| 标准 | risk_gated_decomp_abstract | 38.48 | 1.000 | 0.90 | 0.000 | 2.9 |
| **变体** | **blind_gate** | 29.95 | 0.885 | 0.175 | 0.000 | 0 |
| **变体** | **forced_restore** | **8.73** | 0.890 | 0.88 | **1.000** | 0 |
| 变体 | risk_gated_decomp_abstract | **38.19** | 1.000 | 0.82 | 0.000 | 8.0 |
| 变体 | causal_item | 37.88 | 1.000 | 0.68 | 0.000 | 8.0 |
| 变体 | trivium | 22.70 | 1.000 | 0.80 | 0.700 | 8.0 |

**读法（两世界缺一不可）**：

1. **标准世界**：识别缺口内只有保护性记忆。forced_restore 恰好免探测地拿到保护（38.62，比门控 SQCAD 高出的 0.14 恰好等于探测成本）——**"强制恢复在保护性世界恰好正确"必须如实报告**，不能只报变体世界的崩塌；
2. **变体世界**：同一规则把未识别害记忆每步暴露 → stale 1.000 → V 崩塌至 8.73（−29.9）。**强制恢复把识别缺口转化为持续暴露的害记忆**——这就是被保留的负面生命周期恢复结果：识别失败处不做持久决策不是保守主义，而是避免把缺口变成伤害；
3. **blind_gate 的代价是价值**（rare 0.175、ff 0.82、hit 0.885，两世界相同）：把未识别点估计当作可决策证据，等价于把 75% 的低频关键记忆直接归档；
4. **门控 SQCAD 两世界稳定**（38.48 / 38.19）：探测（预算内解析）或 unresolved（预算外组回退）拒绝在识别缺口上做持久决策；配探测的 causal_item / trivium 在变体世界同样存活（37.88 / 22.70），但探测需求更高（8.0）。

## 6. 可以声称 / 尚不能声称

**可以声称（均有本报告数字支撑）**：

1. 在 Gate 1 统一合同 + 本报告成本合同下，**SQCAD 在默认、风险规避、延迟敏感三个价格区间的净收益最高**；对最优非探测基线的 break-even 探测价格为默认的 110 倍；
2. **探测预算受限时 SQCAD 相对 CMI 的结构性优势**：pb=0 时 V 差 6.6（rare 0.83 vs 0.17），归因于组作用域回退而非探测；
3. **负面生命周期恢复结果（保留）**：强制点估计损失低频保护（rare 0.175）；强制恢复在识别缺口含害记忆的世界把 stale 暴露率推到 1.0、V 从 38.62 崩塌至 8.73；门控拒绝（探测/unresolved）两世界稳定；
4. **极端容量价格下记忆治理不划算**（$\lambda_{\mathrm{tok}} \ge 5\times$ 默认，no_memory 最优）——成本合同如实定价，不给任何策略免费宣传。

**尚不能声称**：

- **默认价格下 SQCAD 对配探测 CMI 的优势是"均值 0.07"量级的**——必须与 E3 探测预算扫描一起陈述，否则是对收敛现象的夸大；
- 探测 oracle 的真实代价（本实验探测解析即得真值组效应；真实系统里探测本身有噪声与延迟，Gate 4 的 $\lambda_{\mathrm{probe}}$ 只是合同参数化）；
- 任何"SQCAD 在真实 Agent Memory 系统上净收益最高"的结论——本报告仍在统一合成流上；真实轨迹的成本结构与机制发生率见 Gate 2（`06`），最终主表数字待 Gate 2.2 承接；
- $\lambda_{\mathrm{llm}}$ 通道（=0 是有意标注：LLM 层未复现，不给虚构价格）。
