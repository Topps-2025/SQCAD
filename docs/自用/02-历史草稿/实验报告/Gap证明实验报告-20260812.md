## 实验结果

### 命题 A：两个观测等价的 SCM（Memory Worth 路径）

```
构造：共享随机序列 → E_star ≡ E_prime（完全共暴露）
M₁: Y = +1.5·E + ε  →  m_star lifecycle = +1650 (keep)
M₂: Y = (+2.5-1.0)·E + ε = +1.5·E + ε  →  m_star lifecycle = -1100 (archive!)
P(O|M₁) = P(O|M₂)：max outcome diff = 0.0（代数等价）
Memory Worth 在 M₂ 的 regret = 1100.0（严格 > 0）
```

### 命题 B：真正 do-intervention（CMI 路径）

```
Δ_do(m_short) = 2.000, Δ_do(m_long) = 2.000（完全相等）
m_short lifecycle = -1784（应 archive — future benefit=0，仅 crowding）
m_long lifecycle = +1776（应 keep — 维持 rare critical 检索路径）
CMI observational regret = 1784.0（严格 > 0）
```

### 命题 C：source-equivalent 世界（OPE/MSM 路径）

```
Source 日志：两个世界完全相同
Source 加权平均 τ = -0.28 → 建议 "archive"
World 1 target τ = +2.0 → 需要 "keep"
World 2 target τ = -2.0 → 需要 "archive"
Source data 无法识别 target value（至少误导一个世界）
```

## 当前可成立的主张

> 在三个明确构造的合成反例中，关联价值（Memory Worth 类）、query-local intervention effect（CMI 类）和 source-scope average（OPE/MSM 类）各自都可能对 persistent-access lifecycle decision 不充分。因此，Agent Memory 中存在一个值得单独形式化的 **memory-specific lifecycle identification gap**。

当前 Gap 的地位是：

> **counterexample-supported memory-specific identification gap**
> 或中文：**有构造性反例支持的持久访问生命周期价值识别空白**

## 当前不能成立的主张

- ❌ "基础理论空白已经被证明"
- ❌ "不可识别性定理已经成立"
- ❌ "所有 OPE/MSM 方法都无法完成作用域迁移"
- ❌ "已经形式化证明 persistent-access lifecycle value 在 observational logs 下不可识别"

## 下一步：从反例到定理

要真正上升到 "有理论基础的理论空白"，还需：

1. 将命题 A 的反例写成正式的 observational non-identifiability 定理
2. 将命题 B 的反例写成正式的 local intervention insufficiency 定理
3. 将命题 C 的反例写成正式的 scope transport limitation 定理
4. 在定理基础上明确识别条件（consistency, exchangeability, positivity 等）
5. 由定理条件反推 SQCAD 框架设计
