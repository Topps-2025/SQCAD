## 8. 应急预案

### 8.1 如果 SSH 断开

- 所有任务用 `nohup ... &` 后台运行
- 重新登录后用 `ps aux | grep python` 查看进程
- 用 `tail -f logs/*.log` 继续监控

### 8.2 如果实验失败

1. 查看日志：`grep -i error logs/*.log`
2. 确认失败原因（显存/代码/数据）
3. 修复后重新运行单个任务
4. 不需要重跑整个 Phase

### 8.3 如果显存不足

1. 检查 vLLM 配置
2. 降低 `--gpu-memory-utilization` 到 0.8
3. 或者降低 SimpleMem 到 n=50

### 8.4 如果时间不够

**最小可行版本**：
- L3 鲁棒性：只做 3 组（GAMMA 扫描，HARM=20）
- SimpleMem：降低到 n=50
- 端到端：只做 SQCAD vs full_store（2 baselines）
