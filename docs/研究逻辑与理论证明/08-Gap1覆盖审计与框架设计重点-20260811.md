# Gap 1 覆盖审计与框架设计重点

> 日期：2026-08-11
> 用途：支撑 '07-Introduction规范稿.md' 的文献边界、Research Gap 与方法设计。
> 裁决原则：只把尚未被现有工作覆盖的交叉问题写入 Gap；不使用 first、unique 或 absence of 等绝对表述。

## 1. 研究对象与三个 estimand

本研究不再把 Gap 1 表述为“Agent Memory 尚未使用因果分析”，也不把所有问题压缩为“相关性不等于因果”。需要区分：

1. **历史关联价值**：某条记忆被策略检索后，结果与其共现的程度；
2. **当前查询局部效应**：在固定 query、模型、候选集与评价器下，强制加入或移除某条记忆造成的答案变化；
3. **持久访问干预的生命周期效应**：protect、downweight、isolate、archive 或 restore 某条记忆后，由此改变的未来候选流、共同暴露、行动、结果和后续学习数据的累计价值。

前两类量不能自动识别第三类量。SQCAD 的 treatment 应是**持久访问状态的改变**，而不是仅研究一次 prompt 中是否包含某条记忆。

| 工作 | 已覆盖 | 尚未覆盖 | Gap 1 裁决 |

| CMI | 在固定 query 上运行 no-memory、with-memory、perturbed-memory，估计当前答案的局部 intervention effect | 依赖 gold target/scorer 与受控候选；未处理 shortlist 外 overlap、多记忆干扰、策略反馈和未来任务价值 | 覆盖 query-local intervention，不覆盖 lifecycle identification |

## 3. 仅保留的 Research Gap 1

> **Research Gap 1 is the lack of an auditable lifecycle-level formulation for identifying the effect of persistent memory-access interventions under policy-dependent, time-varying exposure and feedback, with explicit treatment definitions, overlap conditions, co-memory interference and outcome-measurement assumptions.**

这句话只声称一个尚未被完整覆盖的交叉问题：treatment 是既有记忆的持久访问状态；exposure 由当前 policy 生成；treatment 会改变后续 candidate stream 和更新数据；目标是 lifecycle policy value，而不是当前 query 的答案分差；识别主张必须公开假设和失败条件。

## 4. 框架设计重点

### 4.1 先定义 estimand，再选择估计器

明确处理单元（raw memory、evidence-anchored relation 或 access state）、treatment（一次 exposure 或 persistent action）、outcome（即时答案、未来效用、false-forgetting regret 或风险加权累计效用）、horizon、target policy、target scope 和多记忆 interference。技术中心应是 **memory-specific longitudinal treatment construction**，而不是重新命名 DR、MSM、OPE 或 Bayesian update。

### 4.2 把策略反馈写成可执行日志协议

candidate -> proposal score -> exposure propensity -> position/budget -> adoption evidence -> action -> outcome/cost -> governance action -> next candidate stream

必须区分 candidate generation 与 exposure、exposure 与 adoption、action 与 evaluator outcome、普通 association update 与 causal qualification，以及 source evidence、relation belief 与 access policy。若 adoption 不可直接观测，应声明代理测量、误差模型和不识别边界，不能把“出现在 prompt 中”等同于“产生处理作用”。

### 4.3 建立可识别性与 overlap gate

包括 candidate support 和 propensity 审计、overlap/positivity 检查、多记忆干扰与位置效应诊断、evaluator drift 与 model-version 固定、随机低风险 micro-intervention，以及在无法识别时输出 unresolved。unresolved 的含义不是低分，而是**没有权限改变持久访问权**。

### 4.4 验证未来策略价值，而不是重复测当前答案

采用 chronological lifecycle evaluation：source period 形成 qualification，冻结规则后进入 future period；比较 held-out user/task、tool/model-version shift；测量 persistent action 对未来 candidate stream 和累计效用的影响；单独报告 false forgetting、harmful retention、active tokens、probe/review cost；在同 reader、candidate stream、budget 和 evaluator 下比较 conservative keep、fixed decay、Memory Worth、CMI-style local audit 与强治理基线。只有 source effect 在 future policy rollout 中保持价值，才可称为 lifecycle evidence。

### 4.5 保持资格门与访问动作最小化

保留三层：Evidence（不可覆盖的来源记录与 provenance）；Qualification（scope/version 条件下的 positive、negative、unresolved、mismatch）；Access（固定预算内的 protect、fallback、downweight、isolate、archive、restore）。资格层回答“证据有没有权限”，访问层回答“有限预算如何行动”，不要把二者重新合成一个连续 utility score。

### 4.6 把 scope transport 留在 Gap 2

Gap 1 负责 source regime 中的 lifecycle identification；Gap 2 负责 effect 向新 user/task/tool/model version 的 transport、uncertainty 与非对称 false-forgetting cost、可撤回动作、provenance 和 recovery path。这样可避免两个 Gap 重叠。

## 5. 不应成为框架中心的内容

- 新的通用因果估计器；
- 自动 hierarchy 或因果图表示本身；
- 自由能、贝叶斯或神经动力学术语包装；
- 与 EVSI stop 重复的动态预算模块；
- 物理删除或存储压缩 SOTA；
- 仅在合成世界中读取 latent truth 的复杂 posterior；
- “模块越多越完整”的系统叙述。

现有负结果说明，SQCAD 最有辨识度的核心不是复杂结构，而是：

> **把 persistent-access intervention 定义为序贯 treatment，并把 qualification 设为改变长期访问权之前的显式权限门。**
