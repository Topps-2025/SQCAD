# 研究风险与待验证问题

本设想必须主动暴露风险。近期论文已覆盖不少原先想象的空白，若实验不能超过强基线，应收窄主张而不是继续扩展术语。

## 设想层面的疑问

1. **自由能是否只是换名的打分器？** 若 (F_{graph}) 不能在控制行动价值、可靠性和成本后带来增益，应删除或降为解释工具。
2. **低图冲突是否会压制新异常？** 与背景图不一致可能意味着噪声，也可能是新证据；必须保留探索和反例保护机制。
3. **路径解释是否等于因果贡献？** 语义相似、覆盖度和叙事连贯性都不能直接证明因果，需要遮蔽、替换或反事实测试。
4. **外部记忆是否真的带来增量？** 模型参数可能已覆盖某些内容；必须区分参数、外部证据和二者重叠。

## 工程实现疑问

- 因果/证据图由 LLM 抽取时会产生幻觉；关键边必须有来源、时间、置信度和人工抽检。
- 类型化记忆的版本、作用域、冲突与跨层迁移会增加 schema 和维护成本。
- 图搜索可能抵消稀疏化收益；必须报告端到端延迟、token、调用次数和存储。
- 剪枝不能等同物理删除；应优先使用降权、归档、隔离和可恢复机制。
- 时间边界需要同时记录事件时间、信息可得时间和查询时间，避免静默的未来材料泄漏。

## 最小验证矩阵

| 压力场景 | 必须比较 | 失败标准 |
| --- | --- | --- |
| 低频但行动关键 | Recency/Frequency、FadeMem、DeMem、候选方法 | 关键行动边界丢失或只因增加 token 获益。 |
| 高频但过时 | Oblivion、Memory Worth、ReMe、候选方法 | 旧记忆继续被采用且无时间/证据警告。 |
| 冲突与主体漂移 | Mem0/A-MEM/MemoryOS/MIRIX、候选方法 | 错误覆盖条件性事实或无法追溯版本。 |
| 参数—外部重叠/时间前视 | 参数遮蔽、证据遮蔽、Talkie式时间截断 | 历史任务得分来自未来参数知识或未审计引用。 |

## 更稳妥的研究定位

> 一种以条件化行动价值为目标、以图结构/认知自由能为可消融评分分量、以可恢复生命周期动作和时间受限证据日志为约束的 Agent Memory 治理框架。
