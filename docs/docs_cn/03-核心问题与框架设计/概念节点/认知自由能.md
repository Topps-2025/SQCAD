# 认知自由能

认知自由能是一个工程化、可消融的图路径正则项，不是物理自由能或神经科学定理在 Agent 上的直接实现。它用于刻画候选路径的结构复杂度、与当前背景的冲突及对观察的解释收益。

## 与行动价值的关系

主目标应是条件化行动价值 (U(P\mid c))，其中 (c) 包含任务、主体、时间、预算和证据条件。认知自由能 (F_{graph}(P)) 只作为可选分量：

```text
F_graph(P) = 结构复杂度(P, G) + 冲突(P, G) - 解释收益(P, observation)
```

低 (F_{graph}) 可能表示路径更容易整合、解释成本更低；但低冲突不等于正确，高冲突也不等于噪声。新异常、冲突证据和反例必须通过可靠来源与行动结果检验。

## 与近期方法的关系

- FadeMem/Oblivion 提供可访问性与衰减基线；
- Memory Worth 提供结果共现价值基线，但明确不是因果价值；
- DeMem 提供决策率失真基线；
- MEM1、PREMem、ReMe、HingeMem、MemSearch-o1 提供推理驱动巩固或检索增长基线。

因此，认知自由能只有在控制上述强基线、模型、预算和候选集后仍能改善行动效用或成本—性能前沿，才构成方法增量。
