# 自由能框架相对艾宾浩斯曲线的可检验增量

艾宾浩斯式时间衰减可以作为 Agent Memory 的基础基线；FadeMem 也表明时间、频率和语义相关性是有用的工程信号。因此，本节点不把时间衰减称为“错误”，而把问题改写为：时间信号能否在加入条件化行动价值、证据合法性和环境漂移后继续作为有效特征？

## 可能的增量

- 低频但在当前条件下改变行动的记忆，不因时间单独被淘汰；
- 高频但在环境变化后失效的记忆，不因频率单独被强化；
- 与背景图冲突但有可靠新证据的异常，不被结构一致性分数直接删除；
- 已由参数知识覆盖、且没有来源/时间/权限增量的外部条目，可以避免无差别写入。

## 不能直接宣称的结论

“自由能低就一定有价值”“久远事件一定应保留”“自由能优于艾宾浩斯曲线”都不是现有论文已证明的结论。它们必须在低频关键、高频过时、冲突更新和严格时间切分任务中，与时间/频率、FadeMem、Oblivion、Memory Worth、DeMem 和 ReMe 对照验证。
