# 低频高冲击遗忘困境

低频高冲击遗忘困境指：Agent 面对罕见但具有深刻历史类比价值或因果解释价值的记忆时，现有遗忘机制可能因为该记忆距离当前时间太远、近期访问次数太少，而错误地将其剪枝。

这个困境不是本研究的唯一目标，而是自由能记忆治理框架的压力测试。它用来说明：时间和频率无法充分表示记忆价值，真正需要管理的是记忆路径在当前认知框架中的自由能状态。

## 典型场景

- 用 1929 年大萧条的因果链评估当前宏观金融风险。
- 用 2000 年互联网泡沫的结构逻辑类比当前 AI 投资泡沫。
- 用历史上的流动性危机、政策拐点或产业周期崩塌解释当下高不确定性事件。

## 失效机制

现有遗忘机制偏好时间新近和访问频率。罕见历史事件往往低频、久远，因此在统计规则下被判为低价值记忆。

但这类记忆可能携带高价值的结构性因果骨架，例如：

- 杠杆扩张。
- 估值泡沫。
- 流动性收缩。
- 信用风险传导。
- 叙事过热后的预期反转。

这些结构可能对当前决策极其重要。

## 核心矛盾

人类记忆往往会强化罕见但颠覆性的事件，而当前 Agent 遗忘逻辑可能恰好相反：它强化近期高频信息，却弱化低频高冲击经验。这构成一种认知倒挂。
