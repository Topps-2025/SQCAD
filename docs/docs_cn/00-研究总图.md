# SQCAD 研究总览

> 本文是 docs_cn 的中文入口，给出研究问题、框架、证据状态与结论边界。完整实验链路与数值来源见 [04-数据与实验](04-数据与实验/README.md)。

## 研究问题

Agent Memory 常用相关性、时间、频率、共同曝光和任务结果更新未来访问。但候选暴露、采用和结果同时受到当前策略影响，成功轨迹可能把无关 hitchhiker 与有用记忆一起强化；低频保护性记忆也可能被普通衰减错误降权。

SQCAD 聚焦于：**什么证据有资格改变记忆的持久访问策略，以及在固定工作区预算下如何分配当次访问资源。** 这不是把 BM25、遗忘规则或检索器换一个排序函数，而是把"提出候选"、"资格判断"与"改变访问状态"分离为三个不同的问题。

## 核心分离

- **Evidence**：不可变来源和 provenance，提出候选；
- **Qualification**：特定作用域下的 positive、negative、unresolved 或 mismatch 权限，决定持久访问状态能否被改变；
- **Access**：当前任务的有限预算分配，竞争性读取。

作用域不是自动成立的泛化保证，而是一个需要在未见任务、用户、工具和版本变化下验证的条件化降噪假设。持久治理动作（archive / restore / probe / 弃权）都受识别条件约束。

## 当前边界

- Guard-1 是不放宽持久授权前提下的最小 coverage 修复，**不代表系统性胜过所有 SOTA**；dense/RRF 因权重不可得未复现。
- LifecycleBench 的 reference certificate 在该规则世界与 visible event rule 完全代理；端到端（Phase B）未完成，不能把规则世界结果写成端到端结论。
- R6 人类锚定与 Phase B 是下一工作包。
