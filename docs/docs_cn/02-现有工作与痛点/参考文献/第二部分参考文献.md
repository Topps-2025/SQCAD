# 第二部分参考文献：近年 Agent Memory 扩展书目

`[R#]` 服务于本部分五篇主文档：从 LLM 到 Agent Memory 的演进、Agent Memory 整体方向、已存记忆的生命周期治理与选择性遗忘、生命周期治理的未覆盖问题与研究路径，以及原文证据索引。本地 PDF 条目已依据摘要、引言或正文核读；库外条目均通过论文主页、ACL Anthology、Crossref 或 arXiv 元数据核验题名、作者、年份与稳定入口，并在正文中仅用于其摘要/公开论文页面直接支持的表述。2026 年的预印本或新近会议论文在正式投稿前仍应复核版本。

## H. 2025—2026 年新增直接竞争工作

### [R27] MEM1

### [R34] Infini Memory

- 链接：https://arxiv.org/abs/2606.10677

## I. 参数知识与自适应检索的相邻直接工作

### [R35] Parametric vs. Non-Parametric Memory

### [R37] FLARE

- Jiang, Z., Xu, F., Gao, L., Sun, Z., Liu, Q., Dwivedi-Yu, J., Yang, Y., Callan, J., & Neubig, G. (2023). *Active retrieval augmented generation*. Proceedings of EMNLP 2023.

- 链接：https://doi.org/10.18653/v1/2023.emnlp-main.495

### [R42] Voyager

- 链接：https://arxiv.org/abs/2305.16291

### [R46] Modern Hopfield Networks

- Ramsauer, H., Schäfl, B., Lehner, J., Seidl, P., Widrich, M., Adler, T., et al. (2021). *Hopfield Networks is All You Need*. arXiv:2008.02217.
- 关联问题：给出现代 Hopfield 网络的连续状态与能量极小值，并建立其更新规则与 Transformer 注意力之间的对应；支持将能量地形作为联想存储和检索的计算对象。
- 证据边界：该工作不处理带来源、时间、作用域和撤回语义的外显 Agent Memory 生命周期。
- 链接：https://arxiv.org/abs/2008.02217

### [R47] Energy-based Forgetting in Modern Hopfield Networks

- Takeda, K., Oizumi, M., & Karakida, R. (2026). *Continual Learning in Modern Hopfield Networks with an Application to Diffusion Models*. arXiv:2605.27975.
- 关联问题：将任务变化后的 Hopfield 能量上升定义为 intrinsic forgetting，分析高能量样本的遗忘与基于能量的回放选择。
- 证据边界：研究对象是现代 Hopfield/扩散模型的参数化持续学习与回放，不是外显 Agent Memory 的保留、降权、归档、版本或撤回动作。
- 链接：https://arxiv.org/abs/2605.27975
