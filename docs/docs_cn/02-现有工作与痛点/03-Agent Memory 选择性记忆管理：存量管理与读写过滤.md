# Agent Memory 选择性记忆管理：工作方向、原文证据、算法机制与能力边界

## 0. 研究对象、分类原则与证据使用规则

本文将研究范围扩展为**选择性记忆管理**：在工作记忆、长期/持久外显记忆及其跨层迁移中，选择性控制信息的形成、存续、表示、关系结构与读时暴露，以降低冗余、过时、冲突或不适用信息对存储和任务执行的负担。它不同于参数层面的 Machine Unlearning；后者处理训练样本对模型参数化行为的影响 [R44][R45]。本节不要求论文只作用于某一时间尺度，而要求其明确直接操作的是工作记忆、持久记忆、二者的迁移接口，还是长期记忆到工作区的读取接口。
![[Pasted image 20260727140441.png]]
综述中的 consolidation、updating、indexing、forgetting、retrieval 与 condensation 是可交叉标注的记忆操作，而非每篇论文必须唯一归属的互斥标签 [R24]。为从“少即是多”的选择性减负视角组织研究，本节以论文的中心问题和主要减负位置为判准，形成三个大方向及其四个子方向：

| 大方向         | 子方向                     | 核心问题                               | 代表论文                                                                                       |
| ----------- | ----------------------- | ---------------------------------- | ------------------------------------------------------------------------------------------ |
| 一、形成与跨层迁移减负 | 写入准入与跨层巩固               | 哪些观察应形成记忆，工作记忆中的何种经验应以何种粒度稳定为持久状态？ | SAGE、PREMem、Mem0、MemGPT、MemoryOS [R1][R5][R6][R11][R29]。                                   |
| 二、已存记忆本体减负  | 2.1 状态减负：保留、衰减与弃用       | 哪些已存条目应继续保持默认影响力、被抑制或退出？           | MemoryBank、FadeMem、Memory Worth [R4][R16][R17]。                                            |

|             | 2.3 结构减负：已存记忆的更新演化与关系重组 | 已存单元如何在后续证据或反馈触发下修订、关联、分化与重组？      | Mem0、A-MEM、Zep/Graphiti、TrustMem、ReMe、Infini Memory [R6][R7][R10][R12][R33][R34]。          |

三类减负共同服务于有限资源下的任务充分性，但不意味着“更少”天然更优：形成阶段的少写入可能造成关键经验从未被保存；本体减负可能损失例外、版本和恢复线索；读时减负可能漏读关键证据。因此，评测与归因、时间合法性、来源与权限应作为所有方向的横向验证约束，而不与机制方向并列。

下文中“原文证据”均摘自论文摘要、引言、方法或局限章节；英文引文后的 R 编号可回溯至 [[05-原文证据索引]]。凡是“本文综合”“方法学含义”字样，均为基于多篇论文的分析，而非归属于单一作者的主张。

# 1. 大方向一：形成与跨层迁移减负

## 1.1 背景与意义：在形成前控制冗余，并在跨层迁移中稳定可复用经验

选择性记忆管理不能只从“已写入后如何遗忘”开始。工作记忆中的对话片段、工具观察与中间推理若被无差别地抽取并写入持久层，冗余、偶发噪声与局部错误会在形成时即进入后续维护链；反之，过于保守的准入又可能使低频但行动关键的约束、异常或经验在需要前从未获得稳定表示。因而，写入准入与跨层巩固的作用，是在信息由瞬时工作区转化为可跨会话调用的外显状态时，选择其是否应被保存、以何种类型与粒度保存，以及是否需要先经过抽取、合并或结构化推理。

文献普遍从这一位置切入，**是因为写入期通常拥有最完整的局部上下文，也最适合在存储成本尚未累积之前抑制重复**。然而，写入控制并不等同于遗忘：其直接动作是决定候选信息的形成与稳定化，后续仍可能被状态衰减、表示压缩、结构演化或读时过滤重新修订。将其纳入选择性记忆管理，能够完整覆盖工作记忆、持久外显记忆与二者迁移接口，而不将“选择性”误限为存量删除。

## 1.2 既有工作：新颖性门控、预存储推理与层级巩固

SAGE 将新抽取事实路由为 ADD、NOOP 或与既有条目合并，并以随记忆库几何变化的自适应新颖性阈值约束无差别写入 [R11]。PREMem 则把一部分推理前移至存储期：先抽取事实、经验与主观信息等细粒度片段，再建立跨会话的延伸、转变与蕴含关系 [R29]。Mem0 以事实抽取及 ADD、UPDATE、DELETE、NOOP 等操作提供持久状态的基本维护原语 [R6]。这些工作共同将写入理解为从交互轨迹到可治理记忆单元的选择性映射，而非日志追加。

跨层巩固方面，MemGPT 将有限上下文视为主存、将外部存储视为可分页的长期层，以虚拟上下文管理协调工作区与持久状态 [R1]；MemoryOS 则以短期、中期和长期个人记忆组织存储、更新、检索与生成 [R5]。两类工作说明，工作记忆与长期记忆并非必须被割裂讨论：前者可作为待巩固的高保真局部状态，后者则承载经选择和组织后的长期表示，二者通过迁移与维护动作发生耦合。

## 1.3 综合评述与共性限制：形成期代理信号与长期行动价值之间的缺口

现有写入与巩固方法主要以新颖性、可抽取性、局部语义差异、关系可推断性或上下文容量作出准入判断。SAGE 将准入设为新颖性检测，并在其论文范围内不执行 DELETE 或压缩 [R11]；PREMem 将推理前移至存储期，但其公开机制未把推断关系的来源、撤回与时间作用域作为受治理状态 [R29]。这些结果支持写入控制与预存储推理的效率价值，却不能直接证明“未被写入的信息在未来任务中没有独立贡献”，也不能证明写入时确定的粒度、类型和关系在条件变化后持续适用。

因此，该大方向的共同问题应严格表述为：**如何验证形成期的局部准入信号与后续条件化行动价值之间的对应关系。** 低频关键约束未被保存属于这一问题的压力场景，而非对既有方法已发生普遍失效的断言。

# 2. 大方向二：已存记忆本体减负

## 2.1 背景与意义：在不牺牲可行动区分的前提下，调节状态、表示与关系结构

一旦记忆形成，长期系统仍需处理存续状态、表示粒度和内部结构的持续膨胀。若所有单元等权保留、以原始粒度存储并仅追加局部更新，候选集合、索引负担、冲突密度与版本复杂度会同步增长；若单纯删除、合并或覆盖，又可能损失例外、来源、时间锚点与恢复线索。因而，本体减负不是单一的“删除操作”，而是对已存单元的状态强度、表示分辨率及关系组织进行协同调节。

现有文献通常分别从状态管理、语义/决策压缩和更新演化三个位置切入，因为它们对应不同的直接操作对象：前者改变条目的默认影响力，中者改变信息的编码粒度，后者改变新旧单元的结构关系。三者可以在同一系统中交叉出现，但其失败模式并不相同，故以下作为三个子方向分别讨论。

## 2.2 子方向一：状态减负——自适应保留、衰减与弃用

### 2.2.1 背景、意义与方法论路径

该方向的直接对象是已经位于外部记忆库中的条目。其基本困难在于：长期 Agent 不能让所有历史保持等权可见，但也不能仅凭年龄或容量阈值粗暴删除。前者会造成候选规模增长、检索干扰和提示污染；后者会误伤低频但高损失的约束、例外或未来任务所需的背景条件。

生物启发是这一方向的重要来源，但不是唯一来源。它主要提供“遗忘是可访问性调节而非瞬时抹除”“重复与线索影响保持强度”“工作记忆需要有限容量”的工程直觉。围绕同一问题，还可归纳出至少四类非生物学方法路径：

1. **规则与启发式路径。** 以时间、频率、最近访问、语义相关性、重要性阈值或容量上限为信号，采用衰减、淘汰、融合或分层迁移。优点是可解释、低成本；缺点是信号通常只刻画历史访问模式。
2. **概率统计路径。** 将记忆质量视为条件成功概率、可靠度、后验置信或风险评分，并随观测结果更新。Memory Worth 的双计数器是典型的在线频率学派实现；更一般地，可使用贝叶斯后验或不确定性校准，但其前提是观测机会和任务机制可比较。
3. **在线学习与控制路径。** 把保留、抑制、强化、归档视为长期决策动作，以任务结果或成本作为反馈。该路径可以使用 contextual bandit、强化学习或策略梯度，但会面临探索不足、奖励延迟和混杂归因。


因此，状态减负的学术意义在于将外部记忆从静态档案转化为可随经验演化的状态系统；其难点则在于避免把易计算的代理信号误写为真实的行动价值。

### 2.2.2 代表论文、原文表述与核心算法机制

#### 2.2.2.1 MemoryBank：时间—重要性驱动的长期记忆演化

MemoryBank 是较早将长期对话记忆显式置于持续更新和遗忘问题下的代表工作。作者在摘要中将出发点表述为：“Recognizing the necessity for long-term memory, we propose MemoryBank, a novel memory mechanism tailored for LLMs.” 随后将其能力概括为：“MemoryBank enables the models to summon relevant memories, continually evolve through continuous memory updates, comprehend, and adapt to a user’s personality over time” [R4，Abstract]。

从算法立场看，MemoryBank 属于时间与重要性驱动的启发式状态管理：它不要求直接估计每个条目对某一动作的边际效应，而是通过记忆随时间演化和重要性调节，缓解长期对话中的无差别积累。其贡献是将“长期陪伴”从简单历史拼接转化为持续的记忆维护；其局限是时间和重要性仍是代理变量，原文并未将任务条件化的退出后果或多副本删除定义为优化目标。

#### 2.2.2.2 FadeMem：多信号差异化衰减、冲突抑制与语义融合

FadeMem 的问题意识更明确。作者指出：“Current AI systems employ binary retention strategies that preserve everything or lose it entirely.” [R16，Abstract]。对应地，其机制并非单一遗忘曲线，而是“differential decay rates across a dual-layer memory hierarchy”，其中保持状态由“semantic relevance, access frequency, and temporal patterns”共同调制 [R16，Abstract]。

从算法结构看，FadeMem 包含四个层面：

- 双层记忆结构，用于区分不同粒度或稳定性的记忆；
- 以相关性、频率、时间为输入的重要性/保持强度计算；
- 自适应指数衰减，使条目强度连续变化而非二元删除；
- LLM 引导的冲突消解和融合。作者明确写道：“Through LLM-guided conflict resolution and intelligent memory fusion, our system consolidates related information while allowing irrelevant details to fade.” [R16，Abstract]。

该工作表明，选择性遗忘可同时是存储控制、冲突处理和表征合并问题。作者报告其在设定实验中实现“superior multi-hop reasoning and retrieval with 45% storage reduction” [R16，Abstract]。这一结果不能外推为相关性、频率和时间已构成未来行动价值的充分统计量；论文所定义的保持信号并未直接识别单条记忆的因果贡献。低频关键条目、高频陈旧信息和可靠新异常可作为检验该边界的压力条件。

#### 2.2.2.3 Memory Worth：结果反馈的概率化治理原语

Memory Worth 代表从启发式重要性走向概率统计治理的路线。作者提出的中心问题是：“How [should an agent decide] which memories to trust, suppress, or deprecate as the agent’s task distribution shifts?” [R17，Abstract]。其核心信号为“a two-counter per-memory signal that tracks how often a memory co-occurs with successful versus failed outcomes” [R17，Abstract]。

在给定平稳检索与最低探索条件下，双计数器可估计记忆被检索时的条件成功概率。这使系统能够根据经验结果更新信任、抑制或弃用状态，而不是永远沿用写入时的重要性标签。该工作的重要学术价值并不只在于算法轻量，而在于作者主动厘清了统计信号的解释边界：

> “Importantly, p+(m) is an associational quantity, not a causal one: it measures outcome co-occurrence rather than causal contribution.”  
> — Memory Worth [R17，Abstract]

这一定义为后续研究设定了严格基线：若新方法声称估计“记忆价值”，必须说明其相对条件成功共现多获得了什么识别能力，例如如何控制检索机会、共现条目、任务难度或工具条件。

### 2.2.3 统一理解、能力边界与研究问题

状态减负已经证明三件事：第一，外部记忆可以拥有连续而非二元的保留状态；第二，时间、访问、相关性和结果反馈可作为低成本在线治理信号；第三，衰减、抑制和强化可以与长期任务成本和表现共同优化。

但是，该子方向的共同能力边界同样清晰：

| 现有信号或动作 | 已能支持的结论 | 不能直接支持的结论 |
| --- | --- | --- |
| 时间、频率、相关性、重要性评分 | 条目在历史访问轨迹中更可能被使用或更适合维持较高优先级。 | 条目对当前或未来行动没有独立价值。 |
| 成功/失败共现 | 被检索时的条件成功关联。 | 单个条目造成成功，或抑制后不会损害行动。 |
| 连续衰减、潜伏或再激活 | 可避免一次性硬删除，并降低默认可见性。 | 需要时一定能重新找到、恢复或正确采用该条目。 |
| 存储缩减与端到端增益 | 在给定模型、数据和预算下实现效率—性能权衡。 | 改进来自遗忘动作而非检索器、提示词、模型或任务分布。 |

由此，状态减负的核心开放问题应表述为：在任务、主体、时间、候选集和预算给定时，如何估计某个存量条目被保留、降权、压缩或归档对计划、工具调用和结果的条件化增量影响，而非只估计它与成功共现的频率。

## 2.3 子方向二：表示减负——巩固、压缩与决策充分性

### 2.3.1 背景、意义与方法论路径

选择性遗忘并不总以删除为终点。对长期 Agent 而言，原始交互、观察和工具轨迹会不断增长；系统面临的常常是表示粒度和运行时容量问题，而不是某条文本是否绝对保留。该方向因而研究如何将高冗余历史转化为更紧凑、更可检索、但仍足以支持后续决策的表示。

其方法论可分为四类：

1. **层级与虚拟内存路径。** 通过工作区、缓存、外部库和分层迁移，把有限 prompt 视为运行时稀缺资源。
2. **语义压缩与巩固路径。** 以摘要、结构化单元、主题文档或多视角索引降低重复信息密度。
3. **信息论路径。** 以率失真、信息瓶颈或最小描述长度表述“压缩多少”和“损失什么”的权衡。
4. **决策理论路径。** 不以文本重建误差，而以决策质量损失、状态可区分性或策略价值来定义哪些历史不可合并。

与状态减负相比，表示减负关注的是表征和容量；它不必为每条记忆提供即时弃用分数，却必须说明压缩后仍保留何种可行动的区分。

### 2.3.2 代表论文、原文表述与核心算法机制

#### 2.3.2.1 MemGPT 与 MemoryOS：分层状态和跨层维护

MemGPT 以固定上下文窗口为问题起点，提出“virtual context management”，通过不同存储层级使有限上下文模型可使用超出当前窗口的历史 [R1，PDF p.1，Abstract]。其核心思想是把 prompt 视为受限主存，把外部存储视为可分页的长期层；这是一种工程化的容量管理，而非逐条遗忘价值估计。

MemoryOS 则将层级化思路扩展为个人长期记忆架构。作者指出其包含 “memory Storage, Updating, Retrieval, and Generation” 四个模块，并由“short-term memory, mid-term memory, and long-term personal memory”三层组成 [R5，Abstract]。二者共同构成分层巩固路线：先解决“有限运行时空间中如何维持长期状态”，再讨论每层内部的更新和读取。

#### 2.3.2.2 SimpleMem：语义结构压缩、在线合成与意图规划

SimpleMem 的动机是，现有系统要么保留“full interaction histories”，导致“substantial redundancy”，要么依赖迭代推理过滤噪声，带来“high token costs” [R8，Abstract]。作者的三阶段方案包括：

> “(1) Semantic Structured Compression; (2) Online Semantic Synthesis; and (3) Intent-Aware Retrieval Planning.”  
> — SimpleMem [R8，Abstract]

这一设计体现了语义压缩路径的完整链条：先把原始对话变为紧凑、可索引的单元；再在写入期合成相近内容；最后依据检索意图动态决定读取范围。作者报告方法在准确率、检索效率与推理成本上均优于所比较基线 [R8，Abstract]。从综述角度看，SimpleMem 的关键贡献并非“删除更多”，而是使冗余不再以原始形式持续占据后续推理资源。

#### 2.3.2.3 DeMem：从描述保真转向决策中心率失真

DeMem 是该方向中理论取向最鲜明的工作。作者首先给出价值判断：

> “Memory is valuable not because it faithfully describes the past, but because it preserves the distinctions between histories that must remain separated under a fixed budget to support good decisions.”  
> — DeMem [R18，Abstract]

在此基础上，论文将问题表述为“a decision-centric rate-distortion problem”，并以“the loss in achievable decision quality induced by compression”衡量记忆质量 [R18，Abstract]。其在线机制以有限记忆状态承载历史；仅当共享状态会造成认证的决策冲突时，才进一步细分状态。作者因此声称得到“an exact forgetting boundary for what can be safely forgotten” [R18，Abstract]。

DeMem 将压缩研究从语义相似和摘要质量推进到决策充分性，是本研究的关键直接基线。不过其“安全”边界由给定任务、预算与记忆瓶颈定义 [R18]。该论文并未在其已报告目标中建立跨任务漂移、来源合法性、主体差异或记忆类型撤回的统一治理语义；这些应被视为超出其设定的待验证条件，而非对其方法失效的断言。

#### 2.3.2.4 ReMe 与程序经验精炼

ReMe 将压缩/巩固对象扩展为程序性经验。作者批评现有框架存在 “passive accumulation” 问题，即把 memory 当作“a static append-only archive”，并提出多面蒸馏、情境适应复用和效用精炼 [R12，Abstract]。其方法学含义是：记忆巩固不只压缩事实，也可压缩成功模式、失败触发和可复用行动策略。

但程序经验与事实性记忆的维护语义并不相同：事实可能被新证据替代，技能可能需随环境条件分叉，偏好也可能需要条件化分段。ReMe 的已报告目标是程序经验的蒸馏、复用与效用精炼 [R12]，并未证明其机制可直接充当跨类型的通用删除政策；这构成与结构减负中的类型和版本治理相衔接的待验证问题。

### 2.3.3 统一理解、能力边界与研究问题

表示减负已具备如下能力：在有限 token、槽位或存储预算下形成更紧凑的历史表示；用语义结构、主题、层级或决策冲突约束合并；在特定任务上展示性能—成本权衡改善。

然而，压缩方向的共同边界在于：

| 已有能力 | 不能直接推出的结论 | 方法学原因 |
| --- | --- | --- |
| 当前任务上维持或提升答案质量。 | 被合并的细节在条件变化后仍无独立贡献。 | 既有结果针对给定数据、任务与评测条件 [R8][R18]。 |
| 决策充分性下可安全合并。 | 该边界跨任务、跨时间和跨主体仍保持有效。 | 决策充分性依赖任务定义、奖励、预算和可观测状态 [R18]。 |
| 语义摘要或融合更紧凑。 | 原始来源、时间、冲突前版本和细粒度例外可被恢复。 | R8 的已报告指标聚焦准确率、检索效率与成本，而非这些恢复性质。 |
| 程序经验被精炼。 | 该经验在新的工具、环境和目标条件下仍可复用。 | R12 的效用精炼并未建立跨分布有效性的保证。 |

因此，表示减负的开放问题是：如何在压缩和成本约束下验证关键区分、来源映射与恢复路径是否仍被保留，并在条件变化的任务中检验被合并信息的再解释、恢复或安全弃用。

## 2.4 子方向三：结构减负——已存记忆的更新演化与关系重组

### 2.4.1 背景、意义与方法论路径

该方向关注**已进入记忆库的外显单元**及其内部关系如何持续变化。后续证据、调用反馈或一致性检查可以触发演化，但不构成该方向的直接操作对象：一条已存单元可以被修订、与其他已存单元建立条件关联、由过宽概念分化为多个情境化子概念，或改变既有程序经验之间的适用关系。其核心不是降低条目可访问性（状态减负），缩减表示粒度（表示减负），也不是在当前查询下决定是否读取（读时工作区减负），而是使已有记忆库从静态条目集合演化为具有可追溯关系、层次与角色分工的知识状态。

现有工作已提供若干相邻机制。Mem0 以 ADD、UPDATE、DELETE 与 NOOP 支持事实型记忆维护 [R6]；A-MEM 通过动态链接使新记忆触发旧笔记的关联演化 [R7]；Zep/Graphiti 将时间关系编码进记忆图 [R10]；TrustMem 验证单次记忆转移的 coverage、preservation 与 faithfulness [R33]；Infini Memory 提供主题级维护参照 [R34]；ReMe 则将任务经验持续精炼为可复用的程序性知识 [R12]。这些工作表明，“更新”并不只是将文本覆盖为最新版本，还包含关系重连、语义细化、时间化并存和经验角色重估。

该方向的共同挑战在于，局部更新、动态连边、时间关系或单次转移验证并不共同规定新旧记忆应形成何种长期结构：何时应替代，何时应保留并存版本，何时应细化为情境化子记忆，何时只应建立派生或支持关系。A-MEM、Zep/Graphiti、TrustMem、Infini Memory 和 ReMe 的已报告目标分别覆盖其中部分方面 [R7][R10][R12][R33][R34]，但尚未共同给出并评测统一的关系类型及其多轮演化语义。

### 2.4.2 代表论文、原文表述与核心算法机制

#### 2.4.2.1 Mem0 与 A-MEM：从 CRUD 更新到关联笔记演化

Mem0 将对话抽取出的持久事实维护为可执行的 ADD、UPDATE、DELETE 与 NOOP 操作 [R6]，为事实型外显记忆提供了基本的局部维护原语。A-MEM 则引入动态链接，使后续证据能够触发既有笔记的关联更新与演化 [R7]。二者共同说明，记忆库并非仅在写入时增长；后续信号还会改变既存内容之间的关系与组织方式。

但 CRUD 操作或动态连边本身不规定演化后的语义角色。一个新条目究竟是对旧条目的时间替代、条件例外、同一概念的细化实例，还是应独立并存的不同主体经验，仍需要超出表层文本相似度的状态判定。

#### 2.4.2.2 Zep/Graphiti、TrustMem 与 Infini Memory：时间关系、转移可信性与主题维护

Zep/Graphiti 将时间关系纳入记忆图组织 [R10]，为不同观察在时间轴上的关联与共存提供了结构基础。TrustMem 面向单次记忆转移检查 coverage、preservation 与 faithfulness [R33]，强调演化操作不能以无依据的重写换取表面一致。Infini Memory 则提供主题级维护的参照 [R34]。这些机制分别约束时间关系、转移质量和主题层组织，但尚未形成统一规则来决定事实替代、条件化分化、例外保留和程序经验分叉之间的转换。

#### 2.4.2.3 ReMe：程序经验的持续精炼与角色演化

ReMe 将成功模式、失败触发和对比洞见精炼为可复用经验 [R12]，表明演化对象不仅是事实性命题，也包括行动策略及其适用条件。程序经验尤其要求在新反馈到来后重估其适用范围、依赖环境与失败边界；这与单纯的文本更新或一次性压缩不同。

其边界在于，效用精炼本身并不自动给出跨环境、跨工具版本或跨任务目标的演化语义。程序经验何时应修订、分叉或与旧版本共存，仍需以明确的状态关系和可审计证据加以规定。

### 2.4.3 统一理解、能力边界与研究问题

该子方向已有 CRUD、关联连边、时间图谱、转移验证与程序经验精炼等基础能力；但这些能力尚不能直接推出记忆库具有一致的自演化结构。

| 已有做法 | 不能直接推出的结论 | 原因 |
| --- | --- | --- |
| 对旧记忆执行 ADD/UPDATE/DELETE 或建立新链接。 | 已确定新旧记忆是替代、例外、细化、并存还是派生关系。 | 表层相似或局部更新不含类型、时间、主体和作用域语义。 |
| 对单次转移验证 coverage、preservation 与 faithfulness。 | 多轮演化后关系网络仍可追溯、无环冲突且可解释。 | 局部转移正确不等于长期结构一致。 |
| 以时间图或主题组织记忆。 | 已能处理跨主体、跨环境和程序经验的分化与分叉。 | 时间或主题是必要维度，但不足以决定关系类型与适用边界。 |
| 精炼可复用经验。 | 程序经验会在环境变化后自动修订或安全分叉。 | 经验效用需要与工具、目标和条件状态共同维护。 |

因此，该子方向的核心研究问题是：如何令后续证据或反馈触发可追溯的关系演化，使**已存**记忆单元在“替代—并存—细化—例外—派生—分叉”等结构动作之间进行条件化转换，并使这种转换与时间、主体、任务和环境约束一致。

# 3. 大方向三：读时工作区减负

## 3.1 背景与意义：以任务条件化访问控制限制推理阶段的信息暴露

外部记忆是否仍存在，与它是否应进入当前 prompt 是两个不同问题。若条目已被降权或压缩，但读取器仍固定取 top-k、每轮常开访问或只按表面语义相似度返回，它仍可能干扰推理。反之，保留在库中的条目若不被当前任务暴露，则不会直接占用上下文和影响动作。

因此，该方向将遗忘定义为功能性访问控制：通过控制可访问性、读取时机、搜索范围和候选路径，使当前任务不必面对所有历史。其方法论谱系包括：

1. **不确定性与阈值门控。** 当模型或任务状态足够确定时不检索；当上下文不足时再访问外部记忆。
2. **主动检索与序贯决策。** 把检索看成在生成/推理过程中逐步发起的信息获取动作。
3. **图搜索与结构边界。** 用实体、时间、主题、地点或关系结构约束候选扩展和搜索深度。
4. **贡献回溯与路径重组。** 根据查询和中间推理结果，动态增长或重组局部记忆路径。

这些方法与注意力、线索依赖检索和工作记忆门控具有功能性类比，但其核心仍是受预算约束的信息检索与搜索问题。

## 3.2 既有工作：不确定性门控、结构化搜索与序贯主动访问

### 3.2.1 Oblivion：将遗忘从删除转化为可访问性衰减

Oblivion 是本方向最直接的选择性遗忘论文。作者首先诊断 “always-on” retrieval 和 “flat” memory storage 会在历史增长后造成 “high interference and latency” [R13，Abstract]，继而将遗忘定义为：

> “decay-driven reductions in accessibility, not explicit deletion.”  
> — Oblivion [R13，Abstract]

算法上，读路径依据 Agent 不确定性和缓冲充分度决定是否咨询记忆，写路径只强化形成当前响应所贡献的记忆。该设计将存量状态与读时行为直接耦合，作者总结为系统“dynamically adapts memory access and reinforcement, balancing learning and forgetting under shifting contexts” [R13，Abstract]。

需要强调的是，Oblivion 已反驳“遗忘只是按时间/频率衰减”的简单描述；但其响应贡献和访问门控仍不等同于“该条目在特定任务中不应被采纳”的干预式判定。

### 3.2.2 HippoRAG 与图结构检索

HippoRAG 的出发点是，即便结合 RAG，LLM 仍难以高效整合大量新经验；其方法“synergistically orchestrates LLMs, knowledge graphs, and the Personalized PageRank algorithm” [R14，Abstract]。它不直接执行存量条目弃用，却提供了结构化访问的关键基线：记忆不必被平铺检索，而可经图结构和随机游走选择较可能相关的路径。

该工作对选择性遗忘的启示是，读时抑制不仅可依赖单条分数，也可通过改变图扩展和路径访问控制来实现。但图结构提升多跳检索不意味着图中低中心性节点即可安全退出。

### 3.2.3 HingeMem 与查询边界驱动的自适应深度

HingeMem 针对固定 top-k 和连续摘要的局限，采用人物、时间、地点和主题等边界构造超边，并依据查询类型自适应决定读取内容与深度 [R31，Abstract/§1]。该路线将“是否读取”细化为“在什么边界内读取多深”，特别适合含有时间和主体条件的长期对话。

其方法学价值在于，任务条件化排除不能只写成阈值过滤；还可以先识别查询所激活的结构边界，再限制搜索空间。其已报告机制以人物、时间、地点和主题边界组织读取 [R31]，但并未沿“候选暴露—模型采纳—行动结果”链条验证边界匹配是否转化为正确行动；这一未评测性质构成其适用边界。

### 3.2.4 MemSearch-o1、Adaptive-RAG 与 FLARE：序贯主动访问

MemSearch-o1 指出 think-search 循环会产生 memory dilution，并通过查询种子增长细粒度片段，再以贡献函数回溯和重组记忆路径 [R32，Abstract]。这是将读时管理与推理路径对齐的路线。

Adaptive-RAG 则根据问题复杂度在无检索、单步检索和迭代检索间切换，避免简单问题的无谓成本和复杂问题的检索不足 [R36，Abstract]。FLARE 更进一步，在生成过程中主动决定“when and what to retrieve” [R37，Abstract]。三者共同说明，“何时读取、读取什么”已经是成熟的检索研究问题；后续 Agent Memory 研究的增量不应仅是再提出一个 query-adaptive top-k，而应说明存量状态、版本与退出政策如何进入读时控制。

## 3.3 统一理解、能力边界与研究问题

读时工作区减负已经能够依据查询、模型不确定性、边界结构、生成状态和预算，自适应调整读取时机、范围和深度。它使“遗忘”具有可逆性：信息仍在外部库中，但不会默认进入当前工作区。

其共同能力边界为：

| 已有做法 | 不能直接推出的结论 | 原因 |
| --- | --- | --- |
| 条目未被取回或未进入 prompt。 | 条目因作用域不适用而被规范地排除。 | 未暴露也可能来自索引误差、检索失败或预算截断；现有读时工作未统一标注排除理由。 |
| 条目相关度高并被取回。 | 模型会正确采纳，且采纳改善后续行动。 | R15 区分检索与利用瓶颈，但未延伸到状态动作或工具执行后果 [R15]。 |
| 读取次数或 token 减少。 | 错误计划和工具误用随之减少。 | R13、R31、R32、R36、R37 的主要报告指标并不共同覆盖提示采纳、计划与工具执行。 |
| 查询自适应策略优于固定 top-k。 | 已解决记忆版本、过时事实和撤回治理。 | 读时检索控制与持久记忆生命周期治理属于不同直接对象。 |

因此，读时工作区减负的核心研究问题是：如何将存量记忆状态、时间/主体适用性与当前查询共同转化为读时排除规则，并以“状态→候选暴露→模型采纳→行动”的过程证据检验排除是否源于不适用，而非关键证据漏失。

# 4. 跨方向的统一结论与研究定位

三个大方向及其四个本体/读时子方向共同表明，Agent Memory 已具备写入控制、存量状态管理、压缩、读时访问与局部演化能力。因而不宜再以“尚无遗忘方法”“尚无自适应检索”或“尚无决策导向压缩”作为研究动机。

更精确的整合应是：

| 研究角色 | 从三层地图得出的精确问题 | 必要证据 |
| --- | --- | --- |
| 核心问题 | 在任务、主体、时间、候选集与预算给定时，信息的形成、跨层巩固、保留、压缩、关系演化或读时访问如何改变行动条件？ | 遮蔽、替换、反事实重放；价值排序与行动损失的一致性。 |
| 机制接口 | 如何将价值、适用性和新旧证据关系转化为写入/巩固、可恢复状态动作、表示压缩、读时过滤与结构演化？ | 写入→状态/表示/关系演化→候选→提示→采纳→计划/工具调用的过程日志。 |
| 压力条件 | 在分布漂移、低频高损失与有限预算下，如何避免关键条目不可逆退出或被错误覆盖？ | 漂移、罕见再现、主体切换、恢复率、误弃用率、错误覆盖率和再激活延迟。 |
| 验证协议 | 如何区分动作未执行、错误演化、索引残留、未检索、未采用、错误排除与执行失败？ | 统一模型/候选库/预算下的析因对照和操作级失败分类。 |

“非平稳低频关键项”应被视为核心价值估计的压力条件，而非第二套独立算法贡献；“操作级归因”则是所有方法主张的验证条件，而非与算法并列的又一个创新点。

若后续研究使用“认知自由能”“叙事图”或其他生物启发概念，它们应被严格限制为可消融的工程组件：例如记忆价值评分正则、冲突/不确定性约束、可恢复状态转移或受预算约束的候选搜索。它们不能被表述为对人脑机制的复现，也不能代替对行动价值、来源时间合法性和过程归因的实证检验。

## 5. 与第四节的衔接

第四节应以本节的能力边界为前提：以条件化行动价值与关系演化语义为主问题，以写入/巩固—状态—表示—关系演化—读时过滤为机制接口，以非平稳、低频关键项和有限预算为压力条件，并以状态—暴露—采纳—行动日志和受控干预作为验证协议。
