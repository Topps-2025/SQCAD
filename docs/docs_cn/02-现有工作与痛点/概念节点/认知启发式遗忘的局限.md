# 认知启发式遗忘的局限

许多 Agent 遗忘机制借鉴人类记忆和艾宾浩斯遗忘曲线，主要围绕时间衰减和频率强化设计。

## 常见机制

- 时间衰减：记忆随时间流逝而降低权重。
- 频率强化：经常被访问的记忆得到加强。
- 语义相关性：与当前任务相似或相关的记忆更容易被保留。

## 根本局限

时间和频率并不等于重要性。一个罕见但高度重要的事件，可能比每日重复的琐事更值得长期保留。金融危机、重大疾病、结婚、生子或职业转折等事件，即使低频，也具有高显著性。

因此，遗忘机制需要引入更多维度：

- 结果反馈。
- 语义重要性。
- 因果贡献。
- 风险显著性。
- 记忆类型。
- 长期目标相关性。

## 记忆类型差异

不同记忆应采用不同遗忘语义：

- 事实性知识：更适合被新事实取代。
- 情景记忆：更适合衰减、摘要或归档。
- 程序性经验：更适合基于成功/失败反馈强化。
- 隐私记忆：更适合主动删除或隔离。
