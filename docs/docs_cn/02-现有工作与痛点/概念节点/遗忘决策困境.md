# 遗忘决策困境

遗忘决策困境指 Agent Memory 中最根本的问题：系统如何决定什么应该被记住，什么应该被遗忘。

## 为什么困难

单条记忆的价值通常无法在写入时被准确判断。某条信息当下看似无关，却可能在未来任务中成为关键线索；某条信息当下看似重要，却可能很快过时、被证明错误或与新环境不再匹配。

这使得遗忘决策天然具有不确定性：

- 写入时面向未来价值，判断依据不足。
- 遗忘时基于过去表现，但未来仍可能重新变得重要。
- 记忆之间存在依赖关系，删除单条记录可能破坏后续推理链。
- 长期 Agent 的正确性更像状态轨迹属性，而不是单条记录属性。

## 启发式方法的不足

常见规则包括时间新近度、访问频率、相似度、重要性评分和存储预算。这些规则容易实现，但只能近似回答“哪条记忆可能有用”，无法回答“这条记忆是否应继续影响未来状态”。

## 研究指向

遗忘决策应从记录级删除转向状态级治理。系统需要持续估计每条记忆的价值、成本、可靠性、冲突程度、时间适用性和安全风险，并据此决定写入、保留、巩固、降权、压缩、归档或删除。
