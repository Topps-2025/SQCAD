# 参数化前视偏差

参数化前视偏差指未来信息不是存在于外部记忆库或上下文中，而是已经被大模型训练进参数权重中，从而成为模型内部知识的一部分。当任务要求 Agent 站在历史认知时点行动时，模型可能利用在该时点之后才出现的结果，令“历史推理”退化为参数化记忆复现。

## 与外部记忆的区别

外部记忆中的信息可以：

- 删除。
- 降权。
- 归档。
- 隔离。
- 添加时间戳和权限约束。

参数化记忆则不同。它分布在模型权重中，通常无法定位到单条事实，也无法通过简单删除某个文档来移除。

但二者不是简单替代关系。即使模型能够正确回答，外部记忆仍可能提供参数知识没有的：

- 可引用的来源与证据链；
- 事件发生时间与信息可得时间；
- 用户/任务权限和撤回语义；
- 新近更新、局部事实和可执行经验；
- 对推理过程的审计与纠错入口。

因此，正确问题不是“模型知道就一定不写”，而是：候选外部记忆相对参数知识是否具有**增量行动价值、证据价值、时间边界价值或可撤回价值**。

## 为什么是遗忘难题

普通 Agent Memory 遗忘机制主要管理上下文和外部存储。参数化前视偏差说明，Agent 的“记忆”还包括基座模型自身携带的历史知识。即使外部记忆严格按时间切分，模型仍可能在生成过程中调用未来信息；反过来，若评测未区分答案来自参数还是外部证据，也会错误估计外部记忆的收益。

现有 Agent Memory 论文大多优化外部记忆的写入、检索或压缩，尚少将“参数—外部重叠”作为写入决策变量。LLM 数据污染研究已证明训练数据污染会扭曲通用 LLM 评测，但这并不自动解决 Agent Memory 的生命周期与时间治理问题。

## 可能治理方向

- 使用时间截断训练或时间隔离数据构建评估模型；时间截断模型是最强控制，但成本较高。
- 在任务提示中显式设定认知时间点，但这只能缓解，不能保证消除。
- 为每条外部记忆保存 `source`、`available_at`、`valid_from/to`、`scope` 与 `revocation`，检索阶段硬性过滤未来材料。
- 对模型输出进行时间一致性审查，并要求关键结论附当时可得证据。
- 使用参数遮蔽、证据遮蔽、记忆替换和时间切分对照，区分答案来自参数、外部记忆还是二者重叠。
- 对无法精确删除的参数化未来知识，采用证据优先和审计，而不把普通遗忘机制误作参数层面的精确删除。

## 最小可证伪实验

构造同一任务的三类条目：模型较可能已知的稳定常识、模型未知或新近出现的局部事实、以及在查询时点之后才可获得的未来信息。比较全量外写、无外写与“增量价值门控”三种策略，并在严格时间切分下报告：任务效用、外部证据引用率、冗余写入量、未来信息使用率和错误归因率。只有当门控同时减少冗余并保持/提升时点一致的行动质量，才可主张它解决了参数—外部记忆边界问题。
