# 有限算力

有限算力不是暂时的工程约束，而是开放世界智能的长期前提。因为开放世界的复杂度增长速度通常快于可用算力增长速度。

## 研究含义

- 不能把“更多 token / 更多搜索 / 更多试错”当作唯一方向。
- 需要提高单位算力产生的决策质量。
- 需要用[[Agent Memory|记忆]]复用已有经验，用[[推理]]减少外部试错，用[[持续学习]]在反馈中修正策略。

## 关键词

- 以查代算
- test-time compute scaling
- bounded rationality
- satisficing
