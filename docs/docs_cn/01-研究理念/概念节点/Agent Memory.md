# Agent Memory

Agent Memory 是 Agent 在多轮交互和长期任务中保存、检索、更新和重组经验的机制。

## 不是简单 RAG

RAG 更像是外部知识检索，而 Agent Memory 更强调主体自身经历的沉淀：

- 它保存“我在什么情境下做过什么”。
- 它记录“这个行动导致了什么反馈”。
- 它抽象“哪些失败模式应该避免”。
- 它形成“下次遇到相似情境时应激活什么先验”。

## 两类基本记忆

- 短期记忆：维持当前任务中的上下文、目标、约束和中间结论。
- 长期记忆：沉淀跨任务经验、领域知识、用户偏好、失败反思和可复用技能。

## 为什么重要

在[[有限算力]]下，Memory 让 Agent 以查代算；在[[开放世界问题]]中，Memory 让 Agent 形成可更新的信念结构；在基模趋同时，Memory 是 Agent 层最难复制的差异化资产。

## 子方向

- 巩固：把短期经验沉淀为长期经验。
- 更新：根据新反馈修正旧记忆。
- 索引：让记忆可定位、可组织。
- 检索：在任务中取出相关记忆。
- 压缩：把原始轨迹抽象为可复用经验。
- [[遗忘机制]]：删除、降权或隔离过期、冲突、低价值和有害记忆。
