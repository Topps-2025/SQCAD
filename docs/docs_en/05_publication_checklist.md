# Publication checklist

- [ ] Freeze repository commit, Python version and dependency lock.
- [ ] Run all tests from a clean environment.
- [ ] Verify external database manifest and dataset hashes.
- [ ] Complete Gate A double annotation and adjudication.
- [ ] Run unseen-scope and scope-shift experiments.
- [ ] Reproduce at least the simple and internal baseline tiers.
- [ ] Separate local reproduction, paper-reported numbers, proxy and oracle results.
- [ ] Verify third-party data and code licenses before redistribution.
- [ ] Add only claims supported by the claim-evidence map.
