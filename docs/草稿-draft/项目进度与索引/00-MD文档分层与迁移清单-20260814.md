# Markdown 文档分层与迁移清单（2026-08-14）

## 目标

本仓库的 Markdown 分为三种用途：

1. `docs/实验证据链/`：对外可审查的实验、实验证明方向、数值结果和声称边界；
2. `docs/研究逻辑与理论证明/`：数学定理、证明、形式化定义和理论审计底稿；
3. `docs/草稿-draft/`：研究路线、框架方案、实验规划、基线可达性、历史版本和项目台账。

“对外”在本项目中指当前论文证据链入口，不等同于把所有理论证明隐藏。数学证明继续保留在独立的理论证明区，避免实验报告和路线规划混杂。

## 迁移原则

- 不删除历史文件，只移动并保留 Git 历史；
- 移动后同步修复仓库内 Markdown 链接；
- 外部证据链只引用实验报告、数值佐证、实验审计和结果，不引用“下一步怎么做”的路线文件作为已完成证据；
- 理论公式统一使用 Obsidian 可渲染的美元分隔符：行间公式使用 `$$ ... $$`，行内公式使用 `$ ... $`；
- 不在公式中使用仅适用于 LaTeX 文档的 `$
`、`
$`、`$`、`$` 分隔符。
