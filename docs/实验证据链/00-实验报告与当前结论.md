# 实验报告与当前结论 — SQCAD 证据链总览（2026-08-13）

> 本目录是 SQCAD 论文证据链的**外部总装**：按逻辑顺序回答“什么实验佐证什么主张，主张如何被形式化，形式化如何支撑框架设计实验”。主目录只保留直接承担 research gap、充分性和必要性论证的报告；真实轨迹、基线主表、成本与统计等外围支撑保存在 `../草稿-draft/实验报告/外围支撑归档-20260813/`，历史版本和旧路线保存在 `../草稿-draft/实验报告/` 的其他子目录或文件中。

**证据链的五段逻辑顺序**：

1. **Research gap 佐证实验**——哪些反例实验建立了"persistent-access lifecycle value 不可识别"的 gap；
2. **形式化定理与陈述**——gap 被形式化为 Theorem 1/2/3/4 与 Corollary（Theorem 4 = 门控必要性，`11`/`12`）；
3. **充分性实验**——定理刻画的充分可审计授权条件被实现为 Evidence–Qualification–Access 协议，并在协议路线与观测路线中验证；
4. **必要性审查**——检验 C1–C8 是否为唯一道路，并证明未识别类上的 committing-rule 下界；
5. **现实与部署支撑**——以真实轨迹/半合成接地、基线两层比较、成本合同和统计冻结限定外部效度。

## 1. Research gap 佐证实验

**实验**：三个构造性反例 + 公平性审查（`01-Gap证明实验报告-v2-20260812.md`、`02-Gap实验公平性审查-20260812.md`）。

| 反例 | 构造 | 关键数字 | 佐证的 gap |
|---|---|---|---|
| **命题 A**（观测等价 SCM） | 共享随机序列使 m_star 与 m_prime 完全共暴露，两世界 P(O) 代数等价（max diff = 0.0），但 M₁ 中 lifecycle = +1650、M₂ 中 = −1100 | Memory Worth 在 M₂ 的 regret = 1100 | 观测日志**在信息论层面**无法识别生命周期价值——即使换成正确设定的因果估计器也失败 |
| **命题 B**（真 do-intervention） | forced-in/forced-out 使 Δ_do(m_short) = Δ_do(m_long) = 2.000 精确相等 | m_short lifecycle = −1784（应 archive），m_long = +1776（应 keep）；CMI observational regret = 1784 | 即使局部因果效应**精确已知**，也不足以决定生命周期决策——query-local ≠ lifecycle |
| **命题 C**（source-equivalent 世界） | source 数据完全相同的两个世界，target 机制不同 | source 平均效应不能无条件迁移 | 笼统 source-scope 平均不构成生命周期证据 |

**公平性审查**（S1 信息 / S2 构造 / S3 非稻草人 / S4 正面无特权）判定**总体公平**：基线获得完整信息集、其规范估计器在构造内无偏（命题 B 中 CMI 拿到正确的因果答案仍做错决策）、失败是结构性的而非统计性的；失败均发生在**随机化暴露**（对基线最有利）下。两处代码弱点已修正（命题 A 全联合分布验证、命题 B oracle 列移出日志）。

> **结论**：gap 是 **counterexample-grounded memory-specific identification gap**——不是 "fundamental theoretical gap proved"，但足以支撑严肃的理论型研究问题。

## 2. Research gap 引向的形式化定理与陈述

**文档**：`../研究逻辑与理论证明/11-形式化定理陈述与证明.md`（完整证明与决策期模型）。

| 定理 | 陈述（一句话） | 状态 |
|---|---|---|
| **Theorem 1** | 存在观测分布 P(O\|M₁) = P(O\|M₂) 而 lifecycle value 符号相反的世界（observational non-identifiability） | 构造性证明 + 代码验证 |
| **Theorem 2** | 即使 query-local do-effect 相等，lifecycle value 也可以符号相反（local intervention insufficiency） | 构造性证明 + 代码验证 |
| **Theorem 3** | 在充分可审计授权条件 C1–C8 下，\(V_s^\pi(a)\) 可由双路估计器识别：(a) 协议路径（随机化持久动作的 rollout 样本均值）、(b)(c) 观测路径（sequential g-formula / DR(OPE)）；条件失败时 Qualification 输出 `{point, bound, unresolved, mismatch}` | 协议路线与 g-formula 在各自验证范围内通过；支持缺失会产生可预言错误，局部效应层 DR 性质通过，完整 lifecycle-level sequential DR 尚未验证；部分识别/敏感性输出能把若干错误点决策改写为 unresolved |
| **Corollary** | source-scope 效应不无条件运输（scope transport limitation） | 构造性证明 + Stage 2 scope 违反验证 |
| **Theorem 4** | 未识别类上任何 committing 规则最坏情况 regret ≥ \|τ1\|\|τ2\|/(\|τ1\|+\|τ2\|) = 660、错误概率 ≥ 1/2；拒绝或获取干预证据是唯一低于该界的选项，审计性是必要性推论 | 完整证明 + 计算验证（`necessity_counterexamples.py`，`11`/`12`） |

**估计目标**（三种量必须分开）：historical association（Memory Worth）、query-local intervention effect（CMI）、**persistent-access lifecycle value** \(V_s^\pi(a) = E^\pi[\sum_t \gamma^{t-1}(Y_t - \lambda C_t - \rho R_t) \mid do(A_i^{pers}=a), s]\)（SQCAD）。

## 3. 框架设计实验：识别协议的两阶段验证

**实验**：`03-识别恢复实验报告-20260812.md`。框架的三个组件（Evidence 层日志、Qualification 门控、Access 协议）由定理的识别条件逐条实现。

### Stage 1 — 理想识别环境（验证 Theorem 3(a)）：**通过**

协议路径估计器（随机化持久动作 + H=150 步 rollout，oracle 用同一机制、同一 H/γ/动作窗口、独立 RNG 流）恢复已知生命周期值：

- **bias = −0.47**（MC 水平，无系统性）；**CI 覆盖 12/12**（multi-seed 0.97±0.05，CI 诚实）
- **自信错误 = 0**、mismatch = 0；**unresolved 恰为 3 个 neutral**
- short_term 记忆（局部 +0.2、生命周期 −5.2）被**正确 archive**——Theorem 2 教训在框架内成立
- 对照：SQCAD 门控 regret 2.6 / err 0.0；CMI 与 naive OPE regret 10.3 / err 0.17（恰在 short_term 上误判）；association regret 91.3

### Stage 2 — 逐条件违反（验证 Theorem 3(d) + 门控）：**通过**

| 违反 | 失败条件 | 门控输出 | 盲于门控的强制决策 |
|---|---|---|---|
| 采纳误差 | C6（D≠E，误记 0.3） | 12 `unresolved` | regret 0.4 |
| 共同暴露 bundle | C7（corr=1.00，bundle +9.0 掩盖 −41 的 harmful） | pair `unresolved` | regret **41.0** |
| 资格选择 | C3（harmful 永不随机化） | 5 `unresolved` | regret **83.4** |
| 测量漂移 | C8（版本层 z=147.6≫3） | 12 `mismatch` | regret 2.2 |
| 作用域漂移 | Cor 1（target 在 source 支持外） | 12 `mismatch` | regret 1.0 |

> **门控消融结论**：五种违反下门控全部弃权、**自信错误恒为 0**；强制变体在 C7/C3 上付出结构性代价。弃权不是免费的（C7 下放弃 useful 成员的 48 价值）——框架承诺的是"绝不做自信错误决策"，不是"弃权零损失"。

## 4. 当前结论

### 可以声称（均有实验支撑）

1. **存在** memory-specific 的 persistent-access lifecycle value 识别空白（三个公平构造性反例）。
2. **关联、局部因果、无条件 source 平均都不足以**做生命周期决策（Theorem 1/2/Corollary + 反例数字）。
3. **识别条件 C1–C8 满足时**，随机化持久动作协议能**恢复已知生命周期值**（bias≈0、CI 诚实、决策零错误、unresolved 恰为不可识别对象，5 seeds 稳定）。
4. **在测试的五类条件违反中**，Qualification 门控按预注册规则输出 `unresolved`/`mismatch`，没有把这些失败对象升级为自信动作；这不等于门控在所有条件违反或所有阈值下永不犯错。
5. **在统一合成流 + 成本合同下**，SQCAD 在默认/风险规避/延迟敏感价格区间的平均净收益最高；相对配探测 CMI 的均值优势约 0.069，但 paired CI 为 [0.000, 0.260]，不能声称统计显著领先。对最优非探测基线的 break-even 探测价格为默认的 110 倍；这些不是“真实 Agent Memory 部署收益已证明”。
6. **统计与工程门成立（`08` 报告）**：采样单元=seed 的 studentized paired bootstrap 修复正态近似欠覆盖（heavy-tail 已知真值 0.9275 vs 0.8745；D0 世界 n_traj=300 时 seed-level 覆盖 0.92–1.00 vs within-seed 错误单元 0.79，覆盖–n 斜率反转）；主表 utility 差值 CI 不跨 0（vs 最优可传输基线 +0.100 [0.052, 0.156]、vs 最优非探测 +0.269 [0.216, 0.310]）；rare recall 低于 rrf（0.833 vs 0.967）如实报告；成本合同 V 领先 CI 下界 0.0（10 seeds 不可显著区分，如实标注）；"代码—配置—结果—报告"四件套 SHA-256 冻结成立。
7. **必要性审查与门控下界完成（`09`/`10`/`11` 报告 + `12` 定理文档）**：(a) proxy 基线被限制在结构级声称，禁止外推“现有理论均无法处理”；(b) 11 篇最接近工作全文核对确认当前 gap 的限定表述；(c) Lemma A–D 表明完整 C1–C8 不是唯一道路，其中 C2/C3、C6 存在替代路线，C7/C8 可在改变治理粒度或 estimand 后退守；C1、C4、C5 尚未逐项证明不必要；(d) Theorem 4 在未识别双世界类上给出 committing rule 的 regret ≥ 660、错误概率 ≥ 1/2 下界；(e) “minimal conditions”更名为“一组可操作、可审计的充分识别与治理授权条件”。

### 尚不能声称

- **完整序贯 DR（lifecycle 层面的双重稳健）**——DR 性质在局部效应层面逐格验证，lifecycle 层面实现的是 g-formula（OPE）；
- 观测路径在真实 Agent 日志上的行为（`04-估计有效性实验报告` 全部在已知真值合成世界上）；SQCAD 改善真实 Agent Memory 治理——**尚无 chronological future rollout 或真实数据验证**；
- ~~RCT 正态近似 CI 的名义覆盖（full 配置 88.5% 且随 n 下降，需 paired bootstrap 修复，Gate 5 承接）~~——✅ `08-统计与工程门`（seed-level studentized paired bootstrap；heavy-tail 已知真值 0.9275 vs 正态 0.8745；D0 世界 seed-level 检查 0.92–1.00 @n_traj=300 vs within-seed 0.79）。**如实标注**：seed 均值 truth 检查含 oracle MC 噪声（≈0.35 sd），观测覆盖是名义 95% 的下界，且 n_traj=100 时检查噪声封顶（0.50）；
- 门控"零自信错误"是**配置相关**事实（z*=1.96 在 full 配置下仍有 1.43% 自信错误率，z=2.58 才归零）——只能声称"门控提供 coverage–risk 曲线并允许预注册阈值"，不能声称"门控从不犯错"；
- Theorem 4 是最坏情况频率命题（贝叶斯强先验下 committing 可以更好）、界常数 660 随类内效应量缩放、识别路线分类学未证明完备——必要性声称限于"未识别类上 committing 规则的下界 + 拒绝的必然性 + 审计性推论"（`11`/`12`）；
- 11 篇最接近工作的核对是**估计目标层面**的（全部是 committing 规则、无生命周期识别意识）——"官方完整系统在该界上必然表现差"仍是系统级外延，等待 R3（`09` 升级协议）。
