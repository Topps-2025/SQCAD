# Agent Memory 选择性遗忘机制：存量管理与读时过滤

## 0. 研究范围、术语与语料纳入标准

本文所称的 Agent Memory 遗忘机制，不泛指 Agent Memory 的全部生命周期，也不等同于模型参数的 Machine Unlearning。其研究对象是**已经进入外部记忆库的存量记忆**，研究目标是在长期交互中决定哪些单元应被保留、强化、降权、融合、压缩、抑制或移出默认访问路径，并在具体任务读取时限制 Agent 对不适用记忆的关注。该问题位于“写入—管理—读取”链条的后两个环节：写入决定候选记忆进入系统；管理改变存量记忆的状态、强度或表示；读取则在当前任务条件下访问经管理后的记忆子集。

本节将这一范围称为**选择性记忆管理（selective memory management）**。它包括两类相互耦合的操作：

1. **存量记忆管理**：对已有单元的保留强度、层级、表示粒度、冗余关系或默认可访问性进行调整；
2. **读时过滤**：在查询或任务上下文给定时，降低不适用、低价值或低激活记忆进入 Agent 当前推理上下文的机会。

“遗忘”在此是上述管理造成的可访问性下降、信息压缩或状态退出，而不是未写入、单纯检索失败或参数化知识删除。Machine Unlearning 则试图消除训练样本对模型参数化行为的影响；删除外部记忆条目并不意味着模型已完成 unlearning，反之亦然 [R44][R45]。

### 0.1 核心语料与背景语料的区分

核心语料的纳入条件为：论文的主要问题或核心机制必须直接改变**存量外部记忆的保留/遗忘状态**，或直接以该状态控制**读时访问**。仅处理写入准入、一般更新、表示组织、纯检索优化或通用评测的工作不作为本节的核心证据；它们属于 Agent Memory 大框架，在第二节用于交代上游条件、比较对象或评测资源。

| 文献类别 | 代表工作 | 与本研究议题的关系 |
| --- | --- | --- |
| 核心语料：遗忘/保留状态管理 | MemoryBank、FadeMem、Memory Worth [R4][R16][R17]。 | 直接估计或调整存量记忆的保留、衰减、抑制或弃用。 |
| 核心语料：管理—读取联动 | Oblivion [R13]。 | 以衰减驱动的激活状态协调存量记忆管理与读时访问。 |
| 核心语料：压缩式遗忘 | SimpleMem、DeMem [R8][R18]。 | 通过紧凑表示或决策充分性边界减少存量记忆负担，并服务后续读取。 |

该界定并不否认背景工作的重要性，而是避免将“能写入或检索记忆”误写为“已经解决存量记忆应被遗忘及读时不应关注什么”的问题。

## 1. 核心论文的覆盖矩阵：从存量状态到读时关注

同一论文可能同时包含状态调整和读时使用；因此不应以互斥标签强行拆分论文。表 1 按论文的**主要贡献**列出其覆盖位置、核心算法机制和直接解决的痛点，每篇工作仅出现一次。

| 核心论文 | 主要贡献 | 存量管理 | 读时过滤 | 核心算法机制 | 直接解决的痛点 |
| --- | --- | --- | --- | --- | --- |
| MemoryBank [R4] | 基于时间与重要性的长期记忆遗忘。 | ✓ | 间接 | 时间衰减与重要性调节。 | 长期对话中记忆不断累积。 |
| FadeMem [R16] | 生物启发的差异化保留、衰减和融合。 | ✓ | 间接 | 双层记忆、相关性—频率—时间重要性、差异化指数衰减、冲突消解和融合。 | 二元保留造成的信息过载或上下文边界遗忘。 |
| Oblivion [R13] | 衰减驱动的 Agentic memory control。 | ✓ | ✓ | 激活度衰减、不确定性/缓冲充分度控制读路径、响应贡献强化写入。 | 常开读取和扁平存储引起的干扰与时延。 |
| Memory Worth [R17] | 用结果反馈支持信任、抑制或弃用。 | ✓ | 间接 | 记忆—成功/失败双计数与条件成功概率。 | 静态重要性难适应任务分布变化。 |
| SimpleMem [R8] | 语义压缩与意图感知读取。 | ✓ | ✓ | 结构化语义压缩、在线语义合成、意图感知检索规划。 | 完整历史冗余与反复过滤的 token 开销。 |
| DeMem [R18] | 以决策充分性刻画安全遗忘边界。 | ✓ | 任务条件化 | 决策中心率失真、按决策损失约束压缩。 | 描述保真不能识别对决策真正必要的信息。 |

表 1 的“间接”表示：该工作通过管理后的强度、层级或表示影响后续可见性，但未把“当前任务不应读取什么”单独建模为读时决策。由此，FadeMem 是本研究的关键存量管理基线；Oblivion 是连接存量管理与读时过滤的关键闭环基线；SimpleMem 和 DeMem 则构成“压缩即选择性保留”的代表路线。

## 2. 工作方向一：存量记忆的自适应保留、降权与遗忘

### 2.1 要解决的技术问题

长期 Agent 若将存量条目维持为同等可访问状态，候选规模、检索干扰和维护成本会随交互增长；若仅依固定期限或容量阈值清除，又可能淘汰低频但关键的约束。该方向关注的不是是否写入新信息，而是已有记忆在后续交互中是否仍应保持高激活、被降权或退出默认访问。

### 2.2 核心算法机制与代表贡献

MemoryBank 以时间与重要性实现长期交互中的遗忘 [R4]。FadeMem 用语义相关性、衰减访问频率和新近度构造重要性分数，基于双层结构迁移记忆，并以重要性调制的指数衰减、访问强化、冲突抑制和语义融合管理存量条目 [R16]。Memory Worth 则以记忆被检索时与成功/失败结果的共现更新条件成功概率，并将该信号用于信任、抑制或弃用 [R17]。

这些工作共同贡献在于：将“全部保留或全部删除”的二元做法替换为连续或多状态的存量管理，使记忆强度、访问优先级或存续状态可随交互历史变化。

### 2.3 已覆盖范围与边界

该方向已覆盖按时间、频率、语义相关性和结果反馈实施差异化保留，但这些信号并不自动构成未来行动价值的充分证据。FadeMem 的重要性基于相关性、访问频率和时间模式 [R16]；Memory Worth 也明确将其量界定为关联而非因果贡献 [R17]。因此，低频关键例外、任务漂移以及“降权/弃用是否改变任务行动”的条件化归因仍未由这些机制充分解决。

## 3. 工作方向二：压缩式遗忘与决策相关表示维护

### 3.1 要解决的技术问题

存量记忆的管理不必总以删除为终点。若原始交互全部保留，嵌入、索引、检索和提示词成本会不断累积；若压缩仅追求文本短小或语义相似，则可能抹去支持后续任务所必需的条件差异。该方向研究如何以更紧凑的表征替代冗余细节，并使读时系统主要接触经过选择性保留的信息。

### 3.2 核心算法机制与代表贡献

SimpleMem 通过结构化语义压缩将历史信息转化为更紧凑的表示，结合在线语义合成和意图感知检索规划以减少冗余读取 [R8]。DeMem 将压缩建模为决策中心的率失真问题：若合并或压缩使原本应区分的历史在固定资源预算下不再支持高质量决策，则该信息不应被遗忘 [R18]。FadeMem 的 LLM 引导融合也属于该方向的辅助机制，但其主要贡献仍归于前述自适应保留与衰减，不在本节重复作为独立论文分类。

该方向的贡献是将“少记忆”从简单容量削减转化为**保留对读取和决策仍有区分作用的信息**。

### 3.3 已覆盖范围与边界

SimpleMem 和 DeMem 已分别以语义结构和决策充分性控制压缩，但两者都未充分规定压缩单元的来源、版本、适用时间、作用域或恢复语义。特别是，DeMem 的“安全遗忘边界”对应其给定决策任务和预算下的区分保持，不能直接推出对任务分布变化、低频例外或不同主体的普适退出规则。压缩后哪些信息在具体任务中仍不应读取，也需要与读时过滤机制联合评估。

## 4. 工作方向三：管理状态驱动的读时过滤

### 4.1 要解决的技术问题

存量管理的效果必须在读取时落地：即使某条记忆已被降权、压缩或抑制，若读时机制仍以常开、扁平或固定 top-k 的方式将其暴露给模型，管理带来的降噪可能无法实现。该方向因此关注在具体任务条件下，如何利用存量记忆的管理状态决定**哪些记忆不应被优先读取或不应进入当前推理上下文**。

### 4.2 核心算法机制与代表贡献

Oblivion 是核心语料中最直接的代表：其将 forgetting 表述为可访问性衰减，并用当前不确定性和缓冲区充分度调节读路径，同时用响应贡献强化有用反应对应的记忆 [R13]。SimpleMem 的意图感知检索规划也使压缩后的信息在读取阶段按任务意图被选择 [R8]。FadeMem 通过重要性和层级间接改变后续记忆可见性，但并未单独提出任务条件化的读时过滤器 [R16]。

该方向的贡献是把“遗忘”从库内删除或压缩扩展到读时注意力分配：对当前任务无关、低激活或预算不允许的记忆，不应以与关键证据相同的优先级影响推理。

### 4.3 已覆盖范围与边界

现有机制已说明访问强度、查询意图或缓冲区状态可减少冗余读取，但尚未充分揭示：管理状态变化是否真正导致 Agent 在特定任务中避免关注不适用记忆，以及这种“未关注”是否减少错误计划、工具误用或无效推理。换言之，读时过滤的有效性不能仅由检索相关度、延迟或最终 QA 指标替代；它需要连接“状态调整—候选暴露—模型采纳—行动后果”的过程证据。

## 5. 与第四节 research gap 的衔接

第四节仅从表 1 所列核心语料及其作者明确的边界推导研究缺口。研究缺口并非“目前没有遗忘、压缩或读取控制方法”，而是这些方法在存量管理—读时过滤闭环中共同尚未解决的问题：如何证明状态调整的行动价值、如何在非平稳和低频关键条件下保持稳健、如何使压缩/衰减真正约束读时关注，以及如何对该闭环实施过程级验证。

## 6. 小结

本节将研究议题界定为 Agent Memory 的选择性遗忘机制，即对存量外部记忆进行保留、降权、压缩或退出管理，并将该状态用于约束读时关注。核心文献不以“写入、管理、读取”三个独立模块强制分组，而以覆盖矩阵呈现其跨环节机制：FadeMem 代表存量衰减与融合，Oblivion 代表管理—读取联动，SimpleMem 与 DeMem 代表压缩式选择性保留，MemoryBank 与 Memory Worth 则代表时间/重要性和结果反馈驱动的保留决策。更广泛的 Agent Memory 写入、更新、组织和纯检索研究仍在第二节保留，但不作为本节 research gap 的直接证据基础。
