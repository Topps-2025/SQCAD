# Agent Memory 原始文献证据索引

本附录汇集第二部分所引主要文献的英文原文摘录。每条记录包括稳定来源及其章节位置、实质性摘要摘录、作者明确提出的研究问题、作者报告的结论或结果，以及与本综述论点对应的编辑性说明。编辑性说明用于阐明文献的适用范围，不构成原作者的直接表述；引文中的方括号和省略号仅表示删节，不改变原文主张。

本索引区分“选择性遗忘机制核心语料”与“Agent Memory 大框架背景语料”。前者直接支撑第三、四节关于**存量外部记忆管理与读时过滤**的讨论，包括 MemoryBank、FadeMem、Oblivion、Memory Worth、SimpleMem 与 DeMem；后者用于说明写入、更新、组织、一般检索或评测的相邻进展。第四节的 research gap 仅由核心语料的原文主张、作者明确限制或方法设定推导，而不以背景语料替代直接证据。

编辑性边界说明采用四类证据等级：**A** 表示作者明确给出的限制或假设，**B** 表示由研究对象或实验设置直接界定的方法范围，**C** 表示相邻领域提供的重要性证据，**D** 表示经版本固定的工程实现证据。D 类可支持对公开系统机制的描述，但不替代同行评议论文的性能或因果证据。书目信息见 [第二部分参考文献](./参考文献/第二部分参考文献.md)。

## A. 选择性遗忘机制核心语料：原文证据汇编

本节集中列出第三、四节所依据的六篇核心论文。每篇工作只列一次，并按“研究问题—原文机制—作者主张—可支持的边界”整理。后文保留其余 Agent Memory 文献的详细证据，以支持第二节的整体研究版图；这些背景工作不作为第四节 research gap 的直接论据。

### R4. MemoryBank（存量记忆的时间—重要性遗忘）

- **Primary source:** [AAAI / DOI](https://doi.org/10.1609/aaai.v38i17.29946), Abstract and §1 *Introduction*.
- **Research problem (verbatim, Abstract):** “Recognizing the necessity for long-term memory, we propose MemoryBank, a novel memory mechanism tailored for LLMs.”
- **Mechanism evidence (verbatim, Abstract):** “MemoryBank enables the models to summon relevant memories, continually evolve through continuous memory updates, comprehend, and adapt to a user’s personality over time by synthesizing information from previous interactions.”
- **Reported conclusion (verbatim, Abstract):** “SiliconFriend, equipped with MemoryBank, exhibits a strong capability for long-term companionship as it can provide emphatic response, recall relevant memories and understand user personality.”
- **Scope linkage (editorial):** 直接相关于长期存量记忆的时间/重要性遗忘；但原文不以行动因果归因或任务条件化读时排除为优化对象。**Boundary: B; Gap 1/3.**

### R16. FadeMem（差异化衰减、冲突抑制与融合）

- **Primary source:** [arXiv:2601.18642](https://arxiv.org/abs/2601.18642), Abstract; §2 *Methodology*; §4 *Conclusion*.
- **Research problem (verbatim, Abstract):** “Current AI systems employ binary retention strategies that preserve everything or lose it entirely.”
- **Mechanism evidence (verbatim, Abstract):** “FadeMem implements differential decay rates across a dual-layer memory hierarchy, where retention is governed by adaptive exponential decay functions modulated by semantic relevance, access frequency, and temporal patterns.”
- **Additional mechanism evidence (verbatim, Abstract):** “Through LLM-guided conflict resolution and intelligent memory fusion, our system consolidates related information while allowing irrelevant details to fade.”
- **Reported conclusion (verbatim, Abstract):** “Experiments… demonstrate superior multi-hop reasoning and retrieval with 45% storage reduction.”
- **Scope linkage (editorial):** 直接覆盖存量记忆的保留强度、层级迁移、衰减、冲突抑制和融合；其重要性信号不构成非平稳条件下的反事实行动价值估计，也未单独建模任务条件化读时排除。**Boundary: B; Gap 1/2/3/4.**

### R13. Oblivion（管理—读取联动的访问衰减）

- **Primary source:** [arXiv:2604.00131](https://arxiv.org/abs/2604.00131), Abstract and §1 *Introduction*.
- **Research problem (verbatim, Abstract):** “Memory-augmented LLM agents rely on ‘always-on’ retrieval and ‘flat’ memory storage, causing high interference and latency as histories grow.”
- **Mechanism evidence (verbatim, Abstract):** “We introduce Oblivion, a memory control framework that casts forgetting as decay-driven reductions in accessibility, not explicit deletion.”
- **Reported conclusion (verbatim, Abstract):** “Oblivion dynamically adapts memory access and reinforcement, balancing learning and forgetting under shifting contexts.”
- **Scope linkage (editorial):** 核心的管理—读取联动证据：存量激活衰减直接改变读时可访问性；但该工作未提供干预式估计，以证明被抑制条目不应在特定任务中被 Agent 采纳。**Boundary: B; Gap 1/2/4.**

### R17. Memory Worth（结果反馈驱动的信任、抑制与弃用）

- **Primary source:** [arXiv:2604.12007](https://arxiv.org/abs/2604.12007), Abstract and §1 *Introduction*.
- **Research problem (verbatim, Abstract):** “How [should an agent decide] which memories to trust, suppress, or deprecate as the agent’s task distribution shifts?”
- **Mechanism evidence (verbatim, Abstract):** “Memory Worth (MW): a two-counter per-memory signal that tracks how often a memory co-occurs with successful versus failed outcomes.”
- **Author-stated limitation (verbatim, Abstract):** “Importantly, p+(m) is an associational quantity, not a causal one: it measures outcome co-occurrence rather than causal contribution.”
- **Scope linkage (editorial):** 为“保留/退出价值需要超越共现”的 gap 提供直接作者证据；其平稳检索和最小探索条件亦限制了向非平稳读时过滤的外推。**Boundary: A; Gap 1/3.**

### R8. SimpleMem（语义压缩与意图感知读取）

- **Primary source:** [arXiv:2601.02553](https://arxiv.org/abs/2601.02553), Abstract and §1 *Introduction*.
- **Research problem (verbatim, Abstract):** “Existing approaches either retain full interaction histories… leading to substantial redundancy, or rely on iterative reasoning to filter noise, incurring high token costs.”
- **Mechanism evidence (verbatim, Abstract):** “We propose a three-stage pipeline… (1) Semantic Structured Compression… (2) Online Semantic Synthesis… and (3) Intent-Aware Retrieval Planning.”
- **Reported conclusion (verbatim, Abstract):** “Our method consistently outperforms baseline approaches in accuracy, retrieval efficiency, and inference cost.”
- **Scope linkage (editorial):** 直接覆盖压缩式存量管理与任务意图驱动的读取规划；但并未以行动干预检验被压缩细节在后续漂移或低频条件下的作用。**Boundary: B; Gap 1/2/3/4.**

### R18. DeMem（决策中心的遗忘边界）

- **Primary source:** [arXiv:2605.10870](https://arxiv.org/abs/2605.10870), Abstract and §1 *Introduction*.
- **Research problem (verbatim, Abstract):** “Memory is valuable not because it faithfully describes the past, but because it preserves the distinctions between histories that must remain separated under a fixed budget to support good decisions.”
- **Mechanism evidence (verbatim, Abstract):** “We cast this as a decision-centric rate-distortion problem, measuring memory quality by the loss in achievable decision quality induced by compression.”
- **Reported conclusion (verbatim, Abstract):** “This yields an exact forgetting boundary for what can be safely forgotten.”
- **Scope linkage (editorial):** 为“少而有效”的决策充分性提供直接基线；其边界由给定任务与资源预算定义，尚不等于跨任务漂移、低频例外或读时不适用信息排除的普适规则。**Boundary: B; Gap 1/2/3/4.**

## B1. LLM Agent 的系统演进与行动闭环

### R38. LLM Agent Survey (2024)

- **Primary source:** [Springer](https://doi.org/10.1007/s11704-024-40231-1), Abstract and framework sections.
- **Abstract excerpt (verbatim):** “We present a comprehensive survey of these studies, delivering a systematic review of LLM-based autonomous agents from a holistic perspective. We first discuss the construction of LLM-based autonomous agents, proposing a unified framework that encompasses much of previous work.”
- **Core research focus (verbatim, Abstract):** “the construction of LLM-based autonomous agents” and “a unified framework that encompasses much of previous work.”
- **Review linkage (editorial):** Establishes LLM-based autonomous agents as systems extending a language-model core with agent-level components. It provides a field-level framework rather than evidence for a specific memory mechanism. **Boundary: B (survey).**

### R39. LLM Agent Survey: Rise and Potential (2025)

- **Primary source:** [Springer](https://doi.org/10.1007/s11432-024-4222-0), Abstract and taxonomy sections.
- **Abstract excerpt (verbatim):** “The rise and potential of large language model based agents: a survey.”
- **Core research focus (editorial):** The survey synthesizes the construction, capabilities and applications of LLM-based agents.
- **Review linkage (editorial):** Supports the LLM-to-Agent transition as a systems-level research development. Specific claims about planning, memory, tools and environment interaction are attributed to the component taxonomy in the survey and to the corresponding primary methods. **Boundary: B (survey).**

### R40. ReAct (2023)

- **Primary source:** [arXiv:2210.03629](https://arxiv.org/abs/2210.03629), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “We explore the use of LLMs to generate both reasoning traces and task-specific actions in an interleaved manner, allowing for greater synergy between the two: reasoning traces help the model induce, track, and update action plans as well as handle exceptions, while actions allow it to interface with and gather additional information from external sources such as knowledge bases or environments.”
- **Core research question (verbatim, Abstract):** How can reasoning traces and task-specific actions be generated “in an interleaved manner” to improve their synergy?
- **Core conclusion (verbatim, Abstract):** “ReAct overcomes prevalent issues of hallucination and error propagation in chain-of-thought reasoning by interacting with a simple Wikipedia API,” and outperforms baselines on interactive decision-making benchmarks.
- **Review linkage (editorial):** Establishes the reason–act–observation loop in which external information can update subsequent plans. It does not, by itself, define a persistent cross-task memory lifecycle. **Boundary: B.**

### R41. Reflexion (2023)

- **Primary source:** [arXiv:2303.11366](https://arxiv.org/abs/2303.11366), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “We propose Reflexion, a novel framework to reinforce language agents not by updating weights, but instead through linguistic feedback. Concretely, Reflexion agents verbally reflect on task feedback signals, then maintain their own reflective text in an episodic memory buffer to induce better decision-making in subsequent trials.”
- **Core research question (verbatim, Abstract):** How can language agents “quickly and efficiently learn from trial-and-error” without extensive fine-tuning?
- **Core conclusion (verbatim, Abstract):** Reflexion “obtains significant improvements over a baseline agent across diverse tasks.”
- **Review linkage (editorial):** Demonstrates how feedback-derived episodic memory can affect later attempts without changing model weights. The work does not address long-term versioning, provenance or reversible lifecycle control. **Boundary: B.**

### R42. Voyager (2023)

- **Primary source:** [arXiv:2305.16291](https://arxiv.org/abs/2305.16291), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “VOYAGER consists of three key components: 1) an automatic curriculum that maximizes exploration, 2) an ever-growing skill library of executable code for storing and retrieving complex behaviors, and 3) a new iterative prompting mechanism that incorporates environment feedback, execution errors, and self-verification for program improvement.”
- **Core research question (verbatim, §1):** How can an embodied agent “progressively acquire, update, accumulate, and transfer knowledge over extended time spans”?
- **Core conclusion (verbatim, Abstract):** The developed skills are “temporally extended, interpretable, and compositional,” enabling reuse in a new Minecraft world.
- **Review linkage (editorial):** Provides direct evidence that a reusable skill library supports capability accumulation and transfer in an open-ended Agent. It does not establish general-purpose memory governance or deletion semantics. **Boundary: B.**

### R43. EverOS / EverMemOS (2026; open-source software and technical documentation)

- **Primary source:** [EverOS v1.2.0 release](https://github.com/EverMind-AI/EverOS/releases/tag/v1.2.0), [CITATION.md](https://github.com/EverMind-AI/EverOS/blob/v1.2.0/CITATION.md), and [How Memory Works](https://github.com/EverMind-AI/EverOS/blob/v1.2.0/docs/how-memory-works.md), accessed 2026-07-26.
- **Citation status (verbatim, `CITATION.md`):** “Paper coming soon — a technical paper is in preparation.”
- **Mechanism excerpts (verbatim, README / technical documentation):** “Markdown is the **source of truth**; the other two are **derived and rebuildable**.” “User <code>episodes/profile</code> and agent <code>cases/skills</code> are separate first-class surfaces.” “Memory is partitioned by **`<app_id>/<project_id>`**.”
- **Lifecycle excerpt (verbatim, `How Memory Works`):** “`reflect_episodes` … merges fragmented episodes within a cluster into a single coherent narrative, re-extracts atomic facts, and deprecates the originals.”
- **Review linkage (editorial):** The public implementation is an engineering counterexample to reducing Agent Memory to a vector store: it combines editable representations, typed tracks, scope isolation, asynchronous consolidation, retrieval indexes and audit state. However, it is not a peer-reviewed paper, and its documented mechanisms do not by themselves establish unified conflict semantics, verified physical deletion, or a causal improvement in task actions. **Boundary: engineering evidence; not a paper-performance claim.**

## B2. Capacity, persistent state, and memory streams

### R1. MemGPT (2023)

- **Primary source:** [arXiv:2310.08560](https://arxiv.org/abs/2310.08560), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “Large language models (LLMs) have revolutionized AI, but are constrained by limited context windows, hindering their utility in tasks like extended conversations and document analysis. To enable using context beyond limited context windows, we propose virtual context management… MemGPT… intelligently manages different memory tiers in order to effectively provide extended context within the LLM’s limited context window.”
- **Core research question (verbatim, §1):** “How can LLMs use context beyond limited context windows?”
- **Core conclusion (verbatim, Abstract):** “MemGPT is able to analyze large documents that far exceed the underlying LLM’s context window,” and its chat agents “remember, reflect, and evolve dynamically through long-term interactions.”
- **Review linkage (editorial):** Establishes the capacity-management route. It does not estimate a memory item’s conditional effect on an action outcome or define cross-scope version semantics. **Boundary: B; Q1/Q2/Q3.**

### R2. Generative Agents (2023)

- **Primary source:** [ACM DOI](https://doi.org/10.1145/3586183.3606763), Abstract; §1; §4 *Generative Agent Architecture*.
- **Abstract excerpt (verbatim):** “We describe an architecture that extends a large language model to store a complete record of the agent’s experiences using natural language, synthesize those memories over time into higher-level reflections, and retrieve them dynamically to plan behavior.”
- **Core research question (verbatim, §1):** “How might we craft an interactive artificial society that reflects believable human behavior?”
- **Core conclusion (verbatim, Abstract):** “These generative agents produce believable individual and emergent social behaviors.”
- **Review linkage (editorial):** The memory stream links retrieval, reflection, and planning, but relevance/recency/importance ranking is not an intervention-based value estimator and the paper does not test long-term deletion or scoped conflict. **Boundary: B; Q1/Q2/Q3.**

### R3. HiAgent (2024)

- **Primary source:** [arXiv:2408.09559](https://arxiv.org/abs/2408.09559), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “While considerable research has optimized performance through cross-trial memory, the enhancement of agent performance through improved working memory utilization remains underexplored. … HiAgent… leverages subgoals as memory chunks to manage the working memory of LLM-based agents hierarchically.”
- **Core research question (verbatim, Abstract):** “How [can] improved working memory utilization” enhance “agent performance”?
- **Core conclusion (verbatim, Abstract):** “Experimental results across five long-horizon tasks demonstrate that HiAgent achieves a twofold increase in success rate and reduces the average number of steps required by 3.8.”
- **Review linkage (editorial):** A working-memory compression and organization method, not a persistent external-memory lifecycle mechanism. **Boundary: B; Q3.**

### R5. MemoryOS (2025)

- **Abstract excerpt (verbatim):** “MemoryOS designs a hierarchical storage architecture and consists of four key modules: memory Storage, Updating, Retrieval, and Generation. … [It] comprises three levels of storage units: short-term memory, mid-term memory, and long-term personal memory.”

- **Core conclusion (verbatim, Abstract):** “Our pioneering MemoryOS enables hierarchical memory integration and dynamic updating.”

### R6. Mem0 (2025)

### R7. A-MEM (2025)

## C. Write control, procedural memory, and trustworthy consolidation

### R11. SAGE (2026)

- **Primary source:** [arXiv:2605.30711](https://arxiv.org/abs/2605.30711), Abstract; §1 *Introduction*; §6 *Limitations*.
- **Abstract excerpt (verbatim):** “Agentic LLMs must continuously decide whether newly extracted facts should be added, merged with existing memories, or ignored… We frame memory evolution as a novelty-detection problem and propose SAGE… [which] routes them with an adaptive threshold that tracks memory-store geometry.”
- **Core research question (verbatim, Abstract):** “Prior work has focused more on retrieval and storage than on principled write-side control.”
- **Core conclusion (verbatim, Abstract):** “Novelty-aware write control is a practical lever for improving both memory quality and system efficiency in long-term agentic memory.”
- **Review linkage (editorial):** A direct write-control baseline. The paper’s stated limitations restrict evaluation to English LoCoMo; its framework does not emit DELETE or perform compaction. **Boundary: A/B; Q1/Q3.**

### R12. ReMe (2026)

- **Primary source:** [ACL Anthology](https://aclanthology.org/2026.findings-acl.829/), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “Existing frameworks predominantly suffer from a ‘passive accumulation’ paradigm, treating memory as a static append-only archive. To bridge the gap between static storage and dynamic reasoning, we propose ReMe… [with] multi-faceted distillation… context-adaptive reuse… and utility-based refinement.”
- **Core research question (verbatim, Abstract):** “How [can] static storage [be bridged] and dynamic reasoning?”
- **Core conclusion (verbatim, Abstract):** “Self-evolving memory provides a computation-efficient path for lifelong learning.”
- **Review linkage (editorial):** Covers validated utility and procedural experience. It does not show how utility remains valid after task, user, or tool distribution shift. **Boundary: B; Q1/Q2.**

### R27. MEM1 (2025)

- **Primary source:** [arXiv:2506.15841](https://arxiv.org/abs/2506.15841), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “We introduce MEM1, an end-to-end reinforcement learning framework that enables agents to operate with constant memory across long multi-turn tasks. At each turn, MEM1 updates a compact shared internal state that jointly supports memory consolidation and reasoning.”
- **Core research question (verbatim, Abstract):** “Most LLM systems rely on full-context prompting, appending all past turns regardless of their relevance.”
- **Core conclusion (verbatim, Abstract):** “Our results demonstrate the promise of reasoning-driven memory consolidation as a scalable alternative to existing solutions for training long-horizon interactive agents.”
- **Review linkage (editorial):** Directly refutes any claim that memory consolidation is never coupled with reasoning. Its compact internal state is not a source-addressable, versioned, revocable external memory. **Boundary: B; Q2/Q4.**

### R29. PREMem (2025)

- **Primary source:** [ACL Anthology](https://aclanthology.org/2025.findings-emnlp.1204/), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “PREMem extracts fine-grained memory fragments categorized into factual, experiential, and subjective information; it then establishes explicit relationships between memory items across sessions, capturing evolution patterns like extensions, transformations, and implications.”
- **Core research question (verbatim, Abstract):** “Current systems place excessive reasoning burden on response generation, making performance significantly dependent on model sizes.”
- **Core conclusion (verbatim, Abstract):** “By performing this reasoning during pre-storage rather than when generating a response, PREMem creates enriched representations while reducing computational demands during interactions.”
- **Review linkage (editorial):** Directly refutes a ‘no pre-storage reasoning’ gap. It does not make the evidence provenance, revocation, or temporal scope of inferred relations a governed state. **Boundary: B; Q2/Q3.**

### R33. TrustMem (2026)

- **Primary source:** [arXiv:2606.25161](https://arxiv.org/abs/2606.25161), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “Existing memory agents actively update external memory through generated write, revise, and delete operations, but these updates may omit important information, corrupt existing memory, or introduce unsupported hallucinated content.”
- **Core research question (verbatim, Abstract):** “How [can we] improve the trustworthiness of memory consolidation?”
- **Core conclusion (verbatim, Abstract):** “TrustMem relies on a Memory Transition Verifier to evaluate the transition process of memory updates in terms of coverage, preservation, and faithfulness.”
- **Review linkage (editorial):** Strong evidence that trustworthy local consolidation is already an active topic. It does not establish a shared version/scope semantics across memory types, principals, and time. **Boundary: B; Q2/Q3.**

### R34. Infini Memory (2026)

- **Primary source:** [arXiv:2606.10677](https://arxiv.org/abs/2606.10677), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “Existing memory systems often store observations as isolated records, summaries, or indexed fragments, which makes evidence aggregation, fact revision, and memory maintenance difficult. We propose Infini Memory… [which] treats agent memory as topic-structured documents.”
- **Core research question (verbatim, Abstract):** “How [can] persistent memory… track changing facts and provide relevant evidence across sessions?”
- **Core conclusion (verbatim, Abstract):** “Topic-structured maintenance and iterative evidence inspection improve complementary aspects of long-term memory use.”
- **Review linkage (editorial):** Directly addresses thematic maintenance and fact revision. It does not decide whether a scoped conflict should coexist, nor whether revision changes downstream action. **Boundary: B; Q1/Q2/Q3.**

## D. 核心语料的原始位置与扩展摘录

本节六篇工作构成第三、四节的直接证据集合。它们并不都覆盖完整的“写入—管理—读取”链条：本文的纳入标准是其主要机制直接作用于已存外部记忆的保留、衰减、抑制、压缩或由此驱动的读时访问。

### R13. Oblivion (2026)

- **Primary source:** [arXiv:2604.00131](https://arxiv.org/abs/2604.00131), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “Memory-augmented LLM agents rely on ‘always-on’ retrieval and ‘flat’ memory storage, causing high interference and latency as histories grow. We introduce Oblivion, a memory control framework that casts forgetting as decay-driven reductions in accessibility, not explicit deletion.”
- **Core research question (verbatim, Abstract):** “How [can] selective forgetting” avoid “redundant always-on access” while preserving useful memory?
- **Core conclusion (verbatim, Abstract):** “Oblivion dynamically adapts memory access and reinforcement, balancing learning and forgetting under shifting contexts.”
- **Core-scope classification (editorial):** 核心语料；直接覆盖存量激活衰减与读时访问控制的联动。
- **Review linkage (editorial):** A direct counterexample to the claim that forgetting is only time/frequency decay. It does not provide an intervention-based conditional action-value estimator. **Boundary: B; Gap 1/2/4.**

### R14. HippoRAG (2024)

- **Primary source:** [arXiv:2405.14831](https://arxiv.org/abs/2405.14831), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “LLMs, even with retrieval-augmented generation (RAG), still struggle to efficiently and effectively integrate a large amount of new experiences after pre-training. … HippoRAG synergistically orchestrates LLMs, knowledge graphs, and the Personalized PageRank algorithm.”
- **Core research question (verbatim, Abstract):** “How [can we] enable deeper and more efficient knowledge integration over new experiences?”
- **Core conclusion (verbatim, Abstract):** “HippoRAG… outperforms the state-of-the-art methods remarkably, by up to 20%.”
- **Review linkage (editorial):** A graph-based new-experience integration and retrieval baseline, not a persistent write/delete/version governance mechanism. **Boundary: B; Q2/Q3.**

### R15. Retrieval vs. Utilization Diagnosis (2026)

- **Primary source:** [arXiv:2603.02473](https://arxiv.org/abs/2603.02473), Abstract; §1; §7 *Limitations*.
- **Abstract excerpt (verbatim):** “We introduce a diagnostic framework that analyzes how performance differences manifest across write strategies, retrieval methods, and memory utilization behavior… On LoCoMo, retrieval method is the dominant factor.”
- **Core research question (verbatim, Abstract):** “The relative importance of how memories are written versus how they are retrieved remains unclear.”
- **Core conclusion (verbatim, Abstract):** “Under current retrieval practices, improving retrieval quality yields larger gains than increasing write-time sophistication.”
- **Review linkage (editorial):** The direct Q3 diagnostic baseline. Its authors limit the evidence to one model, LoCoMo, fixed k=5, and prompt-level write implementations; it does not follow actions or forgetting consequences. **Boundary: A/B; Q3.**

### R16. FadeMem (2026)

- **Primary source:** [arXiv:2601.18642](https://arxiv.org/abs/2601.18642), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “FadeMem implements differential decay rates across a dual-layer memory hierarchy, where retention is governed by adaptive exponential decay functions modulated by semantic relevance, access frequency, and temporal patterns.”
- **Core research question (verbatim, Abstract):** “Current AI systems employ binary retention strategies that preserve everything or lose it entirely.”
- **Core conclusion (verbatim, Abstract):** “Experiments… demonstrate superior multi-hop reasoning and retrieval with 45% storage reduction.”
- **Core-scope classification (editorial):** 核心语料；主要覆盖存量记忆的差异化衰减、冲突抑制与融合，读时影响主要经由层级和强度间接实现。
- **Review linkage (editorial):** Another direct counterexample to a time/frequency-only characterization. Its decay signals are not a counterfactual estimator of action utility under non-stationarity. **Boundary: B; Gap 1/2/3/4.**

### R17. When to Forget / Memory Worth (2026)

- **Primary source:** [arXiv:2604.12007](https://arxiv.org/abs/2604.12007), Abstract; §1 *Introduction*.
- **Abstract excerpt (verbatim):** “Memory Worth (MW): a two-counter per-memory signal that tracks how often a memory co-occurs with successful versus failed outcomes… MW converges… to the conditional success probability… under a stationary retrieval regime with a minimum exploration condition.”
- **Core research question (verbatim, Abstract):** “How [should an agent decide] which memories to trust, suppress, or deprecate as the agent’s task distribution shifts?”
- **Core conclusion (verbatim, Abstract):** “Importantly, p+(m) is an associational quantity, not a causal one: it measures outcome co-occurrence rather than causal contribution.”
- **Core-scope classification (editorial):** 核心语料；主要覆盖基于结果反馈的存量记忆信任、抑制和弃用决策。
- **Review linkage (editorial):** The most direct primary-source motivation for Gap 1 and Gap 3: any extension must improve on association under stationary retrieval without discarding MW’s operational strengths. **Boundary: A.**

### R18. DeMem (2026)

- **Primary source:** [arXiv:2605.10870](https://arxiv.org/abs/2605.10870), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “We cast this as a decision-centric rate-distortion problem, measuring memory quality by the loss in achievable decision quality induced by compression. This yields an exact forgetting boundary for what can be safely forgotten.”
- **Core research question (verbatim, Abstract):** “Memory is valuable not because it faithfully describes the past, but because it preserves the distinctions between histories that must remain separated under a fixed budget to support good decisions.”
- **Core conclusion (verbatim, Abstract):** “DeMem yields consistent gains under the same runtime budget, supporting the principle that memory should preserve the distinctions that matter for decisions, not descriptions.”
- **Core-scope classification (editorial):** 核心语料；主要覆盖以决策充分性限定存量压缩与遗忘边界，读时作用体现为保持任务相关区分。
- **Review linkage (editorial):** A decisive baseline for decision sufficiency. Gap 1 cannot be framed merely as ‘decision-centric memory’; the remaining question is conditional action attribution, task drift, and read-time exclusion of inapplicable evidence. **Boundary: B; Gap 1/2/3/4.**

## E. Benchmarks, diagnosis, and surveys

### R19. LoCoMo (2024)

- **Primary source:** [ACL Anthology](https://aclanthology.org/2024.acl-long.747/), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “We collect LoCoMo, a dataset of very long-term conversations, each encompassing 600 turns and 16K tokens on avg., over up to 32 sessions. Based on LoCoMo, we present a comprehensive evaluation benchmark to measure long-term memory in models, encompassing question answering, event summarization, and multi-modal dialogue generation tasks.”
- **Core research question (verbatim, Abstract):** “Despite advancements in long-context large language models (LLMs) and retrieval augmented generation (RAG) techniques, their efficacy in very long-term dialogues remains unexplored.”
- **Core conclusion (verbatim, Abstract):** “LLMs exhibit challenges in understanding lengthy conversations and comprehending long-range temporal and causal dynamics within dialogues.”
- **Review linkage (editorial):** A key downstream long-horizon stress test, but it cannot isolate whether a failure was caused by writing, retrieval, adoption, generation, or execution. **Boundary: B; Q3.**

### R20. LongMemEval (2024)

- **Primary source:** [arXiv:2410.10813](https://arxiv.org/abs/2410.10813), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “We introduce LongMemEval, a comprehensive benchmark designed to evaluate five core long-term memory abilities of chat assistants: information extraction, multi-session reasoning, temporal reasoning, knowledge updates, and abstention.”
- **Core research question (verbatim, Abstract):** “Their long-term memory capabilities in sustained interactions remain underexplored.”
- **Core conclusion (verbatim, Abstract):** “Our study provides valuable resources and guidance for advancing the long-term memory capabilities of LLM-based chat assistants.”
- **Review linkage (editorial):** Covers time and knowledge updates at the result level. It does not annotate the causal contribution of individual lifecycle operations. **Boundary: B; Q3.**

### R21. MemBench (2025)

- **Primary source:** [arXiv:2506.21605](https://arxiv.org/abs/2506.21605), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “Our dataset incorporates factual memory and reflective memory as different levels, and proposes participation and observation as various interactive scenarios. … MemBench [evaluates] the memory capability of LLM-based agents from multiple aspects, including their effectiveness, efficiency, and capacity.”
- **Core research question (verbatim, Abstract):** “Evaluating their memory capabilities still remains challenges. Previous evaluations are commonly limited by the diversity of memory levels and interactive scenarios.”
- **Core conclusion (verbatim, Abstract):** “We construct a more comprehensive dataset and benchmark to evaluate the memory capability of LLM-based agents.”
- **Review linkage (editorial):** Demonstrates that comprehensive result metrics already exist; Q3 should be defined as lifecycle-process observability, not the absence of evaluation. **Boundary: B; Q3.**

### R22. MemoryAgentBench (2025)

- **Primary source:** [arXiv:2507.05257](https://arxiv.org/abs/2507.05257), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “We identify four core competencies essential for memory agents: accurate retrieval, test-time learning, long-range understanding, and selective forgetting. … [The] benchmark transforms existing long-context datasets and incorporates newly constructed datasets into a multi-turn format.”
- **Core research question (verbatim, Abstract):** “Memory… encompassing how agents memorize, update, and retrieve long-term information—is under-evaluated due to the lack of benchmarks.”
- **Core conclusion (verbatim, Abstract):** “Current methods fall short of mastering all four competencies.”
- **Review linkage (editorial):** Selective forgetting is already benchmarked. A remaining Q3/Q4 contribution requires operation-level attribution and parametric-versus-external controls. **Boundary: B; Q3/Q4.**

### R23. Agent Memory Survey (2025)

- **Primary source:** [ACM DOI](https://doi.org/10.1145/3748302), Abstract and taxonomy sections.
- **Abstract excerpt (verbatim):** “While previous studies have proposed many promising memory mechanisms, they are scattered in different papers, and there lacks a systematical review to summarize and compare these works from a holistic perspective.”
- **Core research question (verbatim, Abstract):** “What is [memory] and why do we need [it] in LLM-based agents,” and “how to design and evaluate the memory module”?
- **Core conclusion (verbatim, Abstract):** “We analyze the limitations of existing work and show important future directions.”
- **Review linkage (editorial):** A source for taxonomy and scope, not evidence that a particular algorithm works or that any proposed gap is empirically established. **Boundary: B (document type).**

### R24. Memory Representations and Operations Survey (2025)

- **Primary source:** [arXiv:2505.00675](https://arxiv.org/abs/2505.00675), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “This work categorizes memory into parametric (implicit in model weights) and contextual (explicit external data, structured/unstructured) forms, and defines six core operations: Consolidation, Updating, Indexing, Forgetting, Retrieval, and Condensation.”
- **Core research question (verbatim, Abstract):** “Existing surveys emphasize application-level use… while overlooking the atomic operations governing memory dynamics.”
- **Core conclusion (verbatim, Abstract):** “The taxonomy provides a structured view of memory-related research, benchmarks, and tools.”
- **Review linkage (editorial):** Directly supports the conceptual distinction behind Q4, but does not measure parametric/external redundancy or temporal leakage. **Boundary: B (document type); Q4.**

## F. Recent direct competitors: composition, heterogeneous memory, and reasoning-aligned retrieval

### R28. FraCom (2025)

- **Primary source:** [ACL Anthology](https://aclanthology.org/2025.emnlp-main.1069/), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “Summarizing useful information from historical conversations has achieved remarkable performance, which, however, may introduce irrelevant or redundant information… We propose a Fragment-then-Compose framework… [that] represent[s] the conversation history as a series of predicates plus arguments.”
- **Core research question (verbatim, Abstract):** “How [can a system] flexibly choose and integrate key information from different sessions during memory retrieval?”
- **Core conclusion (verbatim, Abstract):** “Experimental results on four long-term open-domain conversation datasets demonstrate the effectiveness of our FraCom in memory utilization.”
- **Review linkage (editorial):** A strong cross-session composition baseline. It does not specify revocable versions, provenance, or the action consequence of a composed proposition. **Boundary: B; Q2/Q3.**

### R30. MIRIX (2025)

- **Primary source:** [arXiv:2507.07957](https://arxiv.org/abs/2507.07957), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “MIRIX consists of six distinct, carefully structured memory types: Core, Episodic, Semantic, Procedural, Resource Memory, and Knowledge Vault, coupled with a multi-agent framework that dynamically controls and coordinates updates and retrieval.”
- **Core research question (verbatim, Abstract):** “Most [existing solutions] rely on flat, narrowly scoped memory components, constraining their ability to personalize, abstract, and reliably recall user-specific information over time.”
- **Core conclusion (verbatim, Abstract):** “MIRIX sets a new performance standard for memory-augmented LLM agents.”
- **Review linkage (editorial):** Explicitly invalidates a claim that heterogeneous memory types do not exist. Q2 must instead concern common version, scope, and conflict semantics across those types. **Boundary: B; Q2.**

### R31. HingeMem (2026)

- **Primary source:** [arXiv:2604.06845](https://arxiv.org/abs/2604.06845), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “Existing methods rely on continuous summarization or OpenIE-based graph construction paired with fixed Top-k retrieval… HingeMem… build[s] an interpretable indexing interface via boundary-triggered hyperedges over four elements: person, time, location, and topic.”
- **Core research question (verbatim, Abstract):** “How [can memory] enable robust and efficient retrieval under diverse information needs?”
- **Core conclusion (verbatim, Abstract):** “HingeMem achieves approximately 20% relative improvement over strong baselines… while reducing computational cost.”
- **Review linkage (editorial):** A direct adaptive-retrieval baseline. Q3 cannot be framed as a fixed-top-k problem; it must trace retrieval choice through adoption and action. **Boundary: B; Q3.**

### R32. MemSearch-o1 (2026)

- **Primary source:** [ACL Anthology](https://aclanthology.org/2026.acl-long.41/), Abstract and §1 *Introduction*.
- **Abstract excerpt (verbatim):** “The iterative think–search loop accumulates long system memories, leading to memory dilution problem. … MemSearch-o1 dynamically grows fine-grained memory fragments from memory seed tokens from the queries, then retraces and deeply refines the memory via a contribution function.”
- **Core research question (verbatim, Abstract):** “How [can memory management] capture fine-grained semantic relations between queries and documents” without losing “substantial information”?
- **Core conclusion (verbatim, Abstract):** “MemSearch-o1 substantially mitigates memory dilution, and more effectively activates the reasoning potential of diverse LLMs.”
- **Review linkage (editorial):** A reasoning-aligned growth/retracing baseline. It is not a solution to long-lived external-memory versions, revocation, or non-stationary action value. **Boundary: B; Q1/Q2/Q3.**

## H. 相邻领域：Machine Unlearning 与参数化遗忘

### R44. Machine Unlearning / SISA (2021)

- **Primary source:** [arXiv:1912.03817](https://arxiv.org/abs/1912.03817), Abstract; published in IEEE Symposium on Security and Privacy 2021.
- **Abstract excerpt (verbatim):** “We introduce SISA training, a framework that expedites the unlearning process by strategically limiting the influence of a data point in the training procedure.”
- **Core research question (editorial):** 如何在用户要求撤回训练数据后，以低于从头重训练的成本消除其对已训练模型的影响？
- **Core conclusion (verbatim, Abstract):** “SISA training reduces the computational overhead associated with unlearning.”
- **Review linkage (editorial):** 该工作治理的是训练样本对模型参数化行为的影响，而非可寻址外部记忆条目的默认访问状态。它用于界定外部记忆生命周期治理与 Machine Unlearning 的对象和验证边界。**Boundary: C (adjacent field).**

### R45. Who's Harry Potter? Approximate Unlearning in LLMs (2023)

- **Primary source:** [arXiv:2310.02238](https://arxiv.org/abs/2310.02238), Abstract.
- **Abstract excerpt (verbatim):** “We propose a novel technique for unlearning a subset of the training data from a LLM, without having to retrain it from scratch.”
- **Core research question (verbatim, Abstract):** How can a subset of LLM training data be unlearned “without having to retrain it from scratch”?
- **Core conclusion (verbatim, Abstract):** The method “effectively erase[s] the model's ability to generate or recall Harry Potter-related content,” while common benchmark performance is reported as largely retained in the stated experiment.
- **Review linkage (editorial):** 该工作通过微调改变模型参数化行为；它不删除 Agent 的外部数据库、向量索引或缓存。因而，参数化近似遗忘与外部记忆的降权、归档、弃用或受控删除应分别声明作用域和完成条件。**Boundary: C (adjacent field; task-specific approximate unlearning).**

## 文献使用原则

1. 编辑性说明不应作为原作者主张引用；正式论述应引用其前的原文摘录及对应来源。
2. 行动边际价值研究应以 Memory Worth 和 DeMem 为直接比较对象，并区分结果共现、决策充分性与干预式价值估计。
3. 异构记忆研究应将 MIRIX、TrustMem、Infini Memory 及组织/更新类方法纳入比较；可检验对象为版本、作用域与冲突语义，而非异构类型是否存在。
4. 过程可观测评测应在 LoCoMo、LongMemEval、MemBench、MemoryAgentBench 和 R15 的基础上，将生命周期操作与行动结果联合记录。
5. 参数化知识与外部记忆的研究应区别于既有参数化/非参数化和自适应检索工作；Talkie 等时间截断模型仅可作为相邻的方法学控制。
