# 记忆效用治理

记忆效用治理指把写入、保留、巩固、更新、检索、压缩、归档、隔离和删除统一为一个生命周期管理问题。

## 核心思想

记忆不是静态记录，而是有成本、有风险、有时效、有贡献的认知资产。系统需要持续判断每条记忆是否仍值得影响未来决策。

## 与写入和遗忘的关系

写入和遗忘不是两条独立管线，而是同一个问题的两个时间切面：

- 写入：在信息产生时，预测它未来是否可能有用。
- 遗忘：在信息被使用或长期未使用后，复盘它是否真的产生价值。

## 可能评估维度

- 任务贡献：是否提高成功率。
- 检索贡献：是否经常被有效召回。
- 失败关联：是否经常诱导错误行动。
- 维护成本：是否占用过多存储、检索和上下文预算。
- 冲突程度：是否与新事实或新经验矛盾。
- 时效性：是否仍适用于当前环境。
- 安全风险：是否包含隐私、敏感或恶意内容。
- 认知时间一致性：是否包含当前任务时间点不应知道的信息。

## 操作集合

记忆治理不应只有“保留/删除”二元操作，而应包括：

- 写入。
- 保留。
- 巩固。
- 降权。
- 替换。
- 摘要。
- 合并。
- 归档。
- 隔离。
- 删除。
