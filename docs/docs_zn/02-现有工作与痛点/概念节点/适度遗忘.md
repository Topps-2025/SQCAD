# 适度遗忘

适度遗忘指 Agent 既不过度保留，也不过度删除，而是在任务效用、学习能力、成本、隐私和安全之间取得动态平衡。

## 两种失败模式

忘得太少会导致：

- 记忆库持续膨胀。
- 检索成本上升。
- 冗余和过时信息污染上下文。
- 隐私和安全风险积累。
- 旧经验阻碍新环境适应。

忘得太多会导致：

- 跨会话连续性下降。
- 用户偏好和任务背景丢失。
- 失败经验无法积累。
- 长期学习能力受损。
- Agent 行为变得短视。

## 为什么难以评估

传统指标更容易衡量“是否记住”或“是否删除”，但适度遗忘要求系统在时间轨迹中维持合理状态。它不是单次问答准确率问题，而是长期状态管理问题。

## 可能评估维度

- 关键经验保留率。
- 过时信息抑制率。
- 检索成本变化。
- 任务成功率变化。
- 隐私删除成功率。
- 冲突记忆处理质量。
- 长期学习与泛化能力。
