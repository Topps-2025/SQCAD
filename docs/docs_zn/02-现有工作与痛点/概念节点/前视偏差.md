# 前视偏差

前视偏差指模型、系统或评估流程在某个历史认知时间点上使用了当时本不应可得的未来信息。

## 在大模型中的表现

大模型训练数据通常覆盖大量历史材料。如果模型训练于 2024 年，它可能已经在训练中见过 2023 年发生的事件和结果。当我们要求它站在 2023 年初预测 2023 年市场走势时，模型可能不是在基于当时可得信息推理，而是在复现训练中见过的未来答案。

例如，模型可能知道“2023 年英伟达股价暴涨 190%”。如果在回测中让它预测 2023 年英伟达走势，它的表现可能来自参数化记忆，而不是真实预测能力。

## 为什么重要

在金融预测、政策推演、科学发现和历史回测中，前视偏差会让系统看起来表现极好，但这种表现无法迁移到真实未来。它会把“已经见过答案”伪装成“推理能力”。

## 与 Agent Memory 的关系

前视偏差把遗忘问题扩展到模型参数层面。外部记忆可以删除或降权，但模型权重中的未来知识难以被精确移除。这会制造一种无法通过普通上下文管理主动遗忘的顽固记忆。

## 对评估的影响

如果不控制前视偏差，Agent 的历史回测可能无法区分两种能力：

- 基于当时可得信息进行真实推理。
- 直接调用训练数据中见过的未来结果。

因此，可信 Agent Memory 评估需要显式设置认知时间点，区分“模型实际知道什么”和“Agent 在该时间点应该被允许知道什么”。
