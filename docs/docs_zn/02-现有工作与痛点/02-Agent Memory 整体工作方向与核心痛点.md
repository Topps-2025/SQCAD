# Agent Memory 整体工作方向：外部状态的构建、访问与治理

## 0. 研究范围与概念边界

Agent Memory 研究如何将交互历史、环境观察、外部证据、用户偏好与任务经验转化为可跨当前推理步骤保存、并能够在后续任务中被选择性调用的状态。该领域的研究对象既包括工作上下文、外部持久化存储与程序经验，也涉及模型参数所承载的隐式知识；本文聚焦其中**外显、可追溯且可实施操作的外部记忆**。该限定使记忆单元的来源、时间、作用域、版本和删除状态能够被显式记录，并为后续的更新、审计与撤回提供操作基础 [R23][R24]。

现有综述通常以 **memory operations** 或 **memory management** 概括记忆的持续维护，而非为“生命周期管理”规定唯一、封闭的术语体系。以 R24 为例，其将记忆动态分解为 consolidation、updating、indexing、forgetting、retrieval 与 condensation 六类操作 [R24]。本文据此将 Agent Memory 的研究划分为相互关联但分析上可区分的工作方向：**写入与抽取**解决什么信息进入外部记忆；**表示、组织与类型化**解决记忆以何种结构和粒度保存；**更新、巩固与版本**解决内容如何演化；**检索与访问控制**解决何时、何处和以何种深度读取；**利用与行动**检验记忆是否改变计划或工具执行；**生命周期治理**则在广义上指这些操作的组织与协调。

为避免范围泛化，第三、四节采用其**窄义定义**：仅研究已写入外显记忆的维护与状态退出，即降权、压缩、归档、逻辑弃用、受控删除与恢复。写入、通用更新和检索算法并非该窄义问题的直接优化对象，而是提供元数据或构成行动层验证条件。此处的选择性遗忘也不等同于 Machine Unlearning：前者改变外部记忆单元及其派生索引的访问或存续状态；后者旨在消除训练样本对模型参数化行为的影响，并通常以重训练等价性、遗忘有效性和保留效用作为验证目标 [R44][R45]。

## 1. Agent Memory 的层次与功能分工

Agent Memory 不应被简化为单一向量索引。不同载体和记忆类型承担不同的时间尺度与系统功能，因而对应不同的操作语义。

| 层次或类型 | 典型内容 | 主要功能 | 代表性工作 | 关键约束 |
| --- | --- | --- | --- | --- |
| 工作记忆/上下文 | 当前观察、子目标、中间结论。 | 支撑当前推理与短程行动。 | MemGPT、HiAgent [R1][R3]。 | 受上下文预算严格约束。 |
| 情景记忆 | 事件、对话片段、行动轨迹、失败案例。 | 保存事件顺序、原始证据与反思材料。 | Generative Agents、MemoryBank、LoCoMo [R2][R4][R19]。 | 应保留时间与来源，以支持追溯。 |
| 语义/事实记忆 | 实体关系、稳定事实、用户偏好和摘要。 | 支撑跨会话、跨任务的知识复用。 | Mem0、A-MEM、Zep [R6][R7][R10]。 | 易受时效、条件冲突与错误覆盖影响。 |
| 程序/技能记忆 | 工具策略、成功模式、失败触发和可执行技能。 | 改善“如何行动”，而非仅改善“知道什么”。 | Voyager、ReMe、MEM1 [R12][R27][R42]。 | 需检验迁移边界与版本分叉。 |
| 资源与共享知识 | 文档、外部工具结果、知识库与共享工件。 | 提供可引用、可授权的外部证据。 | MIRIX、EverOS [R30][R43]。 | 需满足来源、权限和时间可得性约束。 |
| 参数化知识 | 预训练参数中压缩的模式与通识。 | 提供语言能力、默认先验与通用推理。 | 参数—非参数记忆比较 [R35]。 | 难以逐条溯源、更新或删除。 |

上述类型并非要求每个系统均采用固定模块划分，而是说明：事实替代、偏好分段、情景归档和技能分叉不能由同一文本覆盖规则处理。类型化是后续更新、检索与生命周期治理具有语义基础的前提，而非可有可无的工程标签。

## 2. 工作方向、拟缓解的技术问题、具体算法机制与未覆盖问题

为保证不同路线之间的比较具有可解释性，以下各方向均按照四个分析维度展开：**研究对象**界定该方向直接操作的记忆状态或过程；**拟缓解的技术问题**说明其在长期 Agent 中所针对的失效模式；**具体算法机制**概括文献中已经实现的操作、表示或决策规则；**未覆盖问题**则限定现有机制尚不能充分支持的语义条件、因果归因或评测要求。该组织方式用于区分相邻模块的职责边界，而不将任一模块的局部改进直接推断为端到端行动能力的提升。

### 2.1 写入与抽取：决定长期状态的候选边界

写入与抽取研究哪些交互内容应被转化为外部记忆，以及应以事件、事实、规则、偏好或经验的何种粒度保存。若将原始轨迹无差别写入，记忆库会迅速积累冗余、噪声与相互矛盾的片段；若写入过于保守，则低频但行动关键的约束可能在后续任务到来前丢失。Mem0 将交互转化为可执行 CRUD 的事实单元 [R6]，PREMem 在写入前抽取事实、经验、主观信息及其跨会话关系 [R29]，SAGE 则以新颖性门控在 ADD、NOOP 与合并之间进行选择 [R11]。

该方向的核心限制在于：可抽取性、新颖性和语义差异均是候选信号，而非未来行动价值的充分证据。写入算法需要与后续检索、更新和行动评测共同考察，不能仅以条目数量或写入 token 判断优劣。

### 2.2 表示、组织与类型化：建立可组合的记忆结构

表示与组织研究记忆是以原始片段、关联笔记、命题图、时间知识图谱、主题文档还是层级状态保存。该方向旨在缓解原始对话难以组合、多跳访问和局部修订的困难。A-MEM 以带上下文、关键词、标签和链接的笔记维护关联 [R7]；FraCom 以命题及共享论元构造可组合片段 [R28]；Zep 使用时间知识图谱表达关系与时序 [R10]；Infini Memory 以可维护主题文档组织长期证据 [R34]。MemoryOS、MIRIX 和 EverOS 则从分层、多类型或用户/Agent 分轨展示了结构化记忆的系统实现 [R5][R30][R43]。

结构化表示可改善组合、检索和人工审查，但其本身不足以保证内容真实性、来源合法性或跨类型转移的正确性。尤其在将情景记录提炼为稳定事实、或将反思转化为程序规则时，表示转换应保留适用条件和证据指针。

### 2.3 更新、巩固与版本：维持内容的时效与可追溯性

更新与巩固研究新证据如何修订、补充或重组既有记忆。Mem0 以添加、更新、删除和合并操作维护事实 [R6]；A-MEM 允许新节点推动旧节点演化 [R7]；MemoryOS 与 RMM 分别通过层级和多粒度反思处理不同时间尺度的状态 [R5][R9]；TrustMem 通过 coverage、preservation 与 faithfulness 验证巩固转移 [R33]；Infini Memory 以主题文档持续修订事实 [R34]。

该方向的核心技术问题不在于是否执行更新，而在于如何避免更新退化为无条件覆盖。事实可能需要替代或证据并存，偏好通常需要主体—场景—时间分段，技能可能需要分叉与验证。现有机制已推动内容维护的发展，但跨类型、跨作用域的版本语义仍缺少统一且可检验的定义。

### 2.4 检索与访问控制：在正确条件下读取正确证据

检索与访问控制研究何时读取记忆、读取哪些内容，以及如何在固定预算下控制检索深度与范围。HippoRAG 通过图结构支持多跳访问 [R14]；Oblivion 以不确定性和缓冲区充分度控制读路径 [R13]；HingeMem 基于人物、时间、地点和主题边界自适应选择检索内容与深度 [R31]；MemSearch-o1 在 Agentic Search 中细粒度扩展并回溯记忆路径 [R32]。EverOS 的作用域分区和派生索引则提供工程层面的访问隔离实例 [R43]。

检索命中不等于模型采纳，更不等于行动正确。Yuan 等的交叉诊断表明，在其 LoCoMo 设置中，检索策略差异对性能的影响大于写入策略差异 [R15]。因此，任何将记忆治理、写入或组织机制与任务性能关联的结论，均应控制检索器与上下文预算。

### 2.5 记忆利用与行动：从信息可见到决策增益

记忆利用研究被检索内容是否进入推理、改变计划、影响工具调用并最终改善任务结果。Reflexion 将任务反馈转为情景记忆，以支持后续尝试 [R41]；Voyager 的技能库使可执行程序得以跨任务复用 [R42]；ReMe 依据成功模式、失败触发和验证后的效用精炼程序经验 [R12]；MEM1 则联合学习状态巩固与推理 [R27]。这些工作说明，记忆系统的价值不能仅由存储容量或检索相似度衡量。

该方向的主要难点是分离写入缺失、检索失败、未采纳、推理错误和工具执行失败。最终 QA 或任务成功率通常不足以完成此类归因，因而需要记录候选记忆、检索结果、提示暴露、采纳情况、计划变化和行动结果之间的过程链条。

### 2.6 生命周期治理与选择性遗忘：已存外显记忆的维护与状态退出

广义的生命周期管理可覆盖写入、巩固、更新、索引、检索与遗忘等持续操作 [R24]；本研究所讨论的窄义治理仅面向**已进入外部记忆库的单元**，考察如何通过状态维护降低过时访问、冗余存储和治理风险。其直接动作包括访问降权、语义压缩、归档、逻辑弃用、受控删除和恢复；选择性遗忘是其中改变默认可访问性、表示粒度或存续状态的动作集合，而非整个 Agent Memory 管线。FadeMem 通过相关性、访问频率和时间模式实施差异化衰减 [R16]；DeMem 以决策率失真界定可安全压缩或遗忘的边界 [R18]；Memory Worth 利用成功/失败共现更新信任或抑制信号 [R17]；EverOS 以 `deprecated_by` 表示合并后的逻辑弃用关系 [R43]。

该窄义治理的核心技术问题是：全量保留会扩大检索干扰与维护成本，直接删除又可能破坏低频关键条件、历史解释和恢复能力。其动作选择依赖时间、来源、类型、版本、作用域及资源约束，并可将检索暴露、采纳与行动反馈用作评价证据。本文后续进一步将讨论范围收窄至“存量管理—读时过滤”的选择性遗忘机制；相应核心论文、触发信号与未覆盖问题见 [[03-Agent Memory 选择性记忆管理：存量管理与读写过滤|第三节]] 与 [[04-Agent Memory 选择性记忆管理的未覆盖问题与研究路径|第四节]]。

### 2.7 评测、可信性与边界控制：检验外部记忆的真实贡献

评测与可信性研究如何验证 Agent Memory 的效果、效率、可追溯性与时间/权限合法性。LoCoMo、LongMemEval、MemBench 与 MemoryAgentBench 分别覆盖长程对话、知识更新、事实/反思记忆、效率/容量与选择性遗忘等维度 [R19][R20][R21][R22]。数据污染研究提示，模型训练数据可能包含测试或未来信息，从而使表面任务得分不能直接归因于外部记忆 [R25]；参数—非参数记忆比较、自适应 RAG 与主动检索研究进一步说明，外部检索的增量价值需与参数化知识和查询难度共同评估 [R35][R36][R37]。

因此，可信评测至少需要控制证据的可得时间、来源与授权范围，并区分模型参数、外部记忆和二者重叠对最终结果的贡献。对于治理方法，还应额外验证压缩、弃用或删除是否确实改变了目标条目的访问状态及其派生副本。

| ------------ | ---------------- | ----------------------- | ---------------------------------------------- | --------------------- |
| 写入与抽取        | 新交互、观察和轨迹。       | 冗余写入、关键条件漏写与抽取噪声。       | 事实抽取、预存储推理与新颖性门控 [R6][R11][R29]。               | 候选信号与未来行动价值之间的差异。     |
| 表示、组织与类型化    | 记忆单元、关系与层级。      | 原始历史难以组合、多跳访问与局部维护。     | 链接笔记、命题片段、时间图谱与主题文档 [R7][R10][R28][R34]。       | 表示转换中的来源、条件与类型语义保持。   |
| 更新、巩固与版本     | 新旧记忆及其派生关系。      | 内容时效衰减、相互矛盾、信息腐化与错误覆盖。  | CRUD、关联演化、层级迁移与转移验证 [R5][R6][R7][R9][R33]。     | 跨类型、跨主体与跨时间的统一版本语义。   |

| 生命周期治理与选择性遗忘 | 已存记忆单元及其当前状态。    | 过时访问、冗余成本、不可恢复退出与删除责任。  | 衰减、决策导向压缩、结果反馈与逻辑弃用 [R16][R17][R18][R43]。      | 条件化保留价值、退出状态语义与删除完整性。 |
| 评测、可信性与边界控制  | 任务轨迹、证据时间线和过程日志。 | 结果归因不清、前视污染以及权限/来源不可审计。 | 长期基准、诊断框架与时间控制 [R15][R19][R20][R21][R22][R25]。 | 生命周期动作与行动后果的联合可观测评测。  |

## 4. 系统依赖与研究定位

上述方向构成一个依赖链，但不应因存在依赖而混同研究对象。写入决定可被治理的候选集合；表示、类型和版本决定治理动作的语义条件；检索与利用决定治理动作能否在行动层被观察；评测与时间控制决定结论能否被可信归因。生命周期治理位于这一链条的维护层：它接收上游的记忆元数据和下游的效用/风险反馈，但其直接输出是已存记忆的状态调整，而非新的记忆写入或通用检索策略。

| 被优化方向 | 局部收益 | 若缺少其他方向配合的风险 | 对生命周期治理的含义 |
| --- | --- | --- | --- |
| 写入门控 | 降低写入成本与冗余。 | 漏写关键证据会使后续治理无从恢复。 | 治理不能补救从未保存的关键原始证据。 |
| 结构化组织 | 改善组合、查询和人工审查。 | 条件或来源缺失会使退出决策失真。 | 降权、弃用和删除需依赖可追溯关系。 |
| 更新与巩固 | 维持时效、减少片段化。 | 错误覆盖会污染所有后续状态。 | 治理应区分失效条目与错误更新结果。 |
| 检索与利用 | 提升当前任务表现。 | 选择偏差会把未检索记忆误判为无用。 | 行动反馈不能脱离访问机会解释。 |
| 生命周期治理 | 降低过时访问、成本和风险。 | 过早退出可能破坏关键行动边界。 | 需以可恢复、可审计的状态转移替代默认删除。 |

## 5. 小结

Agent Memory 是由写入、表示、更新、检索、利用、治理与评测共同构成的外部状态系统。生命周期治理在其中具有明确而有限的位置：它不替代写入、通用更新或检索研究，而是针对已存记忆实施选择性维护与状态退出。其科学问题在于，如何在来源、时间、作用域、版本、行动后果和资源预算共同约束下，决定哪些已存单元应保持活跃、降低访问优先级、压缩、归档、逻辑弃用、删除或恢复。

这一界定将“遗忘”从笼统的记忆缺失或删除操作转化为可审计的治理决策，也为第三节的算法机制综述和第四节的未覆盖问题提供了清晰边界。
