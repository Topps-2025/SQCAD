## 2. 建议会议顺序

### 2.1 研究问题与两个 Gap

- Gap 1：整体轨迹尚未成为带证据定位、可干预、可估计的记忆组件；暴露还由当前检索和治理策略内生生成。
- Gap 2：局部效应尚未与作用域、跨环境稳定性、不确定性、非对称误删风险和可恢复状态动作统一起来。

### 2.2 核心方法

- 解构：从事件证据构造实体、属性、条件、行动、结果、时间、约束和关系候选；
- 抽象：在支持证据和适用作用域约束下构造条件规则候选；
- 因果资格链：proposed → auditable → estimable → governable；
- 治理：强化、保留、降权、归档、隔离、恢复；物理删除由独立合规流程控制。

### 2.3 数据与 baseline

- 主标准集：LongMemEval-S；
- 动态验证集：GoodAI-LTM；
- 外部有效性集：LoCoMo；
- 因果真值层：可控 simulator；
- 当前已完成强控制：BM25、MiniLM dense、dev-tuned BM25+dense RRF；
- 必须统一复现：FadeMem、Oblivion、Memory Worth、DeMem、ReMe 中可获取者。

### 2.4 已有证据与边界

- 表面变换 simulator：高质量解构—抽象可改善 OOD，解构噪声会产生负迁移；
- 自然语言表面变换压力测试：50 seeds 下，高质量联合表示 OOD 0.946±0.007，整体/词法/仅解构均0.667；候选质量下降时规则 precision 和低频关键 recall 明显退化；
- 治理压力测试的逐 seed 审计：相对 item-level causal，联合方法在组噪声0.0/0.1/0.2/0.4时的 utility 胜率为1.00/1.00/0.98/0.46；关键召回胜率仍高，但 stale-retention 从未形成优势，因此不能声称全指标绝对支配；
- 针对上述 bad case 已实现 risk-gated 联合策略：置信度门控 + 跨层效应符号检查 + item-level 负效应 veto；四档噪声下 utility 胜率均为1.00，噪声0.4时 utility=0.815、rare-critical recall=0.690、stale retention=0.007、positive precision=0.896，但仍需真实 Gate A/校准曲线验证。
- 统一 workflow runner：30 seeds、100 steps、固定12项 workspace budget、6个治理策略共享 candidate-stream hash；risk-gated 方法 task success/utility=0.991±0.018，item-level causal=0.891±0.053，所有策略 decision-log completeness=1.0；该结果仅验证工程闭环，不是公开 benchmark。
- 静态因果校准：naive 共现存在明显混杂偏差，调整/DR 可恢复真值；
- 序贯 OPE：在小型有限 horizon 环境中可正确排序策略；
- LongMemEval-S：BM25+dense RRF 是当前最强多证据覆盖控制；词法和 POS 关系 sidecar 尚未形成多指标 Pareto 改进。
