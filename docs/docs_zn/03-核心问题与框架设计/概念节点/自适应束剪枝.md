# 自适应束剪枝

自适应束剪枝是把候选记忆路径的条件化行动价值转化为可实现的早停和生命周期动作。它不是声称自由能天然优于概率搜索，而是一个需要与 DeMem、HingeMem、MemSearch-o1 等近期方法比较的搜索/治理组件。

## 基本流程

1. 在带来源、时间和作用域的记忆图上展开 (K) 条候选路径。
2. 对每条路径估计 (widehat U(P\mid c))，并可加入图复杂度/解释力正则 (F_{graph}(P))。
3. 只有当最优路径与次优路径的价值差超过验证集校准的阈值，且证据时间合法、来源可靠时，才提前终止其他束。
4. 保留最优路径及必要证据；其他路径默认降权或归档，不直接物理删除。
5. 记录候选、检索、引用/采用、行动变化和结果，为边际价值更新提供日志。

## 与传统 Beam Search 的区别

传统 Beam Search 主要按语言概率或任务分数保留候选。本设想加入行动价值、证据合法性、作用域、成本和可恢复性；如果这些因素不能改善行动效用或成本—性能前沿，便不应保留复杂的图剪枝。

## 必须回答的实验问题

- 路径级评分是否优于节点相似度、中心性或固定 top-k？
- 早停是否降低端到端检索/推理成本，而非只减少图节点数？
- 在新异常、冲突证据和主体变化中，是否会因偏好背景一致性而误删反例？
- 被剪枝路径是否可恢复、可审计，并能在后续反馈中重新激活？
