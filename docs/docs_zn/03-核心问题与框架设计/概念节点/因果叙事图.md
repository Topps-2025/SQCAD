# 因果叙事图

因果叙事图是将 Agent 记忆组织为动态图结构的一种设想。节点表示事件、状态、实体、假设或观察，边表示因果关系、逻辑依存、时间演化、类比关系或证据支持关系。

## 为什么用图

单条记忆记录无法表达长期经验中的结构关系。真正有价值的记忆往往不是孤立事实，而是由多个事件和状态构成的因果链。

例如，金融危机类记忆的价值不只是“某年市场下跌”，而是：

杠杆扩张 → 资产泡沫 → 流动性收缩 → 信用传染 → 价格崩塌 → 政策干预。

这种结构更适合用图来表示。

## 遗忘问题的转换

在因果叙事图中，遗忘可以被转换为图稀疏化问题：

> 如何在有限存储和有限计算预算下，保留对未来决策最有结构价值的节点与边？

## 可能实现

- 节点：事件摘要、状态描述、关键实体、宏观变量、任务结果。
- 边：因果、时间、证据、类比、冲突、修正。
- 存储：向量数据库 + 图数据库，或向量索引中的邻接表。
- 更新：新任务完成后写入新节点，并根据反馈更新边权。
- 遗忘：删除、降权、合并或归档低结构价值节点与边。
