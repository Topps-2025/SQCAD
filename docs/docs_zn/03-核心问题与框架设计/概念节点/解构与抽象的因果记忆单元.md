# 解构与抽象的因果记忆单元

## 研究定义

本研究将“解构能力”和“抽象能力”定义为 Agent Memory 中相互连接但不可混同的两个表示操作：

1. **解构（decomposition）**：将原始事件或轨迹证据拆分为实体、属性、成分、条件、行动、结果、约束及其关系，并为每个候选成分保留原始证据定位、时间、作用域与版本。解构解决的是**因果候选的可寻址性**。
2. **抽象（abstraction）**：在多个作用域可对齐、关系模板一致且有独立证据支持的候选成分之间建立更高层的条件规则，同时显式保留适用条件、支持集合和不确定性。抽象解决的是**因果结构的跨情境复用**。

二者均不是因果发现的同义词。解构器或抽象器输出的内容首先是测量结果和待验证假设；只有经干预、反事实回放、条件效应估计和跨环境稳定性检验后，才可将其作为治理依据。这一区分对应因果表征学习关于“表示因素不必然等于真实因果变量”的警示，以及因果模型抽象关于“跨层映射必须保持相关结构性质”的问题 [@Scholkopf2021CausalRepresentation; @BeckersHalpern2019AbstractingCausalModels]。

## 形式化表示

对带来源的事件证据 $E$，解构器输出：

$$
\mathcal D_\phi(E)=(F,R,P,\rho),
$$

其中 $F$ 为候选因子集合，$R$ 为关系集合，$P$ 为证据定位，$\rho$ 为解析版本与置信信息。抽象器输出条件规则候选：

$$
\mathcal A_\psi(F,R,P)=(r,\mathcal S,\Gamma,\nu),
$$

其中 $\mathcal S$ 是来源证据集合，$\Gamma$ 是主体、任务、时间、工具版本、权限等作用域，$\nu$ 是规则版本。治理器实际处理的是组件束 $c=(f\text{ 或 }r,\mathcal S,\Gamma)$，而不是脱离证据的自然语言摘要。

## 与因果遗忘的关系

解构—抽象链路将遗忘问题从“删掉哪段文本”转化为“哪些成分在给定作用域中仍具有可验证的反事实增量”。在保持来源谱系的前提下，治理器可以：

- 保留低频但对关键条件有正向增量的因子；
- 降低与结果偶然共现、但在遮蔽干预下无增量的表面属性权重；
- 将跨情境稳定的因果条件提升为规则，以减少重复暴露成本；
- 在规则失稳、来源撤回或作用域变化时，将规则降级并恢复其来源因子。

“规则已抽象”不等于“来源证据可删除”。规则激活时仍应携带最小充分来源证据或可验证引用，否则无法区分真实抽象收益与无证据的过度理解。

## 最小可证伪标准

该模块只有在以下对照均成立时才可作为论文贡献：

1. 在有潜在结果真值的模拟器中，因子级干预比整体轨迹干预更准确恢复因果条件效应；
2. 在替换名称、描述风格和无关属性而保持机制不变的测试中，规则+证据的样本外效用和作用域校准优于摘要压缩及仅规则条件；
3. 在“同名不同机制”的反例中，抽象器不产生无证据的规则继承；
4. 去掉证据定位、作用域或稳定性门槛后，因果条件覆盖率、错误遗忘或规则校准按预期退化；
5. 公开长期记忆 benchmark 上的增益在固定检索器、模型、token 预算与随机种子下仍然存在。
