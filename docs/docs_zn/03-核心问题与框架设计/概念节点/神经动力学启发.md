# 神经动力学启发

本研究设想可以从神经动力学和脑科学中获得启发，但不应直接声称复现大脑机制。更稳妥的表达是：脑科学提供了若干设计原则，帮助我们理解为什么记忆价值不能只由时间和频率决定。

## 启发一：互补学习系统

互补学习系统理论认为，海马体适合快速编码具体情景，新皮层适合缓慢整合结构化知识。这启发 Agent Memory 区分情景记忆与结构性知识：低频事件未必应被删除，因为它可能在长期巩固中转化为结构模式。

## 启发二：显著性驱动的巩固

脑科学研究表明，情绪唤醒、惊讶、奖惩和风险显著性会影响记忆巩固。罕见但高冲击事件可能被长期保留，不是因为它高频，而是因为它对未来生存和决策具有高价值。

## 启发三：海马回放与经验重组

海马 replay 表明记忆并非被动存档，而会在离线状态中被重新激活、重组和巩固。对应到 Agent，可以把长期记忆维护理解为周期性图重写：高价值路径被强化，低价值细节被压缩或降权。

## 启发四：预测误差与自由能

自由能原则和预测编码强调系统通过降低预测误差来维持稳定认知模型。对应到 Agent Memory，可以把低认知自由能路径理解为：既能解释当前观察，又不会与已有结构产生过高冲突的记忆路径。

## 需要谨慎的边界

这些启发不能直接证明算法正确。它们的作用是提供合理的认知类比和设计原则。真正的学术贡献必须落在可计算指标、可复现实验和可比较基线上。
