# 因果结构价值

因果结构价值指一条记忆在因果叙事结构中对解释、预测、类比和决策的贡献，而不是它被访问的频率或距离当前时间的远近。

## 与统计显著性的区别

统计显著性强调：

- 是否新近。
- 是否高频。
- 是否相似。
- 是否经常被召回。

因果结构价值强调：

- 是否连接关键事件。
- 是否解释当前观察。
- 是否揭示机制链条。
- 是否支持跨时间类比。
- 是否包含高风险决策信号。

## 可能计算维度

- 结构中心性：记忆节点是否连接多个关键因果链。
- 解释覆盖度：该记忆路径能解释当前问题中的多少关键观察。
- 反事实贡献：移除该记忆后推理结果是否明显变差。
- 历史类比强度：该记忆的因果链是否与当前情境同构。
- 风险显著性：是否涉及低概率但高损失事件。

## 研究意义

如果遗忘机制只依赖统计显著性，就会保留大量近期噪音，而删除低频但高因果价值的记忆。因果结构价值试图为遗忘决策提供更接近人类高阶记忆选择的度量。
