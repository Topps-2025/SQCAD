# 时间敏感先验：待验证假设，而非方法前提

LLM 可能在参数中编码不同时期的语言、概念和叙事关联；时间感知语言模型与历时语义研究说明语义表征会随时间变化。但对 Agent Memory 而言，不能预设模型稳定拥有可用的“时代叙事模板”，更不能将该假设当作自由能方法有效的前提。

## 两种相反风险

- 若模型参数确实携带历史模式，它可能帮助生成候选类比；但候选仍需由外部证据、时间合法性和行动结果验证。
- 若模型参数含有查询时点之后的信息，同一先验会成为参数化前视偏差来源，而非可信记忆。

## 工程定位

时间敏感先验最多用于候选路径生成或检索重排，不能作为“记忆价值”的唯一证据。外部记忆应显式记录事件时间、信息可得时间、来源和作用域；在历史任务中，优先依据当时可得证据而非模型关于历史模板的流畅叙述。

## 可检验问题

1. 时间敏感候选是否在严格时间切分下提高证据支持的行动质量？
2. 去除该候选生成器后，条件化价值治理是否仍有效？
3. 时间截断模型与可能含未来知识模型的结论是否一致？

若答案是否定的，本研究不应将“时间线嵌入”保留为方法贡献。
