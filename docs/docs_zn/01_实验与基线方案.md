# SQCAD 实验与基线方案

## 分层实验

- D0：可枚举潜在结果的受控机制世界；
- D1：LongMemEval-S，长期事实、更新时间和检索过程；
- D2：LoCoMo，长程多跳、时间和跨 session；
- D3：GoodAI-LTM，动态 retain/revise/update/recovery；
- D4：MemoryAgentBench，增量交互覆盖复验；
- D5：Gate A，因子、关系、来源、作用域和时间标注审计；
- D6：低风险 expose/mask/delay 微干预，用于资格校准。

## 统一比较合同

所有方法共享 history、candidate stream、reader、prompt、model/tool、retriever、top-k、工作区 token、storage、evaluator、时间切分和随机种子。原论文结果、proxy 和本地复现必须分栏。

## 主指标

future utility、future regret、false-forgetting regret、harmful-retention regret、scope transport error、matched-utility active tokens、qualification calibration。

检索 Recall、NDCG 和 MRR 只说明证据访问过程，不能单独证明记忆治理因果效果。

## 必须的消融

1. scoped qualification vs association-only；
2. scoped vs global qualification；
3. competitive projection vs independent decay；
4. protected focus vs no positive floor；
5. bounded fallback vs default-cold；
6. negative attenuation vs no negative action；
7. mismatch penalty vs no penalty；
8. Evidence–Belief–Access 分离 vs 合并；
9. restore path vs irreversible deletion。

## 作用域过拟合专项

必须比较 seen-scope、unseen-scope、scope/version shift、return-to-old-scope、scope 粒度、scope 标签置换和边界对抗样本。只有未见作用域也改善且不显著增加错误遗忘与规则复杂度，才能称为 scope-conditioned denoising。
