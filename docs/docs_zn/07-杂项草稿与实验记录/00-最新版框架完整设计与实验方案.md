# 最新版最小框架完整设计与实验方案

> **2026-08-08 版本关系：** 本文件继续作为正式 v3 已验证技术基线；当前待验证设计候选已由旧 v4 更新为 **Scope-Qualified Competitive Access Decay（SQCAD）**，完整作业二见上级目录的 `../08-作业二-SQCAD完整方案-20260808.md`。SQCAD 尚无性能实验，不改变本文件的任何正式结论。

> 本文件是 Introduction 之后**已有正式实验支撑的 v3 技术基线**。Introduction 已可定稿，不在这里重写。旧方案中的 group-level hierarchy、PathBundle、BCPS 组探测、task-adaptive budget cap、sentinel correction 和“恢复带来性能增益”等主张已被正式 v3 挑战实验删除或降级。框架不再称为“衰减框架”，而称为 **Qualification-Gated Access Governance（资格门控访问治理）**。基于“相关不等于因果、现在不等于未来、这个不等于那个”重新定锚的候选 v4 见 `04-贝叶斯作用域迁移门控与非对称访问动态设计提案-20260807.md`；v4 在完成预注册实验前不得覆盖本文件中的正式结论。

## 0. 一句话论证、证据和边界

### 0.1 一句话论证

在 Agent Memory 的候选、暴露、采纳和结果由策略与任务条件共同生成时，我们研究什么证据应当获得改变记忆未来可访问性的权限：框架保留不可覆盖的原始证据，将廉价关联信号限制为当前低风险任务的条件访问和审计候选提议，只允许经过有作用域序贯资格门的干预证据驱动非对称、可撤回的访问治理。

### 0.2 当前直接证据

- v2 反例：允许 `unresolved` 后验驱动衰减，在 weak-gap stationary 场景造成 Utility -0.4313 ± 0.0796、FF-regret reduction -0.2908；
- v3 正式结果：资格门控访问治理相对 fixed decay 的 Utility Δ 为 +0.2352 ± 0.0228，FF-regret reduction 为 +0.1165；
- 代价：v3 平均多保留约 32.6% 热索引记忆，risk-weighted harm 略差 0.0060；
- 负结果：当前 causal probe、hierarchy、adaptive cap、sentinel 和 recoverability performance contribution 均未通过独立消融。

### 0.3 论证边界

当前证据只能支持受控机制结论，不能支持：

- 真实 Agent Memory SOTA；
- “因果探测提高了总体性能”；
- “解构或层级结构提高了泛化”；
- “预算优化模块带来独立增益”；
- “比 FadeMem/Oblivion 压缩更多”；
- “首次将因果、访问衰减、结构化记忆或恢复用于 Agent Memory”。

## 1. Research Gap 到设计职责

| Research Gap | 失败机制 | 最小设计职责 | 不需要的额外模块 |
| --- | --- | --- | --- |
| Gap 1：Trajectory-Conditioned Associational Overfitting | exposure、task difficulty、retrieval policy 和 outcome 内生；成功共现被误当可迁移贡献 | 明确原子 treatment；分开 candidate/exposure/adoption/action/outcome；关联只作 fallback；少量付费干预产生资格证据 | 全局因果图、group posterior、复杂 PathBundle、因果抽取标签 |
| Gap 2：Scoped Recoverable Governance | 局部效应直接变成永久保留/删除；证据不足被误写成负证据；错误遗忘代价未单独建模 | scope/version qualification；positive/negative/unresolved；非对称 keep/archive loss；Evidence/Belief/Access 三态分离；可撤回归档 | 统一指数衰减、不可逆删除、由 unresolved 驱动的连续衰减 |

框架必须遵守一句系统契约：

> 结构决定“测试什么”，付费干预决定“什么获得资格”，风险与作用域决定“未来如何访问”；任何派生状态不得覆盖原始证据。

## 2. 术语账本

| 规范术语 | 定义 | 禁止混用 |
| --- | --- | --- |
| Evidence Record | 不可变的原始观察、行动、工具返回、结果与来源元数据 | 不称为 causal memory |
| Source-Linked Treatment Adapter | 把 session/turn/span pointer 暴露为可 mask/replace 的 treatment 接口；默认不需要语义本体 | 不称为 semantic/causal discovery |
| Atomic Treatment Handle | Adapter 输出的可寻址候选单元；是干预对象，不是真实因果变量 | 不称为 discovered causal factor |
| Associational Signal | 在历史曝光轨迹上估计的相关性、频率、成功共现等廉价信号 | 不称为 causal value |
| Scoped Causal Belief | 在明确 task/version/policy scope 下，由已支付干预更新的效应后验 | 不称为全局因果真理 |
| Qualification State | `positive-qualified`、`negative-qualified` 或 `unresolved` | 不用单一 causal score 替代 |
| Access Policy | 决定默认检索、优先级、条件访问、隔离、归档和恢复的派生策略 | 不等于证据是否存在 |
| Qualification-Gated Access Governance | 只有 qualified evidence 能改变持久访问权的治理机制 | 不简称为更强衰减 |
| Selective Scoped Causal Audit | 对少数候选执行付费干预以获得资格证据 | 不宣称当前已提高性能 |

## 3. 问题设定

### 3.1 时序对象

在任务 (t) 到来时：

- (E)：不可变 Evidence Records；
- (M_i)：第 (i) 个 Atomic Treatment Handle；
- (X_t)：干预前任务、主体、时间、模型、工具、版本、风险和预算条件；
- (C_t)：共享候选集合；
- (Z_{it})：候选是否进入工作区的 exposure；
- (A_{it})：Agent 是否实际采纳；
- (Y_t)：行动、工具轨迹、任务效用、风险和成本结果；
- (B_{i,s})：记忆 (i) 在 scope (s) 的效应后验；
- (Q_{i,s}in\{q^+,q^-,?\})：资格状态；
- (a_{i,s}in[0,1])：访问权重。

基本 estimand 不是“检索到该记忆时成功概率”，而是在固定候选、reader、workspace、Agent、工具和评价器条件下，针对可执行干预 (do(Z_{it}=1)) 与 (do(Z_{it}=0)) 的条件结果差异。实际论文必须清楚区分 exposure effect、adoption effect 和长期 policy value；若日志不能识别 adoption，则不得把 exposure effect 写成采纳效应。

### 3.2 识别边界

任何因果结论必须说明：

- treatment 是 expose、mask、delay、pointer replacement 还是 archive；
- scope 包含哪些 task/version/subject/tool/model 条件；
- 干预前混杂变量何时记录；
- positivity/overlap 是否成立；
- 共同暴露记忆如何处理；
- evaluator 是否稳定；
- 资格何时因版本变化、证据冲突或 overlap 下降而撤回。

无法满足这些条件时，状态必须保持 `unresolved`，系统只能使用条件关联 fallback。

## 4. 最小完整框架

框架只有六个方法职责；写入器、向量库、reader、planner 和工具执行器是固定工程底座，不列为创新。

### 4.1 M1：Source-Linked Treatment Adapter

**动机。** 整体轨迹或摘要不是理想 treatment：一次 mask 会同时改变多个事实、约束、行动和结果，无法定位贡献；但自动“因果解构”又可能制造错误语义。

**机制。**

1. Event Journal 先写入不可变 raw event；
2. 核心默认直接使用 session ID、message/turn ID、字符跨度或 whole-episode pointer，不依赖语义本体；
3. 可选语义 sidecar 可以增加 fact/constraint/action/relation 类型，但只能扩展候选键；
4. 每个 handle 必须保存 `source_event_ids`、字符/消息跨度、adapter/sidecar 版本、主体、时间、权限和可撤回状态；
5. handle 只用于检索和干预，不能覆盖 raw evidence，也不能直接授予因果资格。

**必要性。** 没有可寻址 treatment，就无法执行组件级干预和来源回放。其必要性是测量接口，不等于已经证明性能创新。

**公开证据。** LongMemEval-S 重跑显示 full-session BM25 的 Recall-all@5 为 0.8298，简单 turn-max 为 0.8000，factor/rule/relation sidecar 也没有稳定增量。因此 source handle 保留为测量接口，复杂语义解构不进入核心贡献。

### 4.2 M2：Conditional Associational Access

**动机。** 等待每条记忆获得因果资格会使系统成本失控；在平稳、低风险任务中，关联信号可能已经足够有用。

**机制。** 历史频率、成功共现、语义相关性和检索分数只产生：

1. 当前任务 shortlist；
2. 未资格记忆的条件访问值。

对 unresolved 记忆，当前任务的 fallback 为：



V_{\mathrm{assoc}}(i,t)
=(1-r_t)\,[s_{it}\hat a_i-c_i],



其中 (r_t) 是任务风险、(s_{it}) 是可观察 scope/semantic match、(hat a_i) 是关联值、(c_i) 是执行成本。该值不能更新 causal posterior，也不能永久提高/降低访问权。

**资格后的在线规则。**

- `positive-qualified`：允许 full task-conditioned value；
- `negative-qualified`：该 scope 下 veto/隔离；
- `unresolved`：仅使用上述风险折扣 fallback。

### 4.3 M3：Selective Scoped Causal Audit

**动机。** Gap 1 要求打破历史共现，但不允许对所有记忆持续付费干预。

**候选提议。** cheap semantic 与 association 各取前 `ceil(sqrt(N))`，取并集；提议不授予资格。未来真实系统可以替换 proposal，但所有策略比较必须共享候选流。

**可执行干预。**

- expose vs mask；
- immediate vs delayed exposure；
- original pointer vs controlled replacement；
- active vs archived retrieval。

干预必须在行动前登记 propensity、candidate set、workspace position、model/tool version 和 evaluator version。

**唯一预算规则。** 对候选计算 best-alternative-aware qualification EVSI：一次额外 probe 只有在可能改变 qualification 或下游 access action，且期望决策收益高于有价格的干预成本时才执行。不存在第二个 task-adaptive cap。



\text{probe}(i)
\iff
\operatorname{EVSI}_{\mathrm{qual}}(i\mid\text{best alternative})
> c_{\mathrm{probe}}(i,t).



**当前证据边界。** v3 中该 probe 实现净效用为负；因此本模块只能称为“审计与资格证据收集”，不能称为性能增强器。

### 4.4 M4：Sequential Scoped Qualification

**动机。** 后验均值的正负、一次显著结果或 group average 都不应直接获得永久治理权限；重复查看还会产生 optional stopping。

**scope key。** 最低要求为：

`task version × subject/tenant × tool/model configuration × proposal policy version`

数据不足时宁可拆分为 unresolved，也不能无证据跨 scope 池化。

**三态门。** 对 scope 内第 (n) 次有效干预，使用：



\alpha_{n,F}
=\frac{0.05}{|F|}\frac{6}{\pi^2n^2},



其中 (|F|) 为当前 family size。

- 若正向尾概率通过门：`positive-qualified`；
- 若负向尾概率通过门：`negative-qualified`；
- 其余：`unresolved`。

资格必须记录 evidence IDs、估计器、样本量、后验、family、look index、scope 和过期/撤回条件。group posterior 只能影响下一步测谁，不能直接授予 item 资格。

### 4.5 M5：Qualification-Gated Access Governance

**动机。** 因果估计本身不回答记忆如何保留；平均效用也不能表达删除稀有保护性约束的非对称代价。

**风险损失。** 对已经 qualified 的记忆，比较：



L_{\mathrm{keep}}
=s_{it}(1+r_t)\mathbb E[(-\tau_{i,s})^+]+c_i,





L_{\mathrm{archive}}
=\lambda_{\mathrm{FF},t}s_{it}\mathbb E[(\tau_{i,s})^+].



令 (Delta=L_{\mathrm{keep}}-L_{\mathrm{archive}})：

- 若 `unresolved`：持久 (a_{i,s}) 不变；
- 若 qualified 且 (Delta>0)：
  

  a_{i,s}\leftarrow a_{i,s}e^{-\Delta};
  

- 若 qualified 且 (Delta\le0)：
  

  a_{i,s}\leftarrow a_{i,s}+(1-a_{i,s})(1-e^{\Delta}).
  


当访问权低于 archive threshold 时，只从热索引移入冷存储；原始证据仍存活。该算子是 scope-specific、qualification-gated 且可逆的，不是时间衰减。

**动作语义。**

| 状态 | 允许动作 | 禁止动作 |
| --- | --- | --- |
| positive-qualified | protect、keep、提高当前 scope 访问、恢复 | 自动传播到其他 scope |
| negative-qualified | downweight、veto、isolate、archive | 覆盖或物理删除来源证据 |
| unresolved | 当前低风险 conditional access、继续审计 | 改变持久 access weight、永久归档 |

### 4.6 M6：Three-State Separation and Recovery

系统必须分别持久化：

1. **Evidence Survival**：来源是否存在、是否合法、能否审计；
2. **Relation Belief**：效应、方向、不确定性、scope 和版本；
3. **Access Policy**：是否进入默认检索、优先级、条件访问、隔离或归档。

任何 effect update 或 access action 都不得重写 raw evidence。

**恢复规则。**

- 同一 scope/version 已存在 positive-qualified evidence：可直接恢复热索引；
- scope/version 改变或证据过期：必须支付 item-level revalidation；
- 纯语义相似、group evidence 或历史高频不能免费恢复。

恢复目前是安全/审计接口，不列为已证明的性能创新。

## 5. 在线、离线与状态闭环

### 5.1 在线路径

1. 读取当前 `Task Contract`：目标、scope、version、风险、硬约束和成本；
2. 从共享 raw/derived index 生成候选；
3. proposal 使用 cheap signal 缩小候选；
4. Access Projector 读取每个候选的资格和访问状态；
5. positive 使用 full access，negative veto，unresolved 使用 conditional fallback；
6. 固定 reader/planner/tools 执行；
7. 记录 candidate→exposure→adoption→action→outcome；
8. 普通 outcome 只更新 associational statistics。

### 5.2 异步审计路径

1. 从高不确定、高潜在决策影响候选中计算 qualification EVSI；
2. 对 EVSI 高于成本者执行预登记微干预；
3. 仅用已支付干预更新 scoped causal belief；
4. 经过 family-wise 与 time-uniform gate 生成三态资格；
5. governance 依据资格、风险和非对称损失更新 access policy；
6. 新状态只投影到索引，不覆盖 Evidence Journal。

### 5.3 失败安全回退

当 parser、日志、overlap、evaluator 或 scope contract 任一 Gate 不通过时：

- 停止资格升级；
- 保持 `unresolved`；
- 不执行持久衰减；
- 使用 raw retrieval + conservative keep + 当前任务风险折扣；
- 记录缺失原因和下一次需要收集的证据。

## 6. 数据模型与工程接口

### 6.1 最小日志合同

| 表/事件 | 必填字段 |
| --- | --- |
| `evidence_event` | event_id、timestamp、subject、task_id、raw_content_pointer、source、available_at、permissions、hash |
| `treatment_handle` | handle_id、source_event_ids、span、type、constructor_version、scope_hint、rollback_pointer |
| `candidate_event` | task_id、candidate_ids、scores、ranker_version、candidate_stream_hash |
| `exposure_event` | candidate_id、exposed、position、mask/replacement、propensity、decision_time_covariates |
| `adoption_event` | adopted/ignored/unknown、evidence、planner trace pointer |
| `action_event` | plan、tool call、arguments hash、model/tool version |
| `outcome_event` | utility、hard constraint、risk harm、cost、evaluator version |
| `probe_event` | intervention、alternative、cost、randomization/propensity、potential-outcome pair id |
| `belief_state` | scope key、posterior、uncertainty、sample size、evidence IDs、estimator version |
| `qualification_event` | state、alpha、family size、look、scope、valid_from/until、revoke_reason |
| `access_state` | access weight、policy action、risk losses、archive/restore pointer、reason |

### 6.2 原子性与顺序

- candidate set、propensity 和干预必须在 Agent 行动前写入；
- outcome 不能反向修改当期 treatment assignment；
- 每次索引投影必须指向 source state version；
- archive 是索引状态，不是数据删除；
- 合规删除单独处理，不由普通效应分数触发。

## 7. 数据获取与验证路线

### 7.1 D0：受控机制世界（已完成）

用途：提供潜在结果真值、固定 DGP 和严格模块反例。正式文件为 `实验资产/最小框架挑战实验/results/formal_v3.json`。它只能证明机制边界。

### 7.2 D1：可选语义 sidecar Gate A（人工标注未完成）

在 LongMemEval 证据上人工标注：source span、实体/约束/时间/行动/结果类型、可独立 mask 性、scope 和冲突。报告：

- source-span precision/recall；
- atomicity agreement；
- intervention validity；
- evidence coverage；
- parser abstention；
- 不同模型/提示版本稳定性。

最小框架已经默认使用 raw session/turn/span handle，因此 Gate A 不再阻塞核心框架；它只决定能否额外主张 semantic decomposition。若不通过，则永久删除该额外贡献。

### 7.3 D2：公开端到端治理（优先未完成）

推荐最小组合：

- LongMemEval：时间、更新、跨会话和检索失败切片；
- LoCoMo：长程、多跳和外部有效性；
- GoodAI-LTM 或可运行动态协议：在线漂移、过时和恢复。

统一 reader、生成模型、候选 (k)、workspace token、提示、工具、evaluator 和 API price。基准本身没有逐条因果真值，因此只能验证端到端效用、错误遗忘和成本；因果校准仍由受控/半合成干预切片承担。

### 7.4 D3：真实微干预日志（未完成）

在可逆、低风险任务上随机化 expose/mask 或 delayed exposure，逐步验证：

1. propensity 与 candidate-stream 可复现；
2. adoption 可观测或可明确标为 unknown；
3. overlap 和 evaluator 稳定；
4. 估计器在 held-out randomized probes 上校准；
5. OPE 预测与在线 A/B 方向一致。

### 7.5 D4：私有轨迹（可选，不作为当前完成条件）

只有在 D0–D3 通过后才进行跨企业/跨租户验证。必须做权限隔离、去标识化和时间切分，不把私有日志当作公开基准替代品。

## 8. 公平基线

### 8.1 必须运行

1. no-memory / full-context / keep-all；
2. recency、LRU、access frequency、fixed exponential decay；
3. BM25、dense、hybrid/RRF，共享同一 candidate stream；
4. Memory Worth-like success co-occurrence；
5. FadeMem 与 Oblivion（代码和协议可用时按官方实现）；
6. DeMem 或其可复现 decision-centric compression；
7. 本框架的 `association-only`、`audit-only`、`qualification-gate-only` 和 full minimal policy。

### 8.2 功能对照

- CMI：query-time intervention selection；
- MemAudit：post-hoc harmful-memory attribution；
- ActMem：causal-semantic structure；
- Trivium：persistent causal evidence/probing；
- GateMem：access-control/active-forgetting benchmark。

若目标、代码或输出接口不同，应按“局部功能是否被覆盖”比较，不强行合成一个总排名。

### 8.3 公平性锁定

- 同一 raw evidence、候选生成、reader、Agent、工具与 evaluator；
- 同一 workspace/token/time/API 预算；
- 所有策略共享任务、随机种子和可执行干预结果；
- 不修改 DGP、阈值或场景让 full method 获胜；
- 每种方法同时报告官方推荐参数和统一预算下结果；
- 调参只在 validation，最终 test 与 stress worlds 一次冻结运行。

## 9. 消融与反例矩阵

每个候选贡献必须有 remove/replace 单变量对照。

| 被检验职责 | Full | Remove/replace | 失败即裁决 |
| --- | --- | --- | --- |
| 原子 treatment | source-linked atomic span | whole episode / summary | 无识别、稳定性或效用增益则删除解构贡献 |
| 关联边界 | unresolved 仅 conditional fallback | association 直接更新 belief / 完全禁用 association | 若直接升级不伤害，Gap 1 实证支撑不足 |
| 选择性审计 | qualification EVSI probe | no probe / uniform probe / entropy probe | 若不优于 no-probe，审计只保留诊断定位 |
| scope | version/subject/tool scope | global pooling | 若 global 同样校准，scope 复杂度降级 |
| qualification | three-state sequential gate | posterior mean sign / fixed p / no alpha spending | 若无差异，统计门不是必要模块 |
| governance permission | unresolved freezes persistent access | unresolved drives decay（v2） | v2 已显示失败；公开任务仍需复验 |
| 非对称损失 | separate FF/FR cost | symmetric loss | 若无 worst-group/FF 改善，删除非对称贡献 |
| 三态分离 | Evidence/Belief/Access | merged state / overwrite evidence | 以 audit/recovery correctness 验证，不只看 accuracy |
| recovery | archive + revalidation | irreversible delete / free semantic restore | 无性能增益时仍可保留安全接口，但不能列贡献 |

明确不再进入 full method 的消融：hierarchy、adaptive budget cap、sentinel、contextual linear effect、semantic bins、item veto；这些已在 v3 中失败，除非新的独立假设和新预注册实验提供理由，否则不得重新加入。

## 10. 指标、统计与成本

### 10.1 主指标

- task utility 与 regret；
- harmful selection 与 risk-weighted harm；
- false forgetting rate/regret；
- false retention/harm；
- worst-group 与 CVaR；
- active fraction、mean access weight、storage/token/latency；
- probe count/cost、restore count/cost、break-even price；
- qualification precision/coverage/calibration；
- evidence survival、rollback success、decision-log completeness。

### 10.2 报告规范

- paired seeds/worlds；
- 均值、样本标准差、95% CI；
- 命名场景与随机 stress worlds 分开；
- 每个模块报告净效用、零 probe price 效用和 break-even；
- 不只报平均分，必须报 weak-gap、stationary、recurrence、high-cost 和 noisy-construction 切片；
- 若 CI 跨零或仅极少事件触发，写“未获得独立证据”，不写“有效”。

## 11. Go/No-Go

| Gate | Go 条件 | No-Go 后的收缩 |
| --- | --- | --- |
| G0：v3 机制 | 协议 hash、共享世界、测试和结果完整性通过 | 修复实验，不写结论 |
| G1：可选 Semantic Gate A | source/atomicity/intervention validity 达到预注册标准 | 核心继续使用 raw span；删除语义解构贡献 |
| G2：公开 benchmark | 相同预算下对强基线有稳定净效用或 FF-risk 前沿改善 | 定位为机制/治理协议，不宣称性能方法 |
| G3：因果校准 | randomized holdout 上方向、覆盖率和 calibration 通过 | causal state 仅诊断，不改变访问权 |
| G4：scope transport | 跨 version/task 外推优于 global pooling 且不过度拒绝 | 缩小 qualification scope，不宣称迁移 |
| G5：真实成本 | probe 和 revalidation 在 break-even 内 | 减少审计范围或转为离线审计 |

## 12. 论文贡献建议

当前可主张的贡献应收缩为：

1. 将 Agent Memory 生命周期治理形式化为**权限问题**：在策略生成的内生暴露下，何种证据有资格改变未来访问权；
2. 提出 Evidence Survival、Scoped Relation Belief 与 Access Policy 的分离契约，以及 positive/negative/unresolved 的序贯 scope qualification；
3. 提出 qualification-gated、非对称且可撤回的访问治理，并用 v2 失败反例与 v3 模块挑战证明 unresolved evidence 不应驱动衰减；
4. 给出 falsification-first 的评测协议，主动删除未通过消融的 hierarchy、adaptive budget、sentinel 和 recovery performance 主张。

不把 decomposition、causal intervention、EVSI、decay、archive/recovery 或统计 alpha spending 单独写成新算法。这些分别有已有工作或通用方法覆盖；论文可能的新意在于它们被怎样约束成 lifecycle permission contract。
