## 2. 正式 v3 的最终证据裁决

| 模块 | 正式结果 | 当前裁决 |
|---|---:|---|
| Qualification-gated governance | Utility `+0.2352 ± 0.0228`；FF-regret `+0.1165` | 唯一稳定正向模块；保留为正式基线 |
| 热记忆占用 | 平均多保留约 `32.6%` | v3 未实现 active-memory “少即是多” |
| Causal evidence probe | Utility `-0.0138 ± 0.0068`，免费时仍无收益 | 当前实现降级为审计；不主张性能贡献 |
| Hierarchy | Utility `-0.0079 ± 0.0024`，oracle 无明显 headroom | 不恢复语义/group hierarchy |
| Sentinel | Utility `-0.0051 ± 0.0022` | 删除 |
| Adaptive budget cap | 约 0；与 EVSI stop 重复 | 删除 |
| Recovery performance | 约 0，事件稀少 | 仅保留安全/可撤回接口 |

正式结论仍是：

> 未决证据不能获得改变持久访问权的权限；当前实验没有证明更多因果探测、更多层级或更多预算模块带来更好性能。

## 3. 候选 v4 的新增、继承和禁止混写

### 3.1 继承的已验证不变量

- 关联信号只负责候选和低风险 fallback；
- unresolved 不是负证据；
- Evidence、Belief 与 Access 必须分离；
- EVSI 同时承担探测选择与停止，不增加重复预算模块；
- 不恢复复杂语义解构和 group hierarchy。

### 3.2 新增但尚未验证的假设

- scoped future-value posterior 优于单点资格分数；
- transport/robustness gate 能降低跨时间、跨版本负迁移；
- default-cold 能在固定未来效用下减少 active tokens；
- 时间通过后验方差膨胀使资格过期，比均值指数衰减更安全；
- 风险特定的非对称后验损失优于对称访问规则；
- 显式元数据的保守部分池化能改善稀疏 probe，但不造成负迁移。

### 3.3 不得提前写入论文的结论

- “贝叶斯框架已经优于 v3 或现有工作”；
- “已经实现少即是多”；
- “解决了因果识别”；
- “首次提出 Bayesian gate、层级衰减、uncertainty ageing 或 EVSI”；
- “可以跨任务、跨版本稳定泛化”。

## 4. 后续实验的唯一替换规则

候选 v4 只有同时满足以下条件，才能替换 v3 成为论文正式 Method：

1. rolling future split 与 randomized holdout 上后验校准通过；
2. 相对 global pooling、no pooling 和 v3 降低跨版本 future regret；
3. 相对 symmetric loss 改善 harmful-retention / false-forgetting 前沿；
4. 在固定 future utility 或固定 regret 下显著减少 active tokens；
5. full posterior 稳定优于 point estimate，且结果对合理先验不敏感；
6. 至少一个公开 future-split benchmark 与一个微干预切片通过。

任何一项失败，都按 `04` 中的 Go/No-Go 表收缩相应主张或删除模块，不通过调参、修改 DGP 或更换弱基线保留组件。
