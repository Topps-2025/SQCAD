# 已有工作—Research Gap—模块—证据—裁决审计矩阵

> 目的：判断每个候选模块是否真正回应 Research Gap、是否已被前人覆盖、当前证据是否足以保留。  
> 来源等级：A = 同行评议正式论文或作者明确理论陈述；B = arXiv 预印本/未核实正式出版状态；C = 综述、技术系统或相邻领域证据。等级表示可主张范围，不表示工作质量。  
> 边界：CMI、MemAudit、ActMem、Trivium、GateMem 当前本地材料主要是 Introduction 中的摘要级核对；在完成全文、代码和同预算复现前，不写“优于”或“首次”。
> 候选 v4 边界：Bayesian update、hierarchical Bayesian model、uncertainty gate、EVSI 和 non-stationary decision 本身均为通用已有方法；在完成 Bayesian memory gating、Bayesian forgetting、contextual-bandit memory 和 transportability 方向的全文审计前，只能把它们写成统一治理契约的组成部分，不能写成单点创新。

## 1. 两个 Research Gaps

### Gap 1：Trajectory-Conditioned Associational Overfitting

Agent Memory 的候选生成、检索暴露、工作区位置、Agent 采纳和任务结果由同一策略与任务条件共同产生。历史成功共现、访问频率或相关性因此不能自动解释为某条记忆的可迁移行动贡献。剩余问题不是“有没有因果分析”，而是能否在策略生成、随时间变化的暴露下，以可审计的处理单元和干预日志识别有作用域的记忆效应。

### Gap 2：Scoped Recoverable Governance

局部效应估计并不自动给出长期状态动作。任务、主体、时间、工具、模型和版本变化后，系统仍需把效应方向、不确定性、作用域和 false forgetting/false retention 的非对称代价映射为可撤回的访问决策，同时保留来源证据和恢复路径。

## 3. “前人做得更好”的明确领域

1. **真实 benchmark 与压缩证据**：FadeMem、Oblivion 和 DeMem 已报告真实长程数据；本项目当前只有受控机制实验，外部有效性明显更弱。
2. **轻量在线可部署性**：Memory Worth 的双计数器比付费探测简单、便宜、易扩展；在关联足够可靠的平稳环境中，它应当是首选基线。
3. **压缩理论**：DeMem 对固定预算下哪些历史区分必须保留给出更清楚的率失真与遗憾边界；本项目不能用“风险治理”替代这类理论比较。
4. **检索和结构工程**：SimpleMem、HippoRAG、A-MEM、HingeMem、MemSearch-o1 等已有更成熟的结构组织或自适应读取机制；本项目没有证据表明自造 hierarchy 更好。
5. **通用因果估计**：MSM、DR/DML、DR-OPE 和 CRM 已提供比当前模拟后验更成熟的识别与估计理论；本研究的价值只能在 Agent Memory 日志、处理定义和治理接口，而不是重新命名估计器。
6. **局部因果能力**：CMI、MemAudit、ActMem 和 Trivium 已覆盖 query-time intervention、事后归因、因果语义结构或长期 probing 的不同部分；“因果框架人无我有”已经不成立。

## 4. 当前仍可能成立的核心创新

### 4.1 强候选：资格是治理权限，而不是又一个价值分数

多数现有信号直接成为排序、强化、衰减或压缩依据。当前框架把它们拆成两个问题：

1. 证据是否足以让某个有作用域关系获得 positive/negative qualification；
2. 该资格在非对称错误代价下允许什么访问动作。

`unresolved` 不是低分，也不是负证据；它是**没有权限改变持久访问权**。v2/v3 的对照为这一点提供了直接机制证据。

### 4.2 强候选：Evidence Survival、Relation Belief、Access Policy 不可合并

原始记录是否存活、某关系在何种 scope 下可信、当前是否可进入默认检索，是三个不同命题。效应估计或访问降权不能覆盖原始来源。该不变量主要贡献于可审计性和撤回安全，而不是压缩性能。

### 4.3 中等候选：把 Agent Memory 内生暴露写成 lifecycle-level 识别问题

Gap 1 的潜在新颖性不在“使用因果”而在 treatment construction 与纵向日志：候选、暴露、采纳、行动和结果必须分开，且治理动作会改变下一期候选流。该定位需要继续与 Trivium、CMI 及纵向 OPE 工作进行全文级对照，当前不能使用 `first` 或 `unique`。

### 4.4 中等候选：非对称 false-forgetting permission

稀有保护性记忆可能降低损失却不翻转二元成功；因此 false forgetting 与 false retention 不能使用对称阈值。当前 v3 支持减少 FF-regret，但 risk-weighted harm 略差，说明我们只证明了更保守的遗忘权限，没有证明总体安全最优。

## 6. 对最终框架的最小性约束

最终框架中的每个环节必须回答一个不可替代的问题：

| 最小环节 | 唯一职责 | 删除后的可证伪后果 |
| --- | --- | --- |
| 证据保真的原子 treatment | 明确测量对象并保留来源 | 无法定位干预对象或回放原始证据 |
| 条件关联 fallback | 在证据不足时保留廉价、低风险利用 | 全部等待因果资格会造成不必要的零使用 |
| 选择性付费审计 | 为少数候选产生可证伪证据 | 资格只能由共现或语义猜测产生 |
| 序贯 scope qualification | 区分 positive/negative/unresolved 并控制重复观察 | 未决证据会再次获得治理权限 |
| 资格门控访问治理 | 把证据资格映射为非对称访问动作 | 资格停留在诊断层，无法回应 Gap 2 |
| 三态分离与恢复路径 | 保持来源、关系和访问动作可撤回 | 派生状态覆盖证据，错误治理无法审计或恢复 |

任何额外模块若不能在固定 DGP、固定预算和共享候选流下通过单变量 remove/replace 消融，应留在可选工程层或删除。

## 8. 最终新颖性表述建议

> We do not introduce causal analysis, structured memory, adaptive retrieval, or accessibility decay as isolated novelties. We instead study a narrower lifecycle question: under policy-generated memory exposure, what evidence should be granted permission to alter a memory component's future accessibility? Our framework separates immutable evidence, scoped relation belief, and access policy; treats associational signals only as conditional fallbacks; and allows persistent governance changes only after sequential, scope-specific qualification under asymmetric forgetting costs. Controlled counterexamples show why unresolved evidence must not drive decay, while current experiments do not establish gains from probing, hierarchy, or recovery themselves.

这段仍应避免 `first`。只有完成最接近因果 Agent Memory 工作的全文和代码级核对，并在公开 benchmark 上完成同 reader、同候选、同预算比较后，才能进一步提高新颖性强度。
