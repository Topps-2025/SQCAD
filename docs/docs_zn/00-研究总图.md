# SQCAD 研究总览

## 研究问题

Agent Memory 常用相关性、时间、频率、共同曝光和任务结果更新未来访问。但候选暴露、采用和结果同时受到当前策略影响，成功轨迹可能把无关 hitchhiker 与有用记忆一起强化；低频保护性记忆也可能被普通衰减错误降权。

SQCAD 聚焦于：**什么证据有资格改变记忆的持久访问策略，以及在固定工作区预算下如何分配当次访问资源。**

## 核心分离

- **Evidence**：不可变来源和 provenance；
- **Qualification**：特定作用域下的 positive、negative、unresolved 或 mismatch 权限；
- **Access**：当前任务的有限预算分配。

作用域不是自动成立的泛化保证，而是一个需要在未见任务、用户、工具和版本变化下验证的条件化降噪假设。

## 当前边界

已有受控模拟和工程测试只支持机制层结论。LongMemEval 检索已在本地运行，LoCoMo 数据已冻结；尚未完成统一协议下的公开端到端强基线复现，不能声称 SQCAD 已达到 SOTA。
