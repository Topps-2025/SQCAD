# 遗忘机制

遗忘机制是 Agent Memory 中负责删除、降权、隔离或压缩低价值记忆的机制。

## 核心判断

在开放世界中，记忆不是越多越好。长期无差别保留历史经验，会带来检索成本上升、伪相关强化、旧因果链污染和信念冲突。遗忘机制的目标不是让 Agent 变得健忘，而是维持记忆系统的高信噪比。

## 与检索的关系

检索解决的是“需要时取什么”，遗忘解决的是“长期保留什么”。检索是用对记忆，遗忘是管好记忆。

## 与传统正则化的区别

传统正则化主要压制参数自由度，属于数学降噪；Agent 遗忘主要压制过期、冲突和低价值的语义记忆，属于语义降噪。

## 可能研究问题

- 如何评估记忆价值？
- 如何检测新旧记忆之间的语义冲突？
- 如何设计记忆的衰减、压缩、删除和隔离策略？
- 如何区分应保留的错误经验与应移除的污染记忆？
- 如何评估“忘得好”而不只是“记得多”？

## 保留疑问：写入与遗忘的边界

写入与遗忘并不总是清晰分离。写入是前瞻性决策，判断一条新信息未来是否可能有用；遗忘是回顾性决策，判断一条旧记忆过去是否真的产生价值。

因此，二者可以统一为“记忆效用治理”：持续估计每条记忆的价值、成本、可靠性、冲突度和时效性，再决定写入、巩固、降权、压缩、归档或删除。

## 统一算法设想

Memory Utility Governance 可以把每条记忆视为有生命周期的资产：

- 高预期价值：写入。
- 高实际贡献：巩固。
- 价值下降但仍不确定：降低可访问性。
- 长期低价值或高冲突：遗忘或归档。
