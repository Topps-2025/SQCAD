# QBism

QBism 是 Quantum Bayesianism 的一种发展形态。它将量子态理解为行动者对自身未来经验的信念度规，而不是独立于观察者的客观实体。

## 在本研究中的作用

这里引用 QBism 不是为了把量子系统直接等同于社会系统或 Agent 系统，而是借用它的认识论启发：

> 在某些问题中，观察者不是纯粹站在外部发现事实，而是通过行动参与事实生成。

开放世界中的 Agent 面对多主体信念交织、环境反馈和策略适应，也更接近“在信念场中动态适应”，而不是预测一个已经固定的未来。

## 与 Agent Memory 的关系

如果信念来自经验，那么经验必须被编码、保存、检索和更新。由此，[[Agent Memory]]可以被视为 Agent 信念形成与更新的基础设施。
