## A. 开放世界、有限理性与算力边界

- 用处：支撑“不存在对所有问题都最优的通用算法，问题结构决定工具有效性”。

它们主要补强四条论证线：

- Agentic Search：检索接口不应只服务人类点击和 top-k 相似度，而应服务 Agent 的多轮轨迹、证据链和直接语料交互。
- Agent Memory：历史错误、技能文档、假设树和轨迹都可以成为 Agent 的外部状态与可优化记忆。
- 持续学习：开放环境中的 Agent 需要从真实环境、反馈和失败中持续进化。
- 有限算力：更好的接口、记忆、技能和搜索策略可以提高单位算力的有效决策质量。
