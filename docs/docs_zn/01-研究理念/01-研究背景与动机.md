# 研究背景与动机：有限算力下，面向开放世界的智能求解范式

## 0. 核心理念：合适的工具，用在合适的地方

我当前想做的研究，可以概括为一句话：

> 问题的本质属性决定了求解工具的有效边界。真正重要的不是让一个模型或算法解决所有问题，而是识别问题处在什么“真理模式”中，再为它匹配合适的计算与推理范式。

因此，研究的出发点不是简单追求更大的模型、更长的上下文或更多的算力，而是追问：在[[概念节点/有限算力|有限算力]]下，面对一个持续变化、没有固定答案、参与者信念会反过来改变系统状态的[[概念节点/开放世界问题|开放世界]]，智能体应该如何组织经验、信念、推理与行动？

这个问题最终把我的兴趣引向 [[概念节点/Agent Memory|Agent Memory]]：记忆不是附属模块，而是 Agent 在开放环境中形成先验、更新信念、复用经验、降低推理成本的核心基础设施。

## 1. 三种真理模式：问题域决定求解范式

我希望先把“什么问题适合什么工具”讲清楚。不同问题域对“真理”的定义并不相同，因此不能用同一种算法想象去覆盖所有智能问题。

### 1.1 数学：定义即真理

数学问题的真理封闭在公理系统与形式定义之内。只要公理、定义和推理规则确定，命题的真假就不依赖具体物理世界，也不依赖观察者的主观状态。

这类问题适合形式化推理、符号搜索、蒙特卡洛树搜索、自动定理证明等“爆算”型或可验证型方法。LLM 在这里可以帮助生成证明思路、补全代码、提示中间步骤，但可靠性最终仍要落在形式验证、可执行检查或严格推导上。

### 1.2 物理：观测即真理

物理问题的核心在于客观规律。观测可能改变系统状态，但一般不改变规律本身。物理研究要做的是通过观测、方程和模型逼近这些规律。

因此，第一性原理数值模拟、物理信息神经网络、实验观测与参数反演，是这一类问题的重要工具。LLM 可以辅助建模、生成假设、解释实验现象，但真值约束始终来自观测、方程与可重复验证。

### 1.3 开放世界问题：无静态真理，无法爆算

我真正关注的是第三类问题：[[概念节点/开放世界问题|开放世界问题]]。

开放世界问题的典型特征是：状态空间指数级膨胀且持续扩展，参与者的行动会改变环境本身，系统中存在反身性、策略适应、信息不完全与语义不确定。复杂社会系统、真实商业竞争、多主体博弈、长期科研规划、开放式软件开发和具身智能探索都属于这一类。

棋盘是有限的，所以 AlphaGo 可以通过自博弈、树搜索和大规模算力在围棋上超越人类；但开放世界没有固定棋盘。状态空间不仅巨大，而且不断被参与者共同创造。对这类问题来说，“把所有可能性算完”本身就是错误想象。

这里可以引入 [[概念节点/QBism|QBism]] 作为认识论启发。QBism 强调量子态不是独立于观察者的客观物，而是行动者对未来经验的个人信念度规。这个观点不能被简单等同于社会系统或 AI 系统，但它提供了一个重要类比：在某些问题中，观测者不是站在系统外部发现一个已经写好的事实，而是通过行动参与到事实生成过程中。

开放世界中的 Agent 也是如此。它面对的不是等待预测的单一客观未来，而是由多主体信念、行动和反馈共同生成的动态场。因此，求解方式必须从“预测客观未来”转向“在信念场中动态适应”。

这也是为什么我认为 LLM 与 Agent 架构在此处具有必要性：LLM 负责在模糊语境中表达信念、理解语义、迁移概念；Agent 负责在环境反馈中感知、规划、执行、反思并更新信念。

## 2. 传统 LLM 范式的两大根本局限

### 2.1 优质语料蒸馏的边界：知道越多，不等于一定越好

大模型的基座能力主要来自海量语料上的压缩与蒸馏。在代码生成、数学证明、知识问答等相对封闭或可验证的问题上，高质量语料确实能持续提升模型能力。

但开放世界问题存在根本差异。第一，这些问题往往没有稳定标准答案，历史语料中充满冲突、噪声、策略性表达和局部最优经验。第二，开放世界具有反身性：当某种历史模式被模型学习并大规模应用后，环境本身会因为这些行动而改变，原有模式随即失效。

这意味着，更大的基座模型可能更会总结历史规律，但也可能更自信地过拟合表面关联。基模变强，并不等价于开放世界问题被解决。真正的能力不只是“知道过去发生过什么”，而是“在过去经验失效时，如何识别变化、更新信念、调整策略”。

### 2.2 有限算力约束：爆算之路走不通

第二个局限是算力。即使模型继续变大、推理预算继续增加，算力扩张速度也追不上开放世界复杂度的增长。实时决策、多主体互动和大规模组合问题，天然无法长期依赖“以量取胜”。

这就要求研究目标从“更多计算”转向“更高算力效率”：每一单位算力应该产生更高质量的判断。换言之，开放世界智能的关键不只是 scaling law，而是如何组织 memory、reasoning 和 learning，让 Agent 在有限预算下做出更稳定、更可解释、更能迁移的决策。

## 3. 宏观出路：Agent 的“记忆-推理-学习”三元组

在有限算力、静态语料过拟合、环境由信念和行动共同生成的约束下，我认为 Agent 架构的关键不是单一模块，而是三个能力的闭环：[[概念节点/Agent Memory|记忆]]、[[概念节点/推理|推理]]、[[概念节点/持续学习|学习]]。

### 3.1 记忆：以查代算

记忆的核心思想是用存储换取算力。Agent 将经历过的状态、行动、结果、失败模式和环境反馈沉淀为可检索经验。当遇到相似情境时，它不必从零开始整合所有变量，而是先唤起历史上的相似情境，再基于当前差异进行局部推理。

短期记忆用于维持当前任务中的关键信号、中间结论和待验证假设，避免推理链反复回溯。长期记忆则沉淀成功策略、失败案例、情境特征和领域知识，使 Agent 能够跨会话、跨任务、跨时间积累经验。

在开放世界中，记忆的意义尤其突出：如果环境变化太快，Agent 不可能每次都从头搜索；如果状态空间太大，Agent 更需要利用相似经验压缩搜索空间。记忆让 Agent 拥有“认知惯性”和“经验先验”，也让有限算力获得杠杆。

### 3.2 推理：单位算力做更好的内部计算

推理的目标是在外部试错成本高昂时，把更多预算投入内部模拟、分解、反思和自我检查。Chain-of-Thought、Tree-of-Thoughts、ReAct 等方法说明，LLM 不只是一次性生成答案，也可以通过中间推理、分支搜索、工具调用和行动反馈提升决策质量。

对 Agent 而言，每多一步有约束的内部推演，都可能避免一次昂贵甚至不可逆的外部错误。推理不是为了制造更长文本，而是为了在有限算力下，把计算花在真正影响行动质量的地方。

### 3.3 学习：在有限认知内打磨局部最优

开放世界中不存在永恒的全局最优策略。更现实的目标，是让 Agent 在持续互动、反馈和反思中形成“此时此地”的满意解，并在能力边界内不断上移。

强化学习、Self-Refine、Reflexion、Voyager 等工作提供了不同路径：根据结果反馈更新策略，把失败经历转化为可复用的反思，将解决过的问题封装成技能库，在新问题中复用。这里的学习不是一次性训练完成，而是运行时的持续修正。

## 4. 为什么聚焦 Agent Memory

在“记忆-推理-学习”三元组中，我希望优先聚焦 [[概念节点/Agent Memory|Agent Memory]]。原因是：记忆既是技术层面的差异化抓手，也是认知层面的第一性结构。

### 4.1 技术现实：基模趋同后，Memory 是 Agent 层壁垒

随着开源模型能力持续接近闭源模型，单纯依赖基座模型差异或轻量微调来形成长期优势会越来越困难。真正的创新空间正在上移到 Agent 层：模型如何被编排，如何在多轮循环中携带经验，如何在感知、记忆、规划、执行之间形成闭环。

Memory 正是 Loop Engineering 的核心抓手。它决定 Agent 在每一轮思考中带着什么先验进入下一步，决定哪些历史经验会被激活，哪些失败会被避免，哪些领域知识会被长期保存。

在私有化部署和垂直场景越来越重要的背景下，长期记忆沉淀的领域经验、用户交互历史和任务反馈，会成为最难复制的系统资产。同样的基模，配上不同质量的记忆系统，可能表现出完全不同的长期能力。

### 4.2 认知科学：记忆塑造认知本身

从认知科学看，记忆不是推理之后的存档，而是推理发生的基础。Hopfield 网络说明，稳定记忆痕迹可以被视为神经动力系统中的吸引子状态；工作记忆理论说明，当前任务相关信息的维持会直接影响语言理解、推理和问题解决；互补学习系统理论则强调，海马体和新皮层分别承担快速情景记忆与慢速结构化知识整合。

这些启发对应到 Agent 上：短期记忆决定当前可维持的“认知线程”，长期记忆决定可调用的经验边界，记忆更新策略决定系统如何把一次经历转化为未来可用的先验。

如果结合 QBism 的认识论启发，可以进一步得到一个更强的观点：信念不是凭空出现的，信念来自累积经验；经验要成为可用信念，必须被编码、检索、重组和更新。因此，记忆是信念的容器。研究 Agent Memory，实质上是在研究人工认知主体如何形成先验、如何更新信念、如何在开放世界中保持适应性。

## 5. 细分方向选择：为什么聚焦选择性记忆管理，以语义降噪与信噪比提升为主旨

在 Agent Memory 的若干子方向中，常见操作包括巩固、更新、索引、遗忘、检索、压缩与评估。近期工作已经表明，它们不是彼此独立的模块：写入控制决定何种信息有机会进入长期状态，存量记忆的衰减、压缩和演化决定其后续形态，读时访问控制决定其是否进入当前推理工作区。因此，本研究的直接对象不宜收窄为“遗忘机制”，而应界定为**选择性记忆管理**：在信息形成、已存记忆维护和推理阶段访问三个位置，对记忆的数量、表示、关系与暴露进行条件化调节。

其统一目标是提升 Agent 的**语义信噪比**：在有限计算、存储和上下文预算下，使与当前及未来行动有关、来源可追溯且作用域适用的证据获得恰当保存和暴露，同时抑制冗余、过期、冲突、失配或会诱发错误行动的信息影响。这里的“少”不是预设追求，也不等于删除数量；它是以较低认知负担维持必要行动区分、可修正性与可恢复性的结果。

因此，选择性记忆管理可按减负位置概括为：

\[
\text{选择性记忆管理}
=
\underbrace{\text{写入准入与跨层巩固}}_{\text{形成前/跨层}}
+
\underbrace{\text{状态、表示、结构减负}}_{\text{已存记忆本体}}
+
\underbrace{\text{读时访问减负}}_{\text{推理阶段}}.
\]

工作记忆与长期记忆可同时置于这一框架：工作记忆可经选择性巩固进入持久层；持久记忆也可在衰减、压缩或关系重组后，以受控方式重新进入工作区。遗忘是其中改变存量条目默认影响力的状态动作，而非全部研究主旨或唯一的语义降噪手段。

### 5.1 开放世界问题中的根本价值：提升记忆系统的语义信噪比

开放世界问题的难点不只是信息不足，也包括信息过剩。长期运行的 Agent 会不断积累交互日志、工具调用、失败轨迹、用户偏好、环境反馈和领域知识。如果这些内容无差别进入长期记忆，Agent 得到的不是经验优势，而是认知负债：检索空间变大、冲突信息变多、过期因果链干扰当前判断，推理成本和错误风险同时上升。

科学史上面对不可知系统、噪声观测和测不准问题，常见解法有两条路径。

第一条是控制论和信号处理中的“观测与滤波”。以卡尔曼滤波为例，它不幻想一次性预测目标的全部未来轨迹，而是持续融合上一时刻状态估计与当前噪声观测，动态修正对系统状态的判断。它的哲学不是长程全知，而是短程跟踪：承认世界在变化，核心任务是不断校正信念。

第二条是贝叶斯和统计学习中的“强先验约束”。面对过拟合，统计学不是相信更多数据必然带来更好判断，而是引入正则化、稀疏性、简单性偏好等约束。其背后的思想接近奥卡姆剃刀：既然真相不可完全抵达，就用更简洁、更稳定的解释压制噪声。

选择性记忆管理是这两条路径在认知架构中的交会。它并非被动的记忆衰退，而是围绕语义状态的主动滤波：在形成期以准入与巩固阻断低价值冗余，在存量期以衰减、压缩和关系演化调节表示与影响，在读时以资格与任务条件限制不适用信息进入推理。删除或弃用只是其中一种动作；对于可复用但当前不适用的经验，降权、归档、条件化并存、压缩或读时排除往往比物理删除更合适。

因此，选择性记忆管理的目标不是让 Agent “记得更少”，而是让记忆系统在形成、维护与调用的全过程维持更高信噪比。被保留或激活的记忆应是经来源、时间、任务、主体与反馈条件检验后仍具行动意义的认知资产，而不是无差别堆积的历史日志。

### 5.2 选择性记忆管理是 Agent 的语义降噪，而不是传统正则化的简单翻版

这里需要区分两类“降噪”：传统机器学习中的数学降噪，以及 LLM/Agent 记忆系统中的语义降噪。

| 维度 | 传统正则化：数学降噪 | LLM/Agent 选择性记忆管理：语义降噪 |
|---|---|---|
| 操作对象 | 模型参数，例如权重矩阵中的具体数值 | 记忆条目、上下文 token、轨迹片段、外部技能与信念状态 |
| 判断噪声的标准 | 权重是否过大、函数是否过于复杂、模型是否过拟合训练集 | 记忆是否过期、冲突、低可靠、低使用价值，是否干扰当前任务因果链 |
| 降噪方式 | 全局静态压制，例如 L1/L2、Dropout、早停 | 写入准入、跨层巩固、状态调节、表示压缩、关系重组、读时过滤与必要删除 |
| 结果表现 | 决策边界更平滑，泛化误差降低 | 推理链更集中，检索负担更小，因果归因更清晰，历史噪声更少干扰当前判断 |
| 核心目标 | 压制参数自由度 | 压制认知冲突和记忆污染 |

传统正则化关心的是函数空间的光滑度和参数空间的约束。它不理解数据的语义，只关心模型是否因过度自由而记住训练集噪声。选择性记忆管理面对的是另一类问题：长期记忆中的信息不是均质样本，而是有语境、有时间、有来源、有价值与冲突关系的经验。这里的噪声不只是随机扰动，而可能是失效策略、错误归因、被环境反身性推翻的旧规律，或与当前目标无关却在检索中反复出现的强干扰项。

因此，语义降噪不是 Dropout 式随机丢弃，也不是将所有低频信息直接卸载。它要求系统在不同位置采用不同动作：拒绝无关写入、将可复用经验巩固为适当粒度、对过时记忆降权或归档、压缩冗余但保留恢复线索、将冲突证据组织为条件化关系，并在当前任务下排除无资格进入工作区的信息。遗忘由此是语义降噪中的重要状态操作，但不能代表全部机制。

这也体现了 LLM 与 Agent 的关键能力：并非单纯提高物理速度，而是在不可知域中形成高信噪比、可追溯且可修正的认知状态。高信噪比的“慢思考”信号往往比低信噪比的“快反应”具有更高决策价值。

### 5.3 三层选择性记忆管理如何共同服务语义降噪

三个大方向对应不同阶段的噪声来源与干预方式：

| 减负位置 | 主要噪声风险 | 典型动作 | 对语义信噪比的贡献 |
|---|---|---|---|
| 形成与跨层迁移 | 瞬时噪声、重复记录、局部观察被过早固化 | 写入准入、抽取、合并、跨层巩固 | 限制低价值信息进入长期维护链，并稳定必要经验。 |
| 已存记忆本体 | 过时条目、冗余表示、冲突版本与无序关系累积 | 衰减/归档、压缩、条件化更新、关系重组 | 调节默认影响力，降低表示和结构性干扰，同时保留恢复与追溯条件。 |
| 读时工作区 | 当前任务下的无关暴露、上下文竞争、错误采纳 | 资格门控、任务条件检索、路径控制 | 阻止当前不适用的记忆进入推理，而不必永久删除。 |

检索回答“此刻应访问什么”，写入与巩固回答“什么应形成稳定经验”，本体减负回答“已存经验应以何种状态、表示和关系继续存在”。三者必须联动：Yuan 等的诊断表明，在其设定中检索方法造成的性能差异显著大于复杂写入策略；Oblivion 也明确拆分读路径和写路径。因此，任何单一动作都不能被宣称天然更重要；研究应通过控制写入、候选库、检索器、预算与工具环境，检验其对任务效用和噪声抑制的独立贡献。

### 5.4 可能的研究问题

围绕选择性记忆管理，后续可将问题收束为以下方向：

1. **形成期条件价值。** 在未来查询未知时，何种观察应被写入或跨层巩固？新颖性、来源、作用域、风险和相对参数知识增量如何共同约束准入？
2. **状态减负与风险敏感保护。** 如何在时间、频率与结果反馈之外，保护低频—高后果记忆，并区分条目的历史活跃度与未来条件化行动价值？
3. **表示减负的可修正性。** 如何压缩历史而不丢失时间、来源、反例、环境签名和恢复路径，使摘要可在漂移后被解压、再解释或安全弃用？
4. **结构演化与冲突治理。** 如何将新旧证据组织为替代、并存、细化、例外、支持或分叉关系，避免错误覆盖与无约束增殖？
5. **读时资格与任务适配。** 如何使“不读取”表示时间、主体、权限、撤回或任务作用域上的不适用，而非索引失败或预算截断？
6. **过程级评测与因果归因。** 如何区分未写入、错误巩固、误衰减、压缩失真、关系误判、未检索、未采用与执行失败，并以干预式协议估计不同管理动作的条件化影响？
7. **参数—外部记忆边界。** 当模型参数已编码某一语义内容时，外显记忆能否提供来源、时间、权限、可撤回性或行动价值的可审计增量？如何避免参数化未来知识造成前视偏差？

### 5.5 保留疑问：写入、遗忘与读时控制的边界是否真的清晰？

这里也存在一个需要保留的关键疑问：记忆写入和记忆遗忘的边界并不总是清晰。

从表面看，写入负责“决定记住什么”，遗忘负责“决定忘记什么”，检索负责“此刻访问什么”。但在真实 Agent Memory 系统中，三者往往不是独立管线，而是同一选择性管理问题在不同时间点和不同操作层的表现。写入发生在信息产生时，状态减负发生在信息存续后，读时控制发生在任务推理时；前者基于未来潜在价值的预测，后两者分别基于历史表现复盘与当前任务条件。

> 写入与巩固是为“可能有用”建立可治理状态；状态减负是为“影响失配或维护成本过高”调整其默认作用；读时控制是为“当前不适用”限制其进入工作区。

因此，写入、遗忘与读时控制之间并不存在预设的静态边界。它们的边界更像动态决策面：当新信息出现时，系统判断是否值得承担存储与未来检索成本；当旧信息存在一段时间后，系统判断它应以何种状态、表示和关系继续占据资源；当具体任务到来时，系统还要判断它是否具备进入当前工作区的资格。

| 维度 | 写入/巩固：形成何种可治理记忆 | 本体减负：如何维护已存记忆 | 读时控制：当前是否暴露 |
|---|---|---|
| 时间方向 | 前瞻性，面向未来潜在价值 | 回顾性，基于实际表现、新证据与维护成本 | 即时性，面向当前任务与上下文预算 |
| 决策时刻 | 信息产生、任务完成或反馈出现时 | 记忆经历检索、使用、冲突、版本变化或时间演进之后 | 查询、规划或生成过程中 |
| 核心依据 | 新颖性、证据来源、作用域、风险、相对参数知识增量 | 时效性、贡献、冲突、替代/撤回证据、表示冗余与关系结构 | 任务相关性、资格条件、不确定性、边界结构与预算 |
| 主要风险 | 误拒有价值经验，导致未来无法复用 | 误衰减、压缩或覆盖关键经验，或保留有害噪声 | 漏读关键证据或暴露不适用信息 |
| 目标 | 形成未来可治理的认知资产 | 在可恢复与可追溯前提下降低维护负担 | 在有限工作区中提供当前适用的证据 |

这一边界问题本身构成研究机会：不应将写入、遗忘和检索硬切开，而应将它们统一为围绕行动价值、作用域、证据谱系与资源成本的选择性记忆管理问题。



### 5.6 与当前 Agent Memory 文献的关系

近期 Agent Memory 研究正在快速从“存储更多”转向“管理更好”。综述类工作已经开始把 Agent Memory 与 LLM Memory、RAG、上下文工程区分开来，并从形式、功能、动态性或“写入-管理-读取”循环来描述记忆系统。A-MEM、GAM、SAGE 等方法强调图结构、动态索引和关联演化；SimpleMem、LightMem、SuperLocalMemory 等工作强调轻量化、局部化、生命周期和工程可部署性；Learning What to Remember、MemBench、Diagnosing Retrieval vs. Utilization Bottlenecks 等工作则开始把研究重点推进到“记忆价值”“诊断瓶颈”和“评估体系”。

这说明 Agent Memory 已经不再只是 RAG 的工程变体，而正在成为一套独立的外部认知系统。选择性记忆管理贯穿这套系统：它连接写入、巩固、检索、更新与安全，决定 Agent 的长期经验是逐渐沉淀为可行动知识，还是逐渐累积为语义噪声。

更准确地说，遗忘不应被孤立理解为“删除模块”。它是选择性记忆管理的一种状态动作；系统应持续判断每条记忆的预期价值、实际贡献、冲突风险、维护成本、作用域与相对参数知识增量，并据此决定写入、保留、巩固、降权、压缩、归档、关系重组、读时排除或删除。

## 6. 阶段性结论

这一研究方向的背景逻辑可以压缩为以下链条：

1. 不同问题域具有不同真理模式，不能用同一套工具解决所有问题。
2. 数学和物理问题可以更多依赖形式验证、数值模拟和观测约束；开放世界问题则没有静态全局真理。
3. 开放世界具有状态空间爆炸、反身性和语义不确定，单纯依靠大模型语料蒸馏或暴力算力扩张无法根治。
4. 因此，智能求解范式要转向 Agent 的记忆、推理与持续学习闭环。
5. 在三者中，Memory 是最值得优先切入的方向：它让 Agent 以查代算、复用经验、形成信念，并在基模趋同后构成 Agent 层的核心壁垒。
6. 在 Memory 的子方向中，选择性记忆管理是进一步聚焦的研究框架：它通过写入准入与跨层巩固、已存记忆本体减负和读时工作区减负提升语义信噪比，使 Agent 不被过期经验、伪相关和冲突信念拖累。

所以，我希望后续围绕 Agent Memory 的选择性记忆管理展开研究：不将其收窄为 RAG、上下文扩展或删除机制，而是将其视为开放世界智能体的“信念形成、信念更新、信念组织与信念清理机制”。
