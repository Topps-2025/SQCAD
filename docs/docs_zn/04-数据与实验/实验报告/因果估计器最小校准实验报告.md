# 因果估计器最小校准实验报告

## 1. 目的与边界

该实验验证因果遗忘框架的一个统计前提：当任务难度同时影响记忆暴露概率和结果时，成功共现或暴露组—未暴露组差值是否会系统性误估记忆效应，以及调整后的 OR、IPW 和 DR 能否恢复已知 ATE。它不包含多步状态迁移，因此不能替代 MSM、sequential DR 或 DR-OPE 的序贯验证，也不是公开 Agent Memory benchmark 结果。

脚本：[[causal_estimator_sanity.py]]；结果：[[causal_estimator_sanity.json]]。

## 2. 数据生成过程

- 50 个独立随机种子，每个种子 4,000 个样本；
- 可观测任务条件 $H$ 同时影响记忆暴露 $Z$ 和结果 $Y$；
- 低频高冲击切片 $H=0$ 的占比为 0.2、真实处理效应为 1.0；常见切片 $H=1$ 的占比为 0.8、真实处理效应为 0.2；
- 真实 ATE 为 $0.2\times1.0+0.8\times0.2=0.36$；
- 暴露倾向分别为 $P(Z=1\mid H=0)=0.15$ 与 $P(Z=1\mid H=1)=0.85$，构造显著选择偏差；
- DR 故意使用忽略 $H$ 的错误结果模型，同时使用正确 propensity，用于校验其在一侧辅助模型正确时的稳健性。

## 3. 结果

| 方法 | ATE 均值 | 平均偏差 | 跨种子偏差 95% CI 半宽 |
| --- | ---: | ---: | ---: |
| 成功共现/naive difference | 1.048 | +0.688 | 0.012 |
| Misspecified OR（忽略 $H$） | 1.048 | +0.688 | 0.012 |
| Adjusted OR（按 $H$ 分层） | 0.359 | -0.001 | 0.011 |
| IPW（真实 propensity） | 0.354 | -0.006 | 0.019 |
| DR（错误 OR + 正确 propensity） | 0.359 | -0.001 | 0.014 |

DR 的单次样本 95% 置信区间在 50 个种子上的覆盖率为 1.00，平均半宽为 0.108。该覆盖结果偏保守，不能单独用于证明真实系统中的区间校准。

## 4. 初步判断

实验支持“成功/失败共现不是记忆因果价值”的核心痛点：在本数据生成机制中，naive estimator 将真实 ATE 0.36 高估为约 1.05。只要记录并正确调整暴露前条件，OR、IPW 与 DR 均能显著降低偏差；DR 在结果模型故意错误时仍接近真值，说明真实 propensity 日志具有不可替代的工程价值。

但该结果仍不支持“序贯因果遗忘已经可行”。下一道门槛是生成过去暴露会改变后续候选、状态和处理概率的长 horizon simulator，在其中比较静态 DR、MSM、sequential DR 与实际部署策略值。若序贯方法不能比静态估计更准确地排序治理策略，则论文的序贯因果贡献不成立。
