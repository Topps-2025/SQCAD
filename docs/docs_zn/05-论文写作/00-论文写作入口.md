# 论文写作入口

本目录用于保存 SQCAD 的中文论文结构、段落草稿和写作审计。英文展示稿位于同级的 `../../docs_en/`。

## 写作边界

- 只使用已核验的研究问题、协议和结果；
- 受控机制实验不能包装为公开 benchmark 的 SOTA 结果；
- 新颖性表述必须等待最接近工作的全文与代码核验后再冻结；
- Introduction、Method、Experiments 的正式英文版本与中文研究底稿分开维护。

- `../04-数据与实验/实验报告/`
